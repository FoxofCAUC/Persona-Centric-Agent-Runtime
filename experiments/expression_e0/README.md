# E0固定材料与E1有限对照

E0冻结24个开发场景及其中8个表达资产消融场景。16份为召回验收中已获作者审阅的公开人工角色真实v8首次主稿，完整文本和必要语境留在所选证据目录；8份为本目录明确标记的人工边界稿，覆盖代码、原样引用、条件与承诺、未取得资料、同题不同角色、关系边界和简短确认。人工稿不冒充模型首次返回。

`materials_manifest.json`固定材料来源、摘要校验及对照位置。`public_fixtures.json`保存人工边界稿和人工表达候选。真实回执正文、业务库、人物原件和密钥不进入源码仓库。证据材料可用性由只读预检检查，缺失时停止对应实验，不回放旧主调用补齐。

E1在同一冻结输入上比较A保存主稿、B仅本地分段计划、C一次表达再制；8个诊断位置另比较C与移除表达候选的C0。C0保留人物身份、获准的基础表达设定、任务和真实语境。正文与候选面对相同材料，首次结果完整保存；候选可为空，表达也可以保持原稿。场景标签和验收要点只供工程审阅，不拼进人物提示。

`call_plan.json`冻结供应商、价格、32个表达物理位置上限、零自动重试及停止规则。B不调用模型，额外分句调用未启用；若E1发现有必要，先修订有限计划，仍受施工方案额外最多24个位置约束。E0不派发收费请求。E1比较新增表达等待，逐条桌面体验在E4/E5验证。

E1提示装配与上游函数抽取在E1实施；本目录没有可启动的模型派发器。原稿、候选再制和作者评语分开保存，真实与人工边界场景分别汇总，作者审阅结果不预填。E5的新场景及连续体验保持未使用状态。
