# 原v8与最小转译的独立会话A/B

本实验使用8组新公开合成会话、4种原有角色，每组6轮。A为原v8，B为同一v8加`expression-persona-draft-v2`；只对B交接源模型的IM标点指导。两链各自保存实际发言历史，B同时保存完整源稿，不复用另一条链的历史。

最多174个客户端请求位置：主回复96、主回复转译48、查前源稿4、查前转译2、Jev24。每个位置每种用途一次派发，异常不补跑或挑样；原生检索由固定资料／失败回执在两个范围分别登记，没有真实检索HTTP请求或隐含工具费用。报告分别保留真实请求、未知用量和受控材料，不能将模拟回执宣称为真实搜索或桌面呈现。

`study prepare`冻结角色、脚本、素材、源代码摘要、匿名键和预算，证据目录必须位于源码之外。`study run`使用显式`--credential-home`读取当前获准提供商密钥，真实密钥仅在派发时替换，不写入实验配置或请求记录。所有公共请求沿既有系统代理；缺失时停止，不改代理设置。

`study report`和`study verify`只读取既有回执，不调用模型。已存在但尚未封口的位置需要先复核，不通过重新执行来恢复成功或未知请求。审阅页提供同排版正文、完整气泡会话和B链源稿，组内甲乙固定、组间随机；相同正文折叠，失败显示原状态。

离线验证为`tests.test_expression_ab_conversation`，其174份客户端响应全部为人工夹具。真实结果由作者判断正文自然度、角色感、意思保持、完整交流及额外等待和费用；未获明确认可前不进入E4或修改正式默认策略。
