# E.N0 人物口吻、素材和提示候选

**2026-11-17作者已否决本候选，以下原交付说明只作历史追溯。** 本目录中的语言材料、提示、模拟场景、理解笔记和输入预览均禁止用于上游LLM、E.N1、表达学习或下一版prompt种子。原文件保持，使用资格已撤销，详见[模型输入与提示词写作总则](../../docs/模型输入与提示词写作总则.md)。

当前装配与render入口直接拒绝执行；verify-review只返回已否决及不可放行状态，旧导出文件中的全部通过选择也不能恢复候选。后续需要新的具体写作授权和独立的使用审阅，不能改名或改任务ID绕过。不得因运行旧静态测试而重新生成候选；现有测试仅验证阻断和历史材料完整性。

本包按[新E阶段指导](../../docs/expression/E阶段重构-人物回复链路开发指导.md)准备作者审阅材料，不提供模型派发、资产入库或正式配置修改入口。

`materials.json`是可编辑原件：四种现有公开合成人物的新口语设定，每人12条情境表达、4组静态话语片段。话语片段由开发代理编写，只供口吻审阅；示例本身不自动进入人物提示，也不作为真人学习材料。`prompts`目录保存Flash理解、Pro人物直接发言、Pro查前发言三份候选。

装配器沿用此前四个人物的完整初始资料，只提出表达设定更新。静态输入覆盖16个待研究位置，另提供查前、资料取得／未取得、关系与记忆更正4个补充场景。理解笔记是开发代理填写的说明稿，不是Flash的实际返回；表达选择也是静态示意，不宣称本地检索已经执行。

生成到操作者选定的数据目录，目标必须在源码仓库之外且不存在：

```powershell
python -B -m experiments.persona_reply_n0.bundle render --output <审阅输出目录>
```

页面支持四种角色和三份提示逐项选择、备注、整体结论及JSON导出。意见绑定完整材料和各条目摘要；新草稿须使用新的输出目录，保留旧文件。

核对作者导出的意见：

```powershell
python -B -m experiments.persona_reply_n0.bundle verify-review --output <审阅输出目录> --review <作者意见文件>
```

`verify-review`只核对意见，既不派发请求，也不改写批准状态。下一阶段E.N1须在作者确认材料后另行冻结，最多64次首次客户端请求，比较v8 Flash、v8 Pro与Flash理解＋Pro Replyer。正式库、程序版本、当前运行链路与旧回执保持原状态。
