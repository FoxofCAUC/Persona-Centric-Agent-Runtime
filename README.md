# PCAR · 超级大肥鱼

**PCAR（Persona-Centric Agent Runtime）是一个全能的开源 AI 伴侣辅助服务项目。** 从创建角色、管理设定，到记住相处中的重要事情、接续过去的聊天，你可以在同一个工作台里完成。

[核心能力](#pcar-的核心能力) · [下载与体验](#从这里开始) · [远期愿景](#远期愿景) · [参与共建](CONTRIBUTING.md)

## PCAR 的核心能力

### 人格中心 · 每个角色有自己的资料

在工作台里创建或导入角色。角色的设定、关系、聊天和记忆都围绕这个人物管理。换一个聊天会话，仍然可以选中同一个角色，沿用她的设定和记忆。

### 人格版本化 · 改过的设定可以找回来

相处久了，你可能想补上角色的背景，也可能发现改过的设定不如从前顺手。PCAR 为人物设定和关系保留版本。你可以查看以前的设定，需要时恢复到熟悉的版本。

### 长期记忆 · 聊起旧事时，找回相关经历

配置记忆整理模型并为角色开启自动记忆后，PCAR 可以从聊天中整理重要信息。下次谈到相关话题时，PCAR 会找回用得上的记忆。比如隔了一段时间聊起旅行，角色可以接上你们曾讨论过的目的地。

### 从私聊记录还原人物

**新版 Windows 工作台候选**支持导入你参与的双人私聊。你可以用记录新建角色，也可以为已有角色接续聊天。

- **从聊天建角色。** PCAR 根据聊天内容预填人物设定和说话习惯。你可以对照原话修改，再选择保存其中一人或两人。[从聊天记录生成角色卡](docs/user/双人聊天生成角色卡.md)
- **从上次聊到的地方继续。** 选好双方身份和可用于续聊的原话，导入后可以接着最后一条消息聊，也可以翻出一句旧话引用。是否整理长期记忆，由你在导入时选择。[历史聊天接续指南](docs/user/历史聊天接续.md)

从当前仓库或历史接续候选包运行 `启动PCAR-新版.bat` 即可体验。

## 从这里开始

**v0.2 公开桌面版**已在 Windows 11 x64 上验证，支持从 v0.1 原机升级。

1. 在 [v0.2 发行页](https://github.com/FoxMoreland/Persona-Centric-Agent-Runtime/releases/tag/v0.2)下载 `PCAR-v0.2-Windows-x64-desktop.zip` 和校验文件。
2. 解压为独立工作区，让 Codex、DSH 等 Agent 阅读包内 `AGENTS.md` 与 `AGENT_INSTALL.md`，完成环境和实例配置。
3. 通过 `启动PCAR.bat` 打开工作台，选择角色并配置官方 DeepSeek 模型，在“聊天”中开始交流。

使用前请准备网络、有效的 Windows 手动 HTTP/HTTPS 系统代理和自己的模型服务。桌面包包含本地检索模型，Python 等依赖由 Agent 准备。[第一次使用指南](docs/user/getting-started.md)

角色和聊天记录保存在本机。调用云端模型时，模型服务会收到生成回复所需的材料。聊天、测试、重试和后台模型任务可能产生费用。

## 远期愿景

**给你的大肥鱼，一个完整的人生。**

![社区鲸鱼娘在窗边翻开相册，身旁的书信与书本象征过去的经历和未来的日常](assets/readme/superfish-vision.webp)

*愿景插画，依据社区鲸鱼娘设定进行 AI 辅助二创。[形象来源与署名](assets/readme/ATTRIBUTION.md)。*

### 她有自己的时间

在 PCAR 的远期设想里，大肥鱼醒来时，昨天读到一半的书还摊在桌上。你去忙自己的事，她可以读完那一章、试着照料一盆植物，也可以睡个午觉。等你回来，她有了自己的事想和你聊。

我们想把聊天里的连续性延伸到日常生活。读到了哪一页、窗边的植物什么时候浇过水、明天有什么安排，都能在下次醒来时接着做。

<img src="assets/readme/continuity-concept.png" width="720" alt="设计方向：同一个人格连接身份与关系、过去的经历、关切与计划、生活状态及未完成的事情">

*设计方向 · 同一个人格如何接续自己的经历、关系和计划。*

### 在经历中，成为自己

她试着照料一盆植物，记下哪扇窗的光线合适，第二天想起给它换个位置。这样的经历可以改变她下一次的选择。

![远期生活设想，按从左到右、从上到下阅读：鲸鱼娘醒来、独自阅读与记笔记、分享照料植物的发现、夜间休息](assets/readme/daily-life-vision.webp)

*远期生活设想 · 醒来、独处、重逢、休息。*

虚拟生活是 PCAR 的远期方向。我们想让角色参与活动、看到行动的结果、回顾自己的经历，慢慢形成兴趣和习惯。

休息也算进日常。远期设计里，角色睡觉时暂停模型调用，醒来再看留言、继续手头的事。全天在线由独立的云端方案探索。学习工具、制作技能和维护自身能力也在远期路线中。
