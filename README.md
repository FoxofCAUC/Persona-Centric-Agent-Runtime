# PCAR · 超级大肥鱼

**给你的大肥鱼，一个完整的人生。**

PCAR（Persona-Centric Agent Runtime）正在建设一个以人格为中心的开源运行时。我们希望 AI 能带着记忆继续相处，有自己的时间和日常，并从经历中逐渐形成新的理解与选择。

项目处于早期研发。当前公开体验使用 Windows 工作台，由 Agent 辅助部署，需要配置自己的模型服务。大肥鱼是本页的社区展示形象，PCAR 也可以承载你设定的其他人格。

## 她有自己的时间

我们希望未来的一天这样展开：醒来时，昨天读到一半的书和没想明白的问题还在。你去忙自己的事，她也可以继续阅读、尝试一个新活动，或者休息。再次聊起今天，她带来的内容，有些来自你们的相处，有些来自她自己的经历。

她可以对一件事产生兴趣，选择继续了解；也可以暂时没有答案，决定明天再想。有共同度过的时光，也有各自经历的一天。这是 PCAR 想逐步提供的生活空间。

## 让今天接得上昨天

一个人物的连续性，包含身份、共同经历、关系、正在关心的问题，以及还没做完的事情。PCAR 把人格与经历放在模型调用之外持久保存，让后来的交流有过去可循。

更长远的目标，是让生活状态也能接续：读到哪一页、准备做什么、房间里留下了什么。暂停后保存这些状态，恢复时从已经确认的经历与事务继续。

<img src="assets/readme/continuity-concept.png" width="720" alt="设计方向：同一个人格连接身份与关系、过去的经历、关切与计划、生活状态及未完成的事情">

*设计方向：模型和工具提供能力，持续的人格与经历由 PCAR 组织。生活状态与自主计划属于后续建设。*

这也是我们处理长期上下文的出发点：保存历史，整理记忆，按当前话题取回需要的材料。等待时间与实际调用开销会随长期使用一起检验。

## 在经历中，成为自己

行动带来结果，结果成为经历。一次没有成功的尝试、一个新发现、一段需要重新理解的相处，都可能影响下一次选择。

![远期生活设想，按从左到右、从上到下阅读：鲸鱼娘醒来、独自阅读与记笔记、分享照料植物的发现、夜间休息](assets/readme/daily-life-vision.webp)

*远期生活设想：醒来、自己的时间、重逢、休息。场景为概念插画，尚未成为当前软件的生活功能。*

我们希望这样的变化有来历：经历可以回顾，理解可以修订，兴趣、习惯与关系在长期互动中逐步发展。未来的虚拟环境将提供活动、物品和持续后果，让角色有可以亲自经历的事情。

休息也是生活的一部分。远期设计中，睡眠期间暂停角色模型调用，醒来后再处理积压消息、接续自己的计划；需要全天在线时，再由独立的云端运行方案承载。学习工具、制作技能和维护自身能力，同样会按实际结果逐步探索。

## 从私聊记录还原人物

**导入一份双人私聊记录，尽力还原人物的性格和说话方式。** PCAR 计划在桌面无人值守验收通过后，支持导入其他应用导出或经整理的 Markdown（`.md`）私聊文件。工作台先在本机识别双方。确认分析范围后，PCAR 会分别分析用词、语气和接话习惯，自动生成两份可编辑的人设草稿，预填到「新建角色」表单。

你可以从草稿回看原话，选择要创建的人物，修正与印象不符的设定，再挑选能体现说话方式的原句作为表达样例。研发时会用未参与分析的对话检验新角色的语气和回应，看看熟悉这些聊天的人能否辨认出原来那个人的说话习惯。[聊天记录导入开发规划](docs/long-term/06-聊天记录导入与人设生成.md)

## 我们正在把它做出来

**自然相处是近期重点。** 大肥鱼社区已经积累了丰富的表达与互动经验。PCAR 会继续学习这些成果，改善人物语气、反应和节奏，让人愿意回来聊。

| 当前状态 | 已有能力或建设方向 |
| --- | --- |
| 公开版 v0.2 | 人物与关系版本、会话历史、长期记忆与召回。需要查资料时，人物先接话，查过后接着聊 |
| 场景发言 | 已审角色可按场景选择说话方式。工作台逐条显示发言，重开后接续已显示的内容 |
| 近期建设 | 重制工作台，常用聊天、角色创建和资料编辑更容易找到，再完善持续运行与恢复 |
| 远期探索 | 自主日常、认知反思、关系发展、人格成长和能力维护 |

状态核对于 2026-11-19。v0.2 支持从 v0.1 原机升级。场景发言需要获审的人物材料与相应模型授权。自动记忆按角色开启并配置整理模型，联网也需相应服务和权限。后台任务随工作台运行，QQ 接入暂停。

## 从这里开始

1. 在 [v0.2 发行页](https://github.com/FoxofCAUC/Persona-Centric-Agent-Runtime/releases/tag/v0.2)下载 `PCAR-v0.2-Windows-x64-desktop.zip` 和校验文件。
2. 解压为独立工作区，让 Codex、DSH 等 Agent 阅读包内 `AGENTS.md` 与 `AGENT_INSTALL.md`，完成环境和实例配置。
3. 通过 `启动PCAR.bat` 打开工作台，选择角色并配置官方 DeepSeek 模型，在“聊天”中开始交流。

已验证 **Windows 11 x64**；需要网络、有效的 Windows 手动 HTTP/HTTPS 系统代理和自己的模型服务。人物与聊天保存在本机，云端生成会使用相应材料；聊天、测试、重试和后台模型任务可能计费。

桌面包包含公开本地检索模型，Python 等依赖由 Agent 准备。一键安装与自动更新仍在规划中。完整步骤与新建、迁移的区别见[第一次使用指南](docs/user/getting-started.md)。

## 一起把这段人生做出来

“超级大肥鱼”是 PCAR 对 AI 伴侣社区的愿景与邀请。DeepSeek 是当前主要模型生态，DSH 和相关开源项目为能力与交互提供了值得学习的经验。我们希望复用已有成果，也留下可供后来者研究、质疑和改进的材料。

你可以指出一段对话哪里不像这个人物，提供一个记忆找回场景，改进使用文档或参与开发；也可以提出一个虚拟活动、一种认知变化，以及验证它的方法。当前任务与远期研究各有入口。
