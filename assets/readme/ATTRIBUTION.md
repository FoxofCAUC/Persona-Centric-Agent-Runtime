# README 插画与展示素材

## 大肥鱼的形象来源

本页的大肥鱼采用社区既有的 DeepSeek 鲸鱼娘二创形象：蓝色渐变长发、鲸鳍、鲸尾与深蓝白女仆装。角色原型与前序设计归相应作者所有。

- **上善无形（上善）**：鲸鱼娘原始角色形象。[作者主页](https://space.bilibili.com/4456176)
- **ZipZipPipe**：加入 DeepSeek 元素的女仆鲸鱼娘二次设计。[作者主页](https://space.bilibili.com/4168597) · [《AI娘化》](https://www.pixiv.net/artworks/148186519) · [《大AI和小AI们》](https://www.bilibili.com/video/BV1tE9XBbErS/)
- **YunYueSama**：本次使用的 Q 版设定图参考。[codex-deepseek-pet](https://github.com/YunYueSama/codex-deepseek-pet) · [固定版本设定图](https://github.com/YunYueSama/codex-deepseek-pet/blob/7661c8b304c5400701f91da01b1a643a207331de/design/character-standard.png)

本次通过 [xiaoweigen 的来源记录](https://github.com/xiaoweigen/deepseek-dafeiyu-assets/blob/7e7a888845877b30314d36a7f274dc3bd6f330b1/NOTICE.md)交叉核对创作链和原作入口，生成输入直接采用上列 YunYueSama 设定图。作者署名说明来源，不表示作者或 DeepSeek 为 PCAR 背书。

## 当前愿景插画

`superfish-vision.png`：2026-11-16 由 PCAR 项目使用内置 imagegen 工具，依据上述设定图制作的 AI 辅助二创。保留角色头身比例、发色、鲸鳍、鲸尾和女仆装，新增窗边、相册、书信与日常场景。画面说明项目愿景，不是工作台截图或已运行的虚拟生活。

`daily-life-vision.png`：同日以相同设定图及上述插画为参考生成，新增醒来、阅读与记笔记、分享植物生长、夜间休息四个连续场景，明确标注为远期生活设想。

首页使用 `superfish-vision.webp` 和 `daily-life-vision.webp`。它们由原 PNG 无损转码，尺寸和解码后的 RGBA 像素逐项核对一致，无裁剪、重绘或画面改动。下列许可与署名适用于两张插画及其 WebP 版本。

## 概念说明图与历史素材

- `continuity-concept.png`：PCAR 原创概念说明图，围绕同一个人格组织身份与关系、经历、关切与计划、生活状态与未完成事务；标明设计方向，按项目文档许可提供。由可编辑原稿 `continuity-concept.svg` 以两倍像素密度导出，避免浏览器深色整页捕获时屏幕外 SVG 内容缺失。
- `desktop-main.png`、`persona-versions.png`、`memory-overview.png`：历史工作台截图，已退出本轮宣传页和预览。它们从独立 v0.1 Windows 工作台采集，人物、会话与手动记忆为公开人工演示数据，没有模型调用。
- `life-roadmap.svg`：前版路线图，当前首页改为简短状态表，原图保留追溯。

界面截图展示操作与形态，预置样例不作为模型生成或自动记忆的效果证据。
