## 行为与入口

工作台新增“记忆整理”页，模型页新增“记忆整理模型与费用”。打开窗口不发模型请求；关闭窗口保留人格服务，因此已经启用的后台计划仍由服务运行。

| 入口 | 实际行为 |
| --- | --- |
| 预览整理范围 | 选择当前人格的会话、模式、起终点，返回一批最多10个成功轮次；不调用模型 |
| 提交本批整理 | 一次调用生成摘要、候选或两者；手动生成候选仍须确认 |

| 候选 | 查看证据与可能相关记忆，编辑确认、新建、修订已有有效版本或拒绝 |
| 摘要 | 查看累计版本、覆盖序号、原文证据；停用摘要或勾选重建后提交新任务 |
| 聊天“查看本轮记忆使用” | 查看本次尝试使用的摘要/记忆版本、匹配依据、预算裁减及覆盖缺口 |
| 每日计划 | 下次本机时间、固定人格、批次进度、额度等待、异常或冲突状态 |

默认独立整理模型不配置地址和名称，不静默复用聊天模型。可明确勾选复用，也可填独立接口/模型/DPAPI密钥。保存不调用模型；“测试整理模型”是一次真实请求，计入额度。

## 每24小时全量自动更新（用户追加要求）

这项要求取代原准备方案中“所有自动候选均需人工确认”的建议：**每日全量任务正常记忆结果自动生效，明确冲突项保留待授权；手动与可选空闲增量任务仍人工确认。**

- 默认开启每日计划，首次在本项目人格服务初始化计划后24小时到期。截止时间持久化，重启不重设；显示为本机时区时间。
- 每轮开始绑定当时选中的人格，对其全部有效历史会话逐批扫描，不处理其他人格。执行中切换人格不改变该轮归属。
- 扫描开始时冻结各会话的历史终点，之后新消息留到下一轮；屏蔽来源不重新扫描或恢复。
- 每日正常候选自动写入，精确重复合并；模型标为与已有记忆直接矛盾的项目不自动覆盖，显示冲突待授权。用户在候选页选择修订、新建或拒绝。
- 冲突批次的摘要暂缓发布，其他无冲突候选仍可生效；扫描完成后若仍有冲突，整个每日周期等待审阅，下一周期不绕过它。
- 达到后台小时6次、滚动24小时20次，或前后台合计小时30次上限时，显示等待额度，恢复后继续剩余范围。全量不代表无限收费或承诺当天一定完成。
- 正常失败、中断和来源过期显示受阻，不自动重试收费调用。可显式重试任务；来源过期或换模型后用“继续受阻的每日更新”重新预览剩余范围。
- 服务离线、电脑休眠期间无法调用；恢复后只开始一轮，不追补离线期间的每一天。该轮原定下次时间向后推进到未来的24小时间隔。
- “立即执行一次全量更新”是显式收费操作，便于验收或提前更新；下次时间重设为此次开始24小时后，不会自动执行此按钮。
- 关闭每日开关会取消未运行的每日任务；正在调用的正常结束。被暂停的周期重新开启后须显式继续。更改整理模型会暂停活动每日周期，等待明确继续。

冲突识别由整理模型依据原文及最多30条规则相关的有效记忆提出，不是逻辑证明或全库语义校验；没有被模型发现的矛盾仍可能误记。原文引用、版本、撤回及人工纠错保留，不承诺零误记。

## 可选空闲增量整理

默认关闭，可按当前人格显式开启。它只处理开启后新增的成功轮次；保留最近10轮，较早未整理部分累计至少10轮，且前台空闲120秒后才提交，每30秒扫描。

此模式与每日全量不同：候选仍待审，不自动确认。换整理模型会关闭此模式；每日任务优先于增量提交，已失败/取消/中断范围阻塞，需显式重试或跳过。既有历史的手动整理和每日完整扫描不倒退其启用边界。

## 证据、纠错与上下文

原始事件保留。模型返回带版本JSON，逐项引用事件和精确原文片段；伪造ID、跨人格来源、非法类别、超限或格式错误导致整次输出不发布，不额外调用模型修复格式。

候选仅自动提取用户事实、偏好、共同经历，必须有本批用户原文证据，不能只凭人格回复或摘要。关系与世界知识仍显式维护。

确认操作事务写入多来源证据与审阅记录，重复确认不重复建记忆；修订检查预期版本。拒绝候选、修订或撤回记忆会屏蔽旧来源的整个对话轮次（笔记只屏蔽该事件），相关候选和摘要失效。原文仍可查看；同轮其他细节也可能不再参与后续上下文。首版不自动解除屏蔽。

上下文为人格、显式关系、有效正式记忆、本会话有效摘要、最近最多10轮成功对话、本轮消息。摘要不跨会话或入口；正式记忆同人格共享。已覆盖轮次不重复拼入，未覆盖旧历史显示缺口。失效摘要停用，不自动收费补齐。

规则召回使用当前消息（权重3）和最近2条有效用户消息（权重1），最多8条；同分按更新时间和ID排序。命令行记忆搜索仍为字面子串。没有引入向量语义检索。

默认整理输入24000字符、输出2048 token、超时60秒；每批最多10轮。输入过大减少完整轮次，单轮仍过大则拒绝，不截断。累计摘要最多3000字符，每批最多10条候选、每条最多500字符。前台超预算依次移除旧近期轮次、低相关记忆和完整摘要项，核心设定仍过大则明确失败。
