# QQ接口开发暂停政策

生效日期：2026年11月12日。发布主体：PCAR项目作者。

鉴于近期腾讯官方对第三方QQ启动器的限制收紧，作者根据近期使用情况判断，通过NapCat、SnowLuma等第三方启动器或插件接入QQ存在账号被限制或禁用的风险，现决定：**PCAR暂时停止QQ接口开发。**

暂停范围包括NapCat、SnowLuma及其他第三方QQ接入方式的功能开发、适配、专项调试和实际平台验收。暂停期间不自动启动QQ组件、恢复登录、继续收发测试，也不通过更换账号或第三方启动器继续补测。

**后续是否恢复开发，请等待作者明确发布公告或推送通知。** 普通的“继续开发”指令、旧施工计划、历史测试安排或第三方工具更新，均不作为恢复QQ专项工作的依据。

工作台及共用核心能力可继续按项目规划推进。历史QQ代码、文档和验收记录保留供追溯；暂停不等于删除已有实现，也不将未完成的QQ验证改记为通过。QQ相关待办统一标记为“政策暂停”，不再作为当前工作台交付或后续通用开发的必测前置。

本政策更新的是项目开发和验收范围。正式QQ知识能力与QQ组件自动启动继续保持关闭。恢复时应由作者明确新的接入方式、账号范围及验收安排。
