# 新版工作台第三方组件

| 组件 | 本包的使用方式 |
| --- | --- |
| pywebview 6.2.1 | 本地 HTML 窗口宿主。版本与传递依赖在 `uv.lock` 锁定，安装时取得对应分发包。许可证为 BSD 三条款。[许可证](LICENSE-pywebview-6.2.1.txt) |
| Microsoft Edge WebView2 Runtime | Windows 机器上独立安装的渲染运行时。候选 ZIP 包含 PCAR 源码、窗口资源和依赖锁，通过本机运行时渲染。 |
| Kelivo | 桌面组织方式参考。UI 资源及依赖来源见项目登记。[工作台设计参考](../REUSE.md#工作台设计参考) |
| 公开角色检索模型 | 按候选包的模型文件清单和原第三方许可交付。[模型许可](THIRD-PARTY-MODELS.md) |
