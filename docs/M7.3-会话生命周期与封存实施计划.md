## 生命周期与并发

- 独立session_lifecycle与完整Scope活动指针；channel_sessions只作兼容投影。状态active/sealed，旧记录legacy_unmanaged；任务状态不混入会话状态。
- 有效输入、生成终结、投递状态推进更新活动；重复消息、查询、草稿、主题和整理不续期。单调时钟计时，UTC持久化，Asia/Shanghai显示。重启从新的观察起点重新计30分钟，不累计离线空闲、不补造结束事件。
- 每5秒检查，正常负载1800–1810秒封存。collecting/等待容量/中断未处置批次、queued/running、未终结投递及相关hold阻塞封存；显示原因，不能暗中取消或追加收费。
- 新输入和封存事务CAS协调：输入先提交则封存失效；封存先提交则无Session入站新建会话，显式旧Session报session_sealed并保留草稿。重复原请求仍先返回原回执。
- 重开保存continued_from_session_id，不搬迁原文、不隐式扩大召回。封存后拒绝新事件、笔记和原turn重试；需新会话明确重发。切换前处理原活动会话未决工作。
- 旧整轮投递提供管理员放弃审计，保持原账本，不伪造sent；sending不能直接放弃，领取及排队识别处置。

## 封存包与来源

SessionPackage只保存Scope、版本、封存理由、全部有序turn/成员/独立Event、语义回复和实际part清单、哈希、状态、排除原因、元数据缺口及Manifest/设定/政策版本，不复制正文、人设或凭据。工程回放零调用零投递；当前来源重新检验权限/撤回/哈希。QQ仅sent正文为发送证据，resolved不等于sent；桌面generated_only，已读未知。

撤回任一成员使整轮退出证据；主题、摘要、候选和整理预览同步失效。原包/Manifest不改写。包构建在写事务外，短事务复核后原子提交包、封存与触发；数据库失败不得留下半成品。

## 整理、主题与接口

- 每包按类型/版本生成幂等organize awaiting_manual、reflect deferred_m8；无合格来源NO_ACTION。复用M4队列、额度和Reflection Manifest，每次先保存Manifest再调用。
- 先预览来源/覆盖/预计批数，再手动提交本批；最多10完整回合并受字符预算约束，后续批次不自动提交。类型化来源区分Event/实际part，保存引用/hash；候选只由用户输入支持，人工确认，不扩大每日自动授权。
- QQ封存摘要供检查整理，不改变M7.2聊天摘要策略。调用前/发布前复核；同会话重叠整理串行，已覆盖复用，显式或原每日重建另记费用理由；重启未完成任务interrupted，显式继续。
- OrganizationDecisionProvider.evaluate(package_view)返回NO_ACTION/DEFER/PROPOSE_ORGANIZATION；当前固定DEFER/provider_not_enabled，零凭据读取零模型调用。
- 主题段只选同封存会话连续完整有效回合；Thread跨同Scope会话手动关联。标题/说明是人工标注，不是事实。创建/编辑/归档/关联有版本、操作者和operation_id。撤回保留关联但标失效。
- 管理读写显式Scope；写入expected_revision与operation_id、选择冲突、关联双版本检查。沿用/v1/manage增加session.current/list/show/seal/reopen/package/replay/triggers、session.organization.preview/submit及topic/thread管理；旧入口适配，桥接无新增管理权限。
- 工作台“会话与主题”页显示空闲/阻塞、封存/接续、来源/回放、手动整理、主题/版本。历史浏览不更改发送目标；失败保留草稿，切换后拒绝过期响应，引用不串身份。M8明确未启用，不做UI重设计。
