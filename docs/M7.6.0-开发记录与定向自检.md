## 3. 失败与变更历史

1. P01初冻后、首次执行前发现夹具共享字典使跨Scope反例同时改了owner；修正独立Scope，并给人格反事实明确不同虚构身份。原freeze与执行前补记保留，未按成绩改标签。
2. 首次validate/evaluate启动因异常处理语法错误退出，尚未运行场景；修复为标准raise语法，错误记入startup-failure。首次完成的评估32/24全部匹配。
3. 代码复核补齐ASCII大小写位置保持、显式解释观察、记录中的政策指纹及v1政策内容校验；规则字典/评分/标签未变。随后16项定向通过。
4. 外部副作用测试再补强io.open与环境读取拦截，仅重跑对应单项并通过。

规则、夹具冻结及原报告未覆盖删除，首轮/最终记录分别留存。无模型修补、评分或重试调用。

- 触发与权重均人工定义；数值不是置信概率，不能证明真实用户心理、作者长文本编译质量或自然度。
