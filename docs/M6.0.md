# M6.0 角色资料使用说明

运行时0.6.0.dev1、结构7，桥接0.3.0；2026-10-27。本阶段只交付角色系统，整个M6自然交互尚未完成。

## 日常使用

重新打开新版工作台并启动人格服务，选择现有人格，进入“角色资料”。点击“读取角色资料”查看当前版本与资料。姓名、核心特征和基础表达来自原M5版本，可通过页面入口编辑；扩展资料不会另存一份姓名/性格。

点击“编辑角色资料”，在“基本资料”中填身份、年龄、外貌、背景、兴趣、社交和世界。未知项留空，列表每行一项；身高单位厘米、体重单位千克。生日格式MM-DD，出生日期YYYY-MM-DD。年龄未设定/固定/随现实增长三选一；随现实增长必须完整出生日期，按上海日期计算。

“设定书”页可新增/编辑/启停/删除人物、地点和事件背景，填写字面关键词、优先级及依赖条目。取消“允许在聊天中使用”后仅创作者可见。循环、缺依赖和公开条目依赖私密内容会拒绝保存。删除被依赖条目前先解除依赖。

“表达样例”填写情境、场景关键词和示例，启用后按当前消息匹配。首版人工管理，不自动学习聊天。条目“加入角色草稿”不等于写入服务；最后点击“保存角色资料”才产生版本。

保存失败不会清空输入。版本冲突时先查看服务器当前资料，再选择重新读取或手工调整草稿；重新读取会确认是否放弃草稿。保存中禁止关闭/改动，成功后可继续编辑。离开页面、切换人格或关闭主窗口时需先处理草稿。

## 版本与预览

“版本与预览”→“读取版本历史”，选版本可查看、比较或恢复。恢复建立新版本，仅恢复角色扩展，不回退M5核心、关系、记忆、历史或状态。当前名称/表达需在各自M5编辑器单独处理。

在预览输入框输入“你多高，书店那位朋友呢”，点“预览设定激活”。结果包含实际版本、精确字段、激活条目/样例、预算排除和未命中原因，不调用模型、不创建事件。预览是创作者管理工具，会展示将注入的数据；creator_only内容不进入激活结果。

普通聊天只注入相关资料。角色总额≤3000字符，并受总模型输入字符上限约束；精确事实优先，可选背景/样例可被裁掉。设定不是现实共同经历，空值不是允许模型随机补齐。

新请求受理即固定角色版本，修改资料不改变已排队请求。显式重试采用当前版本并保留旧调用记录；旧历史没有角色快照时保持未使用角色扩展。

## 导入导出和数据

“导出角色包”写入D盘exports，只含当前PersonaSpec和角色扩展，不带私人经历或凭据。“导入为新角色”只接受原生JSON包，创建独立身份，不覆盖现有角色、不继承聊天和关系，也不自动切换当前身份。需自行在人格列表选择。

现有“导出人格数据”为完整私人导出，格式4，包含旧字段与角色版本/指针；它与可分享的角色包不同。导出/备份可能包含私人数据，保留在D盘，不提交Git。

数据库升级前备份，结构6→7会为旧人格创建空扩展，不自动解析旧背景。旧软件会拒绝新结构；回退软件前应恢复升级前一致备份。新增头像、多模态、外部卡、联网、缓冲、自动情绪和演化均未开启。
