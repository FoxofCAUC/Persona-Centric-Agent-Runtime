## 作者操作

1. 打开“角色资料→人格倾向”，读取当前身份和来源。原“基本资料”仍是默认入口。
2. 选择作者来源，查看原文；来源在每次展开时重新核验。点“编译所选来源”前确认正文数量与一次调用提示。
3. 查询编译状态，完成后重新读取草案。失败不自动重试；旧操作号查询返回原结果，不重复收费。
4. 选草案项，用表单修改标签、优先级、启停、触发和动作权重；“来源定位”重新核验并展示引文。不支持的新事实先回权威角色资料编辑。
5. 保存草案后集中确认。收集批次必须明确封存/取消；版本冲突时保留草稿，重新比较。空集合确认是清除投影。
6. 按入口保存baseline或shadow。未配置不会凭空生成倾向；source更新后needs_review，重新编译/审核。明确撤回立即阻止后续使用，历史仍可审计。
7. 输入人工文本预览，或检查已有请求的决策记录及Manifest。预览不生成聊天、不写事件或调用模型。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| not_configured | 没有经确认的有效定义，不能说已有有效人格决策 |
| ready | 来源与确认版本有效 |
| needs_review | 作者来源版本更新，新请求不自动移植旧定义 |
| withdrawn / source_unavailable | 投影撤回或来源资格变化，不再使用 |
| observed | 此次Shadow计算并记录成功；applied_to_prompt仍为false |
| timeout / busy / snapshot_invalid | 本次未得到可用观察，原M7继续 |
| record_failed | 独立审计写入失败；Manifest显示未持久化，健康报告缺口 |
| interrupted | 编译中断，未知费用不自动重放 |

有观察记录不代表已兑现安慰/解释等交流策略；主模型的behavior_intent另列。有限中文规则不是心理诊断或通用情境理解。

## 开发与诊断

生产内核在persona_runtime/disposition_core，不引用实验目录。disposition.py负责权威来源和确认，disposition_compile.py负责一次编译，disposition_shadow.py负责150毫秒准备及保存点。服务端保持已有M7权限与主要调用合同。

定向：`python -B -m unittest tests.test_m761 tests.test_m761_api tests.test_m761_desktop tests.test_provider_deadline`。副本工具verify_m761_migration.py拒绝覆盖旧证据；性能工具measure_m761_shadow.py只用人工隔离数据。真实编译工具只在显式人工资料与既有授权内执行，每次操作落账，已有槽不重放；结果仍需审阅，不能把工具自动测试作者确认当作日常作者授权。

编译传输复用选择模型的文本协议，服务端严格解析完整JSON；不强加额外网关json_schema能力，不展示原始坏输出或模型思维。编译TLS使用已锁定certifi公开CA证书，仍验证证书与主机名；不改系统信任、安全设置或既有供应商/密钥。参见[aiohttp官方说明](https://docs.aiohttp.org/en/stable/client_advanced.html#example-use-certifi)。既有M7聊天传输路径保持。

本轮验收次数限制已按用户追加指令移除，但不自动循环补跑，不修改正式运行额度，不放宽单调用60秒和连续失败暂停规则。真实证据、数据库、凭据及引文留D盘。
