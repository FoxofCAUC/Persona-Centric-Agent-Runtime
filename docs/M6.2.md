## 已实现范围

- `legacy_full`、`context_full`、`context_structured` 三种版本化回复策略，按受理时策略固定到输入批次和 turn。
- 本地 `behavior_resolver_v1` 词法线索最多提供两项弱提示，不增加模型调用，不推断情绪或用户状态。
- 角色表达样例可按情境线索选择，并记录规则、样例和角色版本追踪信息。
- 结构回复严格校验 1–3 段、白名单字段、格式、单段/总长度、重复 JSON 字段及代码围栏；不修复、不自动重试。
- 回复完成时原子保存完整回复、语义段和用量；验证失败时保留用量、给出明确失败状态，原始 JSON 不作为回复事件。
- 管理员版本化设置接口与工作台选择；桥接令牌无权更新回复策略。
- 数据库结构9从结构8事务迁移；全量导出格式6包括结构回复记录并排除凭据。

## 使用限制

所有入口默认仍是 `legacy_full`。切换只影响随后受理的请求。结构化段在本阶段仅作语义记录，桌面/QQ仍使用既有全文投递；不能假设各段独立送达或可单独重试。情境词法规则只是提示，不应被解释为对用户的心理判断。历史请求不补造回复策略快照。

正式服务仍保持停止，结构9未正式部署。不得以当前离线通过推断真实模型自然度、正式迁移恢复或 QQ 平台送达。
