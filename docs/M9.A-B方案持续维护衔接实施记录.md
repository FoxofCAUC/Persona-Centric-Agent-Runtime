# M9.A B方案持续维护衔接实施记录

2026-11-12，承接用户“继续任务”。本轮完成网页资料与既有增量维护的连接，以及工作台代表真实验证；最终候选为 `0.9.0.dev22`。正式日常仍为 M8.E，本轮没有 QQ、正式迁移或提交推送。M9.A 联合验收与 .6 正式接入尚未关闭。

## 实现范围

- 新角色的维护职责默认复用主模型配置，读取与学习仍分别授权；已存的旧维护策略没有 `model_source` 时继续使用记忆整理模型。Jev 保持独立受保护配置。界面显示实际配置来源，不把知识整理一概称为记忆整理。
- 获准且实际读取的中文 Wikipedia 修订页面，自动登记为本角色的按需维护目标。每日协调补登记既有网页，并复查该角色最近使用的最多 100 个目标；沿用每批最多 5 份及现有队列、租约、预留、回执与恢复。显式查证／人工请求优先于按需请求，按需请求优先于每日扫描。
- 后台从原站取得实际版本正文，再以主模型分别提取、独立复核。新主模型提取协议提供 500 字符原文窗口，程序按窗口 ID 绑定逐字引文，避免重复传入正文与抄写错误。已完成的同正文版本复用原处理结果；成功或效果未知的逻辑位置不重新收费生成。
- 新增角色归属过滤，防止共享页面导致另一角色复用未获准的任务或主张。抽取旧事实、保留片段、每日目标和查询均受归属及现行来源政策约束。
- B 路径在普通快照问题中先找新鲜的增量事实，再选材、翻译、独立复核并注入主回复。资料不足时继续原联网流程。Jev 只接收匹配主题、属性、来源名称提示，不接收事实值；该提示不替代正文证据。这里是业务增量库，不是已删除的 ANN 百科。
- 明确要求当前／最新信息仍走上游查证，不以普通事实缓存代替。首版自动衔接限精确修订的中文 Wikipedia；其他原生 Fetch 网页没有被假装成可自动维护的 Wikipedia 文档。
- 观察到较新上游版本即停止旧主张及旧网页回答，等待新正文处理；更正、撤回同时约束历史回答、出处、缓存与恢复。旧备份不能将已知新修订降级或覆盖当前撤回。内容不变的新版若被撤回，旧提取结果也不能借内容复用重新进入回答。
- 撤回后的上下文保留当前角色仍获准的用户原问题，隔离旧助手答案，并明确传递“原资料不可用”状态；用户明确排除的原问题仍不保留。
- 冲突资料逐项保持 `unresolved`，包括单独归属某一来源的转述。新提示约定进入任务输入与缓存身份，程序的冲突拦截条件保持。

不重建本地百科、模型权重或原生检索组件；开发五项自动次数额度继续均为 0，费用、自动身份及有限故障重试保持。P95 只记录，不设验收上限。

## 真实来源与模型结果

两组使用全新隔离角色和真实主模型、真实 Jev。未复制正式聊天、私人人格或备忘录。模型与来源读取分别留账；每日协调采用维护时钟偏移，物理请求时间另外保存，不冒称已经真实运行数日。

| 场景 | 实际结果 |
| --- | --- |
| 首次问“光年是时间单位还是距离单位” | 实际取得中文 Wikipedia 正文，注入真实主请求；产品自动登记目标并完成主模型提取和独立复核 |
| 新会话问“光年用来衡量什么” | 使用已维护 `knowledge_claim`，正确回答距离／长度单位，无新增来源读取 |
| 模拟下一日复查 | 产品协调器读取同一页面，内容未变，新增来源执行 1 次，新增提取／复核 0 次 |
| 隔离环境本地撤回光年资料 | 初次网页回答和增量事实回答同时退出；未修改 Wikipedia 上游 |
| 撤回后出处追问 | 原回复安全但误说“没有上下文”；修复后新位置明确说明旧出处不可用。原回复原样保留 |
| 撤回后的普通告别 | 正常回复“晚安，回头再说。”，无来源及学习调用 |
| 虚构公告 A 初版 | 实际 HTTP 读取人工公告，真实模型提取／复核后回答 10:00 |
| 公告 A 改为第 2 版 | 产品每日协调自动取得新正文、提取／复核；新回答为 11:00，旧回答被拦截 |
| 独立公告 B 说 12:00 | 两份来源形成冲突；原翻译分类未满足合同而失败，保留原失败。新位置准确回答 A 为 11:00、B 为 12:00，没有擅自裁决 |
| 公告 B 明确撤回 | 产品下一轮协调处理撤回；旧冲突回答被拦截，新回复只采用 A 第 2 版 11:00，当前冲突清零 |

两份公告由本机只读 HTTP 测试源提供，明确记录 `controlled_http_fixture`，来源名称及修订地址均为测试源，不伪装为真实百科。初始公告目标通过管理入口登记；后续读取、派发、提取、复核、提交和每日维护由产品调度完成。程序没有注入主张、替模型填写复核意见或强制 Jev 选路。

最终实际冲突回复：“两份虚构验收公告说法不一致：公告A称每天11:00开放，公告B称每天12:00开放。两者相差一小时，现有资料没有说明哪个为准……”撤回后回复：“根据受控验收公告A（第2版），受控验收灯塔每天11:00开放。”
