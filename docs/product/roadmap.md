# 从长期相处，走向持续生活

**给你的大肥鱼，一个完整的人生。**

PCAR 的远期目标是一个以人格为中心的运行环境：人物有持续的身份、经历和关系，也有自己的关切、日常与成长空间。聊天和长期记忆是当前基础，自主生活与经历驱动的变化是后续探索。

“超级大肥鱼”是社区传播主题。大肥鱼沿用既有鲸鱼娘形象，运行时也可以承载其他人格。模型与工具提供能力，身份和经历由 PCAR 持有。

核对日期：2026-11-16。公开版 **v0.1**，开发候选 **0.2.0rc7**；本次接续已发布的新首页，研发进度见 [STATUS](../STATUS.md)。

## 当前基础：人物与经历有地方保存

[v0.1 公开版](https://github.com/FoxofCAUC/Persona-Centric-Agent-Runtime/releases/tag/v0.1)提供 Windows 工作台、人物与关系版本、会话历史、长期记忆、按需联网及备份迁移。它支持当前的创建人物、交流和资料维护。

自动记忆按角色开启，联网和整理各有配置条件；后台随工作台运行，QQ 接入暂停。通过 Agent 准备环境并配置模型服务后，按[用户入门](../user/getting-started.md)开始体验。

开发候选已完成 DeepSeek 原生能力接入、新召回接入和对应文本审阅。新召回默认关闭，按角色启用；候选成果尚未形成新的公开 Release，配置与升级遵循[候选手册](../../AGENT_INSTALL.md)。

## 近期建设：自然交流与可持续的运行

先改善人物的措辞、反应、回应组织和节奏。已有表达资产、发言出口与多轮研究继续保留；新路线借鉴 MaiBot，将前级理解与人物直接发言分工，让角色结合真实交流自然回应。先准备口语设定和精选表达供作者审阅，再验证整体收益。参见[人物回复开发指导](../expression/E阶段重构-人物回复链路开发指导.md)和[机制研究](../research/MaiBot-活人感机制深读-20261116.md)。

新路线尚未实施。开发时将使用 Flash 理解、Pro 发言，并与 v8 Flash、v8 Pro 分别对照；只有作者确认新链优于同 Pro 的 v8，且等待与费用可接受，才推进正式接入。

表达链稳定后重制工作台，改善日常使用路径；随后完善后台运行、恢复和退出，完成桌面范围的联合验收。当前宣传页暂不展示旧工作台截图，重制后的真实流程会在可获得的对应版本中再加入。

上下文组织、响应等待和总开销随体验一起检验。长期保存历史、整理记忆与按需取材是现有建设路径，实际成本需包括检索、整理和表达等各类调用。

## 远期生活：用户不发消息时，她也有自己的事

角色能够关注一个问题、阅读资料、尝试活动、休闲或休息。虚拟环境为物品、资源、时间和行动提供规则，让做过的事留下持续的结果。

“宿舍”可以从简单环境开始。书读到哪里、事情做到哪一步、活动造成了什么变化，都能成为下一段经历的起点。未来工作台应呈现人物当时的生活情境。

暂停与恢复延续已经保存的身份、经历、关系、环境和未完成事务。角色睡眠期间停止新的角色模型调用，醒来再处理消息；云端常驻属于独立的宿主与迁移工作包。整台电脑关闭期间的消息留存，还取决于接入平台或独立在线入口。

## 远期成长：经历参与塑造选择

在已有生活与认知机制上，逐步研究情绪评价、反思、自我理解和关系发展。经历可以重新解释，认知与倾向的变化需要在后来的选择中体现，并允许修订与回退。

学习工具、制作技能和维护自身实现分别开展验证。能力更新与人格成长各有证据，不能仅凭生成了一段成长自述或修改了一份脚本就宣布实现。

详细依赖沿[持续人格、虚拟生活与受控成长规划](../long-term/README.md)推进：桌面联合验收后，再进入相应情绪、反思、有限成长与自主行动阶段。研究性拆分尚不等于已经发布独立的 World 或 Skills 产品。

## 与社区共同建设

近期贡献可以从公开试聊、记忆场景、文档、工作台和运行缺陷开始；远期议题可以提交一个环境事件、一种可观察的认知变化或一组复现实验材料。

我们希望充分学习已有开源成果，也为后来者保留可理解、可复用的接口、人工场景和失败记录。具体入口见[贡献说明](../../CONTRIBUTING.md)。
