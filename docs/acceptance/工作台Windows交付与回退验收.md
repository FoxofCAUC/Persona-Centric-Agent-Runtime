# W5 Windows 候选与升级回退验收

2026-11-19。新版候选程序版本 0.2.0，数据库结构 33。旧版对照使用核对 SHA-256 后解压的 v0.2 发布包。演练从旧版准备的独立实例开始，使用既有公开模板和数字标识。发布包、试用实例和另一窗口的聊天记录导入研发各自独立。

## Windows 启动

- 保留旧版和新版 BAT。新版首次打开已有实例时检查窗口依赖。已就绪时直接启动。需要补齐依赖时取得实例锁，按 `uv.lock` 准备。v0.2 发布环境实测原依赖版本保持一致。实例运行期间会提示先退出。
- 结构 33 同级回退切换程序目录，继续使用同一数据目录。候选自带的旧版入口和独立 v0.2 发布程序都参与演练。[试用与回退操作](../user/新版工作台-Windows试用与回退.md)
- ZIP 保留窗口资源、依赖锁、公开检索模型、许可证与文件清单。SHA-256 校验值随 ZIP 交付。[窗口依赖及许可](../licenses/THIRD-PARTY-WORKBENCH.md)

## 工程与实际窗口验收

| 路径 | 核对内容 |
| --- | --- |
| v0.2 → 新版 | 在含中文和空格的路径依次启动。原实例补齐 pywebview 6.2.1 后继续使用原配置。核对原有依赖版本、结构 33、人物身份、会话、历史和记忆。 |
| 新版 → v0.2 | 新版界面编辑人物、添加设定与带来源的记忆。退出后用原 v0.2 程序读取该人物同一版本、设定和新记忆，随后在旧运行时修订记忆。 |
| 再次打开新版 | 新版读回旧运行时修订的记忆，恢复原会话草稿。核对两个角色共 73 个旧回合、SQLite 外键和结构版本。主会话的回合标识、顺序与内容摘要一致。真实模型调用为 0。 |
| 生命周期 | 新版进入托盘后，用候选中的旧入口唤回同一窗口。新版、候选旧入口和发布版分别验证配套服务的释放。 |
| 交互与可读性 | 在 Windows 150% 显示缩放下检查长历史翻页、切换人物后的阅读位置、宽窗、窄窗抽屉和弹窗焦点。用 WebView2 中文输入合成检查回车确认候选词、留在草稿和零提交。页面布局另模拟 100%、125% 和 150%。 |
| 空白实例 | 从最终候选的解压目录双击启动，进入首次引导。关闭后核对模型凭据缺项、业务表为空和组件释放。 |

47 项工作台测试及 116 项关联测试通过。W4 记录的结构 20 迁移测试已修正其构造方法，改用真实结构 20 的临时库验证升级与回执保留。
