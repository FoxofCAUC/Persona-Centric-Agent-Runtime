## 权限、额度和取证口径

- 隔离实例的日常自动调用采用有限额度。全项目 300 次/小时，后台 60 次/小时且 240 次/24 小时，选择与理解 300 次/小时且 2,000 次/24 小时。额度专项另建有限额度实例，用自然跨窗验收。真实模型连续第 5 次失败时停测保存断点。测试调用逐笔按缺项记账，已成功或结果未知的物理调用沿原证据核对。
- 双人建卡内置资产 `pcar-import-prompts-v1` 的 SHA-256 为 `72aa23bcda484a474c746e8634b0601b8fb8e43f266677e3ec851d5e36e97df6`，用途沿已批准范围。阶段 0 用公开迁移样本、数字标记和本地替身。真实长稳的聊天材料、发言角色、用途、模型配置按作者批准版本在入场时登记。Flash 单独登记模型可见材料、作用域、动作和额度。
- 每项证据带场景编号、提交与包指纹、版本和授权、实例及人物/会话、原请求与回合 ID、物理尝试与回执、起止状态、时长、干预、费用及结果位置。观察节点依次为发送意图、持久受理、批次关联、出站与回执、业务结算、实际可见和呈现回执。模拟、历史证据、真实模型和作者体验各用对应证据签收。
- 管理介入从首次配置完成起算。日常发送、取消、正常纠正和新授权单独记录。手工点继续、重建、解锁或改库，以及测试代理代点管理入口，都算管理介入。
- **硬门零违规。** 已受理消息静默丢失、成功或结果未知的物理调用重放、虚假或重复呈现、串角色或会话、撤回后继续取材、越权越额、错误释放其他实例、维修无限锁窗，任一例即退回责任包。有用恢复须由原任务结果及下一条聊天共同证明。
