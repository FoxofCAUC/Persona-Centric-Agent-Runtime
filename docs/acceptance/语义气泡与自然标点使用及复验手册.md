# 语义气泡与自然标点使用及复验手册

本手册对应候选表达政策3，不代表正式启用。先读[当前结论](语义气泡与自然标点验收结论.md)及[施工计划](../语义气泡与自然标点更新实施计划.md)。

## 前置条件

审阅前仅打开隔离运行目录工作台，不能用默认正式目录启动候选代码。核对候选 dev7、结构18、桥接0.7.2，通用测试人格与专用 QQ 测试账号。私有原体禁止试聊，副本不参加真实 QQ。

## 零调用检查

1. 打开“输入与缓冲”，选择入口。确认滚动五秒政策2与表达政策3分别显示，回复模式仍 natural_structured，其他检索设置不变。
2. 有收集中批次时选择封存或取消后再切换；版本冲突时保留草稿，不覆盖当前版本。
3. 打开“回复投递”的预览，选择 model-bubbles-v1。输入通用六项 v3 数据，确认六泡、合理逗号未拆、计划等待正确；普通预览零模型调用。
4. 检查十三项整批失败，错误元数据可安全回退时保留每项且均不可取消。损坏正文拒绝，不发送半批。
5. 历史详情核对语义、展示、传输与哈希；旧 v1/v2 仍三项、旧平台记录不改。

## 真实窗口与 QQ

窗口固定八类输入已冻结于本机台账。恢复先查旧回执和实际调用日志，成功样例不重放；有工具调用前失败的记录与真正网络失败分开。

QQ 仅在机器确认监听与身份之后，用测试账号发送普通聊天。建议类输入及连续补充均不得附加分条、标点、纯文本等提示，不写工程编号。每条输入只发一次。通过需核对完整成员、一次主要调用、v3 原生分泡、实际文本及平台 ID；界面看到生成不等于已发，更不等于已读。

机器分别检查内容完整、气泡组织、自然标点、原始质量、展示安全。普通末尾句号被清理仍记原生成问题；逗号正确保留不算失败；>50 字只提醒审阅。

## 用户集中审阅

本机预览列出所有样例及失败，左右对照原生成和最终展示，附长度、转换和人工分析。请重点判断独立意思是否堆叠、是否拆得过碎、逗号是否自然、短回应是否被凑长，以及条件/事实是否完整。认可前不升级正式私有人格。

## 部署与收尾

全部门通过并获认可后，排空、持锁备份、迁移18；自然入口追加表达政策3。新建/导入/复制采用新默认，兼容模式不强改。回收站身份仅维护不复活。原文学/关系/历史逐项核对，正式身份零收费试聊。

恢复原账号、人格选择、额度、每日整理、启停初态，仅保留新表达政策。数据库回退配套结构17备份，先保全期间新数据。临时私有副本必须停服、校验删除范围后清理。
