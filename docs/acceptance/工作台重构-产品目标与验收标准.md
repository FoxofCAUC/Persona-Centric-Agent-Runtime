# 工作台重构产品目标与验收标准

2026-11-19。本阶段从已正式部署的 E.N6（0.2.0rc9／结构 33）接续，完成工作台重构后进入无人值守收尾与桌面 G-AUTO。[本机部署及接续](../HANDOFF.md)

## 产品目标

**从开发者友好转向用户友好。** 把工作台做成普通用户能自然上手、愿意日常打开的 Windows 桌面产品，达到成熟消费级软件的交互和视觉完成度。按用户要完成的任务重整操作流程、页面层级、默认值和反馈，建立适合长期聊天的统一视觉设计。交互逻辑与美术设计的验收地位和工程质量相同。[原始工作台简化规划](../后续演进想法与实施顺序-20261109.md)

- **首次使用和日常操作。** 基础界面提供模型连接、人设导入与选择、聊天、自动记忆、可用状态、托盘和退出。用户能从当前页面判断下一步，并在配置或导入失败后继续操作。
- **聊天与高级设置。** 聊天区突出人物交流，正常呈现查找前的人物发言。常规系统进度、模型阶段、费用、日志和精细参数在高级设置按需查看。基础界面与高级设置使用同一份配置。聊天区保留简明的失败反馈和结果核对入口。[人物回复链路开发指导](../expression/E阶段重构-人物回复链路开发指导.md#53-正式接入及工作台)
- **视觉完成度。** 统一聊天、会话列表、人物入口、设置和弹窗的字体层级、间距、色彩、图标和控件状态。让主次操作一眼可辨，中文长聊容易阅读，窗口在空白、等待、出错和内容较多时都保持清晰。人物形象沿用项目已核对的素材来源。[品牌与素材约定](../product/readme-maintenance.md#2-保持的产品与设计约定)

[工作台终端交互定义](../product/工作台终端交互定义.md)细化新手引导、每日聊天、消息状态和恢复操作。后续原型与交互验收沿这些实际使用路径展开。

## 阶段验收

**交互逻辑、美术设计和工程质量均须通过，工作台重构方可结项。** 原型可用于评审交互和风格，最终验收使用实际运行的 Windows 窗口。

| 验收项 | 通过表现 | 验收证据 |
| --- | --- | --- |
| 交互 · 首次上手 | 一位首次使用新版的目标用户能自行完成模型配置、人设导入与选择、首次聊天、开启基础自动记忆和正常退出。排障时能找到高级设置并返回聊天。 | 实际操作记录，写明发生停顿、误操作及需要帮助的位置，复验修复后的路径。 |
| 交互 · 日常与异常 | 切换人物或会话、查历史、发消息、打断和重开都有明确反馈。常规等待、失败和待核对结果容易区分。用户知道如何继续或查证，中文输入法选词时回车保留输入法行为。 | 实际窗口覆盖常规对话、等待与打断、失败或待确认、重开恢复。保留状态和操作结果。 |
| 美术 · 整体与细节 | 窗口、导航、消息、表单和弹窗采用统一的视觉规范。主操作、正文和次要信息层级清楚。字体、色彩、图标、留白及选中、焦点、禁用和错误状态经实际窗口评审，符合陪伴产品的视觉定位。 | 同类场景的实际窗口截图或短录屏，附设计规范、评审结论及修正记录。 |
| 美术与交互 · 可读性和操作 | 在常用尺寸、最小支持窗口和目标 Windows 显示缩放下，主要操作可达，长中文内容可读。键盘可完成主要路径，焦点清楚，关键状态有文字或图标辅助识别。 | 记录实测尺寸、缩放和键盘操作结果，抽查长会话、对话框和高级设置。 |
| 工程 · 运行和数据连续性 | 从日常入口启动，正常收起到托盘并退出所属组件。逐泡呈现、取消、人物与会话隔离、旧历史读取、重启恢复和配置存取通过关联回归。后续对话接续已确认显示的内容，未知结果可以按原记录核对。 | 按 [E.N6 呈现与回退约定](../expression/E.N6-场景发言接入与回退.md) 和 [分级验证原则](../开发验证与验收分级原则.md) 保留回归、运行及恢复证据。 |

由目标用户操作首次上手与日常路径，作者审阅实际窗口的视觉完成度。使用隔离实例及适用于该用途的已获准材料保存界面证据。报告逐项记录通过、待复验及证据位置。

## GitHub 开源项目参考

2026-11-19 核对项目说明、示例和适用许可。现有工作台使用 Python/Tk。候选库以同一组用户操作的完成质量、Windows 打包与运行成本比较。

| **WinUI Gallery** | Windows 桌面交互参考。查看导航、自适应布局、窗口、对话框和可访问性的可运行示例。示例仓库采用 MIT。 | [WinUI Gallery](https://github.com/microsoft/WinUI-Gallery) |
| **PowerToys Settings** | 真实桌面应用的设置参考。看常用入口、功能分组和详细设置如何组织，以及标题栏和控件资源如何统一。仓库采用 MIT。 | [PowerToys 设置界面](https://github.com/microsoft/PowerToys/tree/main/src/settings-ui/Settings.UI/SettingsXAML) |
