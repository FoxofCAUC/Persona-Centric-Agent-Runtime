## 工作台步骤

1. 打开“会话与主题”，核对人格、desktop/qq及Bot/联系人，读取列表，选择会话后“查看状态”。此处选择不改变聊天发送目标。
2. “只读回放”核对全部输入成员、生成文本与sent片段区别、覆盖缺口；此操作零调用。
3. “封存会话”提示旧会话只读；有输入或投递阻塞时跳转对应页面处置，不能强行假定送达。
4. “查看触发”：整理awaiting_manual，反思deferred_m8；无有效来源no_action。没有自动调用。
5. “新建接续会话”应生成新ID，旧包不变；跨会话开关不自动打开，旧引用清除而聊天草稿保留。
6. “整理预览”核对来源、已有覆盖、剩余回合，再“提交本批整理”。仅本批进入原M4队列，继续下一批须明确操作；记忆候选待审。
7. 从回放列表选择连续完整回合，填写标题/说明，“新建主题段”。新建Thread后分别查看两个版本，关联/解除关联；归档或修改仍保留历史，不能改变原文。
8. 切换人格/入口/目标，旧响应不能覆盖新页。失败保留标题、说明与聊天草稿；旧会话发送报session_sealed。
