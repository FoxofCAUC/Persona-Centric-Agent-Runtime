## 已实施范围

- 两种整理来源格式共用冲突解析：标准 ID 字符串保留；严格核验 `{id,quote}` 的作用域、版本、状态和冻结引文后，确定性转换为 ID。未知字段、错引文、过期或撤回来源仍拒绝，整批发布保持原子性。
- SQLite 结构 21 新增本地整理回执表。原始响应、哈希和转换位置留在运行数据根；用量先于内容发布独立保存。任务详情提供诊断，不把正文写入普通日志。
- 摘要预览及详情显示实际覆盖缺口；有缺口的默认追加要求显式重建。明确指定后续范围可以继续采集，但摘要标记“覆盖不完整”，不把范围上界冒充完整覆盖。
- 相关待确认冲突携带有效用户原文进入上下文；批准必须指定当前目标及版本，复用记忆替换、旧摘要失效流程。生产冲突仍需人工确认。
- 插件 v2 只在其独立虚拟人格目录模拟审核：唯一有效目标、明确用户更正、模型实际候选原文，不读取评分答案编造记忆。真实小批先保留待确认分支，之后批准并重启复查。
