# W4 工作台首启与人物操作验收

2026-11-19。基于已认可的工作台 Demo 和 W3 桌面消息链路，接续首启、人物和基础设置。可用「体验演示」在同一窗口查看原型。

## 试用路径

- **首次使用。** 在聊天区任选「新建角色」或「配置连接」。两个步骤就绪后选择「开始聊天」。已有桌面会话可直接打开，缺少连接时可从聊天区补配。
- **模型连接。** 首次引导、应用菜单和聊天的连接提示共用同一张表单。基础设置使用官方 DeepSeek 地址和项目支持的聊天模型。已存密钥只显示状态，新密钥遮挡输入，清除需用户确认。保存只更新本机配置。真实测试使用原有探针，确认页说明可能计费，受理未确认时可核对同一请求。
- **新建角色。** 人物身份、性格和边界、表达习惯共用一张表。相处关系、固定年龄、外貌、兴趣和世界背景可选。支持已有 PersonaSpec JSON 和 PCAR 角色包 JSON。文件先进入本地预览，修改并确认后才创建独立人物。角色包只带入设定和补充资料，沿用原有可见范围。
- **人物资料。** 浏览其他人物时可以查看设定和历史。选择「设为当前人物」后可编辑设定、表达、关系、临时状态及扩展资料。新增设定可设为仅作者可见或允许聊天参考，表达样例由用户填写并主动启用。版本历史支持逐项比较和恢复，恢复形成新版本。遇到并发修改时可核对最新版，继续保留表单中的填写。
- **记忆与运行状态。** 可选择当前桌面会话里的消息或笔记，录入并查看其来源，之后可修订或撤回。自动记忆沿用当前角色的整理授权和独立连接设置。高级设置先提供本机服务、连接和待处理状态，备份和维护沿用旧版入口。

## 本机验证范围

- 在含中文和空格的路径解压，通过 `启动PCAR-新版.bat` 打开真实 WebView2 窗口。空实例完成首启、进入聊天、人物编辑与记忆管理。角色 JSON 通过窗口的文件选择入口预填。两次启动之间核对人物、会话、补充资料和密钥状态，退出释放所属服务。
- 在实际界面核对必填反馈、密码遮挡、取消真实测试、清除密钥、版本冲突保留草稿、补充资料可见范围及版本恢复。检查宽窗、窄窗侧栏和对话框布局。
- 43 项工作台回归通过。关联回归 99 项中 98 项通过。历史结构 20 迁移测试在干净 `e04c062` 基线同样失败，其测试数据仍保留后续版本的 `proactive_policies` 表。
- 验收使用隔离数据和既有模板或数字标识。模型调用和计费尝试为 0。API Key 的实际可用性通过用户自选的真实测试确认。
