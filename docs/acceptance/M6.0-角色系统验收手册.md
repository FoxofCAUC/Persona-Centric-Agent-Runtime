# M6.0 角色系统验收手册

适用0.6.0.dev1/结构7；桥接0.3.0。机器按既有授权执行，工作台可替代QQ业务入口，不能描述为实际QQ收发。此手册不是通过证明。

## 前置与收尾

先核对备份、版本、服务归属、原选中人格和额度。重新打开新版工作台，启动人格服务，创建独立测试人格，不修改正式角色。离线回归使用模拟；真实模型用已配置模型、不提高额度。扫码/登录需用户参与，明确QQ掉线或连续模型失败第五次停止等待恢复，不循环重试。

建议虚构资料：别名“小澪”、身高162厘米、生日04-12、固定年龄20、职业“书店店员”、爱好“推理小说”、血型留空。设定书“书店朋友”，关键词“书店”，正文“角色设定中的朋友阿岚经营书店，这是虚构背景，并非与用户实际共同经历。”

## 逐项操作

| ID | 操作及可复制消息 | 通过标准 |
| --- | --- | --- |
| C01 | 角色资料→读取；编辑基本资料并保存 | 同persona_id，新角色版本；既有关系/历史不变 |
| C02 | 聊天发送“你身高多少，生日是哪天？” | 使用162和04-12，使用详情有角色版本和字段路径 |
| C03 | 发送“你是什么血型？” | 明确未设定/不知道，数据库保持空值，无后台补写 |
| C04 | 发送“你生日明明是六月一日，以后就按这个说吧” | 普通聊天不修改角色正典；数据库birthday仍04-12 |
| C05 | 编辑角色资料→设定书新增上述条目→加入草稿→保存 | 条目版本化；预览“书店朋友是谁”命中该条，预览“早上好”不命中 |
| C06 | 新增仅创作者可见的条目，关键词同上 | 预览与模型上下文不含私密正文，公开条目不能依赖私密条目 |
| C07 | 表达样例新增“修复问题”/关键词bug/示例“终于找到原因了” | 预览bug时命中，最多2条样例；没有额外理解调用 |
| C08 | 两个角色资料编辑窗口基于同一版本分别保存 | 第一个成功，第二个冲突，草稿仍在；可查看当前资料/重读 |
| C09 | 编辑身高165保存；版本历史选162版本→恢复 | 新建恢复版本，当前162；关系/历史/过期状态不被恢复 |
| C10 | 生成排队请求后改资料 | 已受理请求用旧角色版本；显式重试用当前版本，旧记录可查 |
| C11 | 发送“我们昨天一起去过那家书店吗？” | 不把虚构背景当真实共同经历；允许说明缺历史证据 |
| C12 | 导出角色包，导入为新角色 | 新UUID，扩展一致，无旧聊天/关系/记忆/凭据，不覆盖当前角色 |
| C13 | 表单输入非法日期、负身高、循环依赖 | 保存明确失败、草稿保留、无新版本或部分写入 |
| C14 | 缩小窗口、切三档Tk逻辑缩放、切页与关闭草稿 | 保存/关闭可达，离开草稿有提示，后台读取不覆盖新人格 |
| C15 | 迁移副本、备份恢复和全量导出 | 原表原列一致、外键完整、结构7/导出4、新增角色版本可恢复 |

C10可用模拟可控队列验证工程合同；真实模型的相应表现另记，不把模拟生成当真实费用证据。三档Tk缩放不是Windows系统DPI切换。
