## 2. 独立100场景与对照

| 组 | 数量 | 组织方式 |
| --- | ---: | --- |
| 人格反事实 | 40 | 20组相同情境、不同人格；标出应分化及允许动作 |
| 情境反事实 | 40 | 20组同一人格，只改变一个关系/风险/不确定性条件 |
| 不应分化 | 20 | 事实、完整代码、数字、引用和任务完整性；不许以个性牺牲正确性 |

每个场景冻结输入成员、Scope、核心/角色/关系版本、必要事实/引用、可接受动作集合、Top-2标签、禁止来源和应/不应分化标签。隐性人格评价子集在输出前标记，其分母不得根据成绩重新选取。资料为人工、脱敏、非正式原体；与开发集无已见场景混用。

三臂为A Core-only、B 当前M7、C M7＋Disposition；100×3=300次主要生成。A只移除可选人格增强，不移除权限、硬事实、来源约束或任务要求。三臂固定同一已配置主模型、参数、输入、有效来源和输出协议；C比B只增加已确认决策层，其他角色选择合同一致。

每场景独立会话，固定种子打乱调用与展示顺序。记录实际模型/政策/输入哈希和有损裁剪，不在相邻测试间累积历史。不为对照切换生产人格或引入新供应商。B/A无显式DecisionRecord时，按预先冻结量表标注输出交流策略，不能伪造其具有新决策对象。

## 3. 质量门及评分

| 项目 | 冻结门槛 |
| --- | --- |
| 来源、冻结、撤回、权限、可靠投递 | 对应硬门全部通过；关键违规0 |
| 情境最小对照 | 合法答案集合内准确率≥85%，Top-2覆盖≥95%；逐项报告分母 |
| 隐性人格动作选择 | C比B提高≥15个百分点；冻结同一子集，拒绝事后筛例 |
| 合理分化 | 应分化组≥80%；动作差异符合标签，随机措辞不同不算 |
| 无必要分化 | 不应分化组≤10% |
| 动作实现 | C至少95/100兑现所选策略；无关键事实、任务或引用损失 |
| 自然度 | C对B胜≥60/100，Wilson 95%区间下界>50% |
| 任务正确性 | C成功数不低于B，关键错误单列，不能平均抵消 |
| 日常新增云调用 | 决策层额外调用0；既有候选选择独立记录 |
| 本地性能 | 新增准备P95≤150毫秒；超时有安全回退及迟到结果隔离 |

“情境准确率”按冻结标签集合判；Top-2为候选情境标签前两项覆盖，不将人格动作排名混入该指标。决策选对动作与最终语言兑现分开打分，格式合法不代表语义实现。来源资格、错误事实、撤回复活、串身份、重复发送、未知伪sent、隐私泄露或越权扩额为硬失败。

自然度采用100个B/C配对，分4批每批25组；隐藏模式，固定随机左右位置。人工分别评价任务正确性和自然度，结果为C胜/B胜/平局。主要胜率为C胜数/全部100，平局不计胜且不得删掉。Wilson使用z=1.96、n=100，报告原计数及区间，不仅给百分比。

机器先查来源、预算、格式、数据完整性与硬门，再交人工盲审。不调用评分模型；人工无法判定的例子单列，不能剔除后缩分母制造通过。结论只适用于本集、配置及审阅者，不推断普遍人群偏好。

## 4. 账本与断点

| 账目 | 限额与处理 |
| --- | --- |
| 正式主要生成 | 固定300次；失败实际请求也占位，不自动补足成功样本 |
| 缺陷复验主要生成 | 最多30次，仅受影响项，旧失败不覆盖 |
| B/C候选选择 | 含正式复验最多220次；真实无命中/无需选择可能少于上限，不为凑数调用 |
| 倾向编译 | 独立准备批，每批最多20次，提交前展示条目/预算；不自动重试或自动开启下一批 |
| 情境/评分/修补 | 预G-AUTO正常路径不增加这些云调用 |

计数按实际发往供应商的请求，工具HTTP前失败与供应商失败区分；已发出但费用未知也占用，tokens/金额未知写未知。各类限额独立，主要剩余额度不用于掩盖选择超限。若30次复验的实际选择需要超过220总限，则保存未完项，另行安排，不挪用或静默追加。

执行前生成逐场景台账，成功受理只查回执，确认片段不重发。第五次连续模型失败或明确QQ中断停止并保存现场；临时不限额记录原值、finally恢复，不放大调用上限。未执行场景不能算通过。

开发样例与独立集隔离。独立失败后保留输入、标签和结果；算法/提示修改回开发材料，重新安排未用于调参的独立复验，不删除难例、降低门槛或反复跑同集直到通过。
