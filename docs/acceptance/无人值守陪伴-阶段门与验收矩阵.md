M7.4、M7.5、M8.A/D/E、M9.A/B 完成后执行联合验收。G-AUTO 未通过，不接入或调用 Director（包括影子模型），不启动人格自我演化。现有 Affect/Director/Planning 只读占位不视为通过或实现自治。

一次性配置完成后，在测试窗口内不点击整理提交、候选确认、任务继续、索引重建或投递解锁。机器验收代理代替用户逐个点击这些按钮，同样算人工编排介入，不能计作产品自治。真实用户聊天输入、明确纠正以及正常对话澄清不属于管理干预；为了让测试通过而补录来源、直接改库则属于。

## 3. 不允许用平均分抵消的门槛

- 错人格/入口读写或投递、无源事实提交、撤回资料重新出现、已确认片段重发、未知结果伪 sent、越权扩额/模型/数据源、私人内容未经授权上传：固定硬门集零违规。
- 所有已受理输入和任务都有明确归宿；正常依赖下，无任务无限停在 awaiting_manual/awaiting_review；需要裁定的内容可隔离，但整个陪伴服务必须继续。
- 正常场景和可恢复故障场景的管理干预次数为零，不能靠验收脚本调用管理员继续接口伪装。
- 必须覆盖可自动接受的有效记忆、可确定更正、新知识更新及真实后续召回，不能把全部候选拒绝、隔离或 NO_ACTION 当成成功。固定可判定样例的预期处理全部匹配；开放质量集的来源正确率、相关性、遗漏率和时效达标率在各阶段开工时冻结，联合验收前不得按输出调低。
- 自动恢复次数、总调用/费用、后台占用和知识刷新延迟必须在批准的有限政策内。主对话响应不得被后台积压饿死，性能目标按实际基线冻结并保留前后对照。
- 真实私聊质量需与 M7.4 基线比较，不因“会自动记忆”而允许文章腔、关键输入遗漏、错误事实或无必要追问退化。机器评分/用户评价分别记录，不能把机器小样本称为已证明长期主观陪伴质量。

## 4. 模拟、真实平台与外部例外

离线固定时钟验证边界、周期和故障；短时真实调度验证触发/执行/恢复管线。按用户既有约定不通过改系统时间或账本伪造长时结果，结束必须退出模拟。模拟通过只能证明覆盖的逻辑，长期稳定性按实际观察时长另报。

真实验收至少连接：真实聊天输入 → 实际主要调用 → 自动封存/整理调用 → 记忆生效与后续召回；以及授权世界源更新 → 自动校验/写入 → 后续回答；QQ 接收、发送平台 ID 与用户已读分别记录。自动处理部分必须由产品运行时自行触发。

每阶段开工冻结有限真实调用数、上限、修复复验额度和停止条件；不自动重跑历史 72 次质量对照。沿用验收临时额度机制及 finally 恢复，生产有限额度恢复必须另验，不能用不限额掩盖。验收第五次连续模型失败或明确 QQ 中断时保存断点，按既有约定停止真实验收；产品自身的有界故障恢复在隔离场景验证，不借此无限重放。

账号强制重新授权、断电、长期断网、供应商/数据源不可用记录为 external_blocked：必须有真实原因、开始/恢复时间、受影响范围及未完成项。不能将正常可恢复软件故障归为外部例外。硬门场景若一直被外部条件阻挡则保持未验，不能用降级演示替代通过。
