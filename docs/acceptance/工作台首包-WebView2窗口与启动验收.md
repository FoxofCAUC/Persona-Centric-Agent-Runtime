# 新版工作台首包 · Windows 窗口与启动

2026-11-19。首包加载已获认可的工作台 Demo，使用 pywebview 6.2.1 和 Microsoft Edge WebView2。新版入口为 `启动PCAR-新版.bat`。左栏、聊天区与首次引导沿用审阅版本。左下角「应用菜单」增加运行状态、收起到托盘和退出工作台。

## 试用入口

在 Windows 11 x64 准备 Python 3.12、uv 和 WebView2。将候选 ZIP 解压到独立程序目录，从「启动PCAR-新版.bat」选择专用数据目录。新建隔离实例时，新版入口按锁定版本准备 Python 依赖，并在候选包提供公开检索模型时从包内加载。需要先单独准备时，可对空数据目录运行包内 `scripts/Prepare-Desktop.ps1`，选择 `-Frontend webview`。[公开版 v0.2 部署基线](../../AGENT_INSTALL.md)

本机人格服务按所选实例的运行设置启动。首包的角色、聊天和模型连接继续使用演示数据。使用左下角菜单查看本机服务状态。选择「收起到托盘」后可通过托盘或再次双击唤回。点击关闭按钮或菜单的「退出工作台」执行正常退出。旧入口 `启动PCAR.bat` 仍默认打开 Tk，同一实例的两个入口会唤回当前窗口。

## 工程接入

- 新增 `gui --frontend webview` 与 `prepare --frontend webview`。WebView 依赖写入可选组与依赖锁。Windows 上的第三方窗口依赖采用 BSD-3-Clause。[pywebview 6.2.1 许可证](https://github.com/r0x0r/pywebview/blob/6.2.1/LICENSE)
- 两种界面共用实例锁、唤回协议、服务组件归属和结算流程。WebView 仅向本地页面提供窗口操作及本机服务状态。页面启动时验证呈现引擎，并核对实际加载的内嵌页面内容。Windows 托盘与原生窗口事件复用现有退出流程。
- 候选 ZIP 的清单单独收录新版 BAT 和静态页面。界面的 HTML 与获认可的 Demo 内容一致，桌面操作由单独的脚本接入。业务库仍使用结构 33。
