# R06 AI辅助盲审操作说明

本工具让官方 DeepSeek 对已经冻结的匿名左右回复提出评分建议，再由用户逐组核查。AI建议不是人工结论，不会直接写入正式 `reviews` 表，也不能代替用户自然度判断。

2026-11-01实际执行：100组建议全部成功，记录总用量44,276 tokens，旁车SQLite完整性检查为`ok`。随后用户核查并保存100组（99组通过建议、1组修改），审阅已经冻结；质量门未通过，Live未获授权。

## 生成建议

脚本只读取受控评测包，复用工作台已保存的主模型连接、模型名、密钥和超时；仅接受 `api.deepseek.com` 官方端点。它不会读取隐藏的 B/C 映射，也不会解盲。

```powershell
$env:PERSONA_RUNTIME_HOME='D:\Persona-Centric Agent Runtime'
D:\Persona-Centric Agent Runtime\.venv\Scripts\python.exe -B scripts\assist_m763_review.py generate `
  --home 'D:\Persona-Centric Agent Runtime' `
  --package-id m763-r06-official-review-v1 `
  --confirm-billable
```

一次成功调用对应一组，共最多100次。结果写入独立旁车台账：

`D:\Persona-Centric Agent Runtime\exports\acceptance\evaluations\m763-r06-official-review-v1.ai-suggestions.sqlite3`

成功槽不会覆盖或重放。进程中断时，在途槽记为费用未知，不会自动再次调用。失败只保留错误码及无效输出哈希，不把不合规内容当评分。可用以下命令只读检查进度：

```powershell
D:\Persona-Centric Agent Runtime\.venv\Scripts\python.exe -B scripts\assist_m763_review.py status `
  --home 'D:\Persona-Centric Agent Runtime' `
  --package-id m763-r06-official-review-v1
```

## 人工核查

重启人格服务和工作台以加载新代码，然后在“角色资料 → 人格倾向 → 独立评测盲审”载入原评测包。成功的建议会自动填满五个中文选项和评分理由，并锁定为待核查状态。

- 点击“通过”：确认当前DeepSeek建议符合人工判断；系统将原样保存为正式审阅，记录建议指纹和人工通过来源，然后自动进入下一组。第25组通过后自动载入下一批。
- 点击“修改”：只解锁当前建议，不会保存。用户必须手工修改所需选项或理由，再点击“保存”和“下一组”；正式审阅会记录为“人工修改AI建议”。
- 不点击上述任一按钮时，不能跳过当前待核查建议。
- 已经存在正式人工审阅的组仍显示已保存内容，不被AI建议覆盖。

“冻结并解盲”仍要求100组都有正式审阅。AI脚本、建议完成数或“通过”按钮均不改变既定质量门，也不自动授权Live上线。
