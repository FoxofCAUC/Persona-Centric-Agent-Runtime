# R06人工盲审操作说明

如需使用官方DeepSeek先生成逐组评分建议，再由用户通过或修改，请参见
[AI辅助盲审操作说明](M7.6.3-R06-AI辅助盲审操作说明.md)。AI建议不会自动成为人工结论。

2026-11-01：`m763-r06-official-review-v1`的100组审阅已经保存、冻结并解盲；质量门未通过，Live未获授权。下列内容保留为本次实际使用的操作说明。

## 打开与保存

1. 在PCAR工作台的“角色资料”页面打开“独立评测盲审”。
2. 输入本地评测包ID `m763-r06-official-review-v1`，选择第1批，再点击“载入”。评测包只从受控证据目录按ID读取，不能在此输入任意文件路径。
3. 每组查看输入场景、共同作者资料摘要及左右两份回复。左右位置已随机化，界面不显示模式或调用信息。代码也按纯文本展示，不执行。
4. 分别填写左右任务结果、左右主要交流动作、自然度胜方和平局选择，并填写“评分理由”。全部选项和理由均为必填，理由最多2000字；各项没有默认答案。
5. 点击“保存”，看到“已保存（修订N）”后再点“下一组”。保存期间点击下一组会等待成功确认后切换；如果期间另有编辑，新草稿会保留在本组。缺项、连接失败、版本冲突和操作忙碌会在盲审窗口内明确提示，不再只写入被遮住的主窗口状态栏。修改目标包或批次后须重新载入；冲突或保存失败时保留草稿，不要换操作号反复提交。
6. 四批各25组，共100组。可以分次完成；已保存记录再次载入时可读取并修改，未保存文字不会自动成为评分。
7. 全部100组保存并复核后，才点击“冻结并解盲”。冻结后不能修改评分，解盲结果用于计算正式指标。

## 评分口径

任务和自然度分开判断。语气更亲切不抵消错误答案；更简短也不自动代表更自然。

| 界面字段 | 含义 |
|---|---|
| 通过 | 完成当前任务，没有发现关键事实、来源或内容完整性错误 |
| 关键错误 | 有会影响任务完成的关键错误；在理由中指出具体位置 |
| 无法判断 | 保留不确定，不勉强给通过 |
| 自然度：左侧更自然／右侧更自然／平局 | 按本场景及给定作者资料判断 |

主要交流动作从实际正文判断，而不是猜测模型内部选择：

| 选项 | 含义 |
|---|---|
| 直接回应 | 直接接续当前内容或回答 |
| 确认或肯定 | 确认收到、感谢或肯定对方 |
| 询问必要信息 | 询问完成任务所必需、尚未提供的信息 |
| 澄清歧义 | 澄清指代、含义或要求中的冲突 |
| 支持或倾听 | 提供情感支持或倾听 |
| 解释说明 | 说明原因、原理或做法 |
| 依要求质疑 | 按用户要求批评、反驳或检验 |
| 说明暂不能处理 | 明确说明当前暂时无法处理 |
| 说明边界 | 明确表达不能接受或不能执行的边界 |
| 无法判断 | 无法确定主导交流动作 |

回复可能同时包含多种行为，选择主导交流动作即可。理由可以简短说明“正确完成任务但追问多余”“两边都合适”等；不需要猜臂别。助手的事前任务初筛保存在独立记录中，不会预填您的自然度或动作判断。

界面选项已全部汉化，内部评分值和存储格式保持兼容。已有评分重新载入后显示中文；没有评分的项目仍为空白。若工作台在更新前已经打开，请先保存当前评分，再重开工作台加载新版界面。

## 隐私、费用和结论

审阅包只包含本轮通用人工资料和模型输出，不包含正式私人角色、凭据或供应商地址。载入、保存与冻结不调用模型、不发送QQ、不启用Live。盲审前不提供左右映射。


100组全部完成后，再按既定固定分母计算任务正确性、动作兑现和自然度指标。未完成、无法判断与平局不用于缩小分母；即使人工偏好达标，也仍需满足其余质量、平台及作者配置条件，不能自动推断上线许可。
