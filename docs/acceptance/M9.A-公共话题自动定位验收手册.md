# 未登记公共话题自动定位验收手册

2026-11-11，源码dev17。[实施与真实结果](../M9.A-未登记公共话题自动查询实施记录.md)。

## 使用方式

在隔离工作台角色开启知识读取、主模型知识整理、联网及Jev，选择仅联网。保留中文Wikipedia在允许网站中，允许正文保存和原站API；勾选「自动定位未登记公共话题」并保存。角色无需逐题登记查询词，旧策略默认不会自动打开新能力。

用未登记的新问题测试，例如科学概念、技术原理、作品作者。展开实际出处，核对正文、修订与主模型采用内容；观察提出标题和独立复核分别留账。明确私人请求和普通告别不应变成来源查询。页面不存在应显示无匹配，不能凭参数知识宣称查到了。

## 已执行

- 空主题表、无ANN环境：首轮8个知识场景全部证据注入；首轮私人边界冲突保存原失败。
- 版本化路由修复后，两个纯私人请求正常回复且不访问来源，混合叙述的新公共概念正常取得证据，3/3完成。
- 来源请求只含通过复核的公共页面URL，人工测试号码、私人姓名和原问题没有外发给来源站点。
- 撤权、取消、审查记录／URL／角色篡改、非文章目标、缺页、JSON值与布尔标志不变、旧策略及界面等54项不同检查覆盖通过。

## 边界与后续

模型参与公开性判断，代表测试不等于无限主题／隐私组合都已证明。首版自动定位限中文Wikipedia，其他来源仍按登记政策。新能力默认关闭、按角色显式开启；不自动开启正式日常角色。
