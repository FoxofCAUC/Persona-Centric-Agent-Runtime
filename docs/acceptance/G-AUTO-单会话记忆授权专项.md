# G-AUTO · 仅可见资料副本的单会话记忆授权

r2 的通用后台用途授权拒绝仅可见资料副本。专项增加独立的本地授权入口，操作人明确指定实例、人物、桌面会话、接收方身份和当前授权修订号。修订号从 0 起算。授权与撤回保存在该实例的结构 33 数据库中。

只有该会话的原生桌面回合可进入自动记忆提取和复核。旧会话、导入历史和缺少同会话来源的既有记忆均排除。领取、实际派发和本地发布时复核副本身份、会话、接收账户、任务归属和来源。撤回再授权会产生新修订，旧任务不能借用新修订。普通整理、主动任务和其他模型用途沿用各自的原授权。

```powershell
python -m persona_runtime.copy_session_memory authorize --home "<验收实例>" --persona "<人物ID>" --session "<当前桌面会话ID>" --provider "<已核验的接收方身份摘要>" --expected-revision 0
python -m persona_runtime.copy_session_memory revoke --home "<验收实例>" --persona "<人物ID>" --session "<已授权会话ID>" --provider "<授权时的接收方身份摘要>" --expected-revision 1
```

隔离回归验证了新旧会话的材料边界、同一决定的幂等性、接收方与账号更换、实例身份变化、撤回再授权以及在途回执的结算。正式观察沿 r2 的实例、会话、逐笔账本和已显示回复接续，换版前后分别登记候选摘要。[专项回归](../../tests/test_private_copy_authorization.py) · [正式入场记录](G-AUTO-正式入场与首批观察.md)

r3 的正式复验已在原会话中自动完成首轮提取、独立复核与覆盖结算，使用 2 次修复预留，原主回复新增派发为 0。后续两条作者原文均从真实聊天窗口发送并取得完整可见回执。r3.1 将处理既有隔离冲突和旧摘要片段的范围同样限定到该会话。正式质量结论以实际发布来源和后续回复的取用证据为准。
