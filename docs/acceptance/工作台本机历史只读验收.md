# 新版工作台 · 本机历史只读接入

2026-11-19。在已验收的 WebView2 启动包上新增「本机历史」视图。双击新版 BAT 后，左栏显示所选实例的角色和桌面会话，默认打开后台已选角色与当前会话。可切换角色、查找会话、加载更早记录或从应用菜单刷新。右上角可进入演示，再返回本机历史。

## 数据与协作边界

读取使用 SQLite 只读事务，按人物、会话与本机用户核对归属。历史按已有呈现规则读取。E.N6 轮次只展示已确认呈现的气泡。窗口只接收角色名称、会话标识和可显示内容。当前阶段发送与角色编辑留在演示里。旧版启动入口继续打开 Tk 工作台。

工作树以通过校验的首包 ZIP 为基线，验收使用独立数据目录和本地数字标记。只读适配器和历史页面脚本独立维护。导入链路继续在原工作区推进，双方随后合并窗口入口时需对齐桥接暴露的操作与资源清单。历史视图仅接现有桌面聊天，导入原文的展示由导入链路接续。

## 验收范围

核对跨角色拒读、QQ 与导入轮次过滤、分页顺序、已呈现范围、选择与数据库不变。用解包后的新版 BAT 验证原生窗口、角色切换、加载更早记录、演示往返和正常退出。验收使用离线资料，实际模型调用为零。
