# M7.0 工作台启动异常修复 — 2026-10-28

用户报告：双击`启动PCAR.bat`，Windows管理员授权点击“是”后，工作台仍不出现；重复启动结果相同。本次只修复启动流程，不恢复已暂停的QQ/模型验收。

## 原因与修复

现场的管理员清理报告显示一个pythonw进程被结束，而控制台租约仍停在active、租约进程已不存在。旧选择器保护了发起清理的工作台PID，却没有保护该工作台的祖先进程。Windows虚拟环境的pythonw启动器是基础解释器的父进程；UAC清理助手由提升代理创建，不一定与工作台在同一进程树内。祖先被结束会带走工作台，租约也来不及正常关闭，下次启动再次进入异常清理。

修复为对清理助手和显式保留的工作台分别展开完整祖先保护；不保护工作台的全部子进程，相关服务、QQ和其他旧工作台仍在原强停范围内。循环、父进程缺失和多条保护链重叠均有回归。没有删除或篡改旧租约来绕过故障，没有恢复脱离控制台的后台驻留。

另外增加pythonw可见错误提示与D盘脱敏诊断：记录失败阶段、异常类型、源文件名和行号，不记录异常正文、配置、凭据、命令参数或聊天内容。启动锁、初始化或清理失败不再仅消失于隐藏终端；正常退出不误报。
