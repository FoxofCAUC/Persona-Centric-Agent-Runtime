工程回归用模拟模型；真实固定8次主要＋1次现有整理，修复复验最多另3次，逐笔记账，不重做旧72次对照。通过既有临时不限额机制执行，finally恢复；第五次连续模型失败或明确QQ中断时停止，不自动重放。恢复进度先查稳定回执，不更换ID重发。

## 实际工作台（必测，先隔离）

1. 打开PCAR，进入左侧“认知上下文”。核对入口、Bot、联系人、两个开关、五种任务、请求及整理任务ID。
2. 选独立人格/desktop，点击“读取入口政策”。应显示working_set、cross_session=false及版本。
3. 取消“自动工作集召回”，点击“保存开关”再读取，应显示legacy_recent，原缓冲及回复模式保持。重新勾选并保存。若有收集中批次，必须先封存或取消；取消弹窗不改政策。
4. 点击“载入最近请求”选请求，点击“预览任务上下文”。检查分区、来源、版本、字符数、裁减、降级及哈希；前后Event/turn/attempt/持久Manifest数量不变。
5. 点击“查看调用清单历史”。应读到调用前保存的清单，不能把预览临时context_id当作持久结果。旧清单不替代当前原文授权。
6. 切Reflection、填写实际整理任务ID并预览，核对用途、来源与guard。Affect/Director/Planning分别预览，应显示not_ready及缺失原因，无模型调用、情绪数值或新任务。
7. 查询/保存失败后检查草稿；等待期间切换人格、入口或请求，旧响应不得覆盖新页。目标变化后需重新读取政策；后台刷新不吞草稿。
8. 从档案页展开来源，撤回后不得再作为有效上下文。记录实际点击、API对应结果与截图；HTTP通过不能代替界面实操。

隔离界面使用模拟模型不算真实收费或QQ验收。

## 副本迁移与恢复（必测，不收费）

三服务停止并核对无未决请求/批次，备份结构11。D盘副本升级12、重复初始化，核对46张旧表原列摘要、主键、完整性及外键；仅计划内政策新版本/head变化单列。恢复结构11再升级，形成第二链；事务失败专项保留现场。导出9保留旧内容并增加清单/政策快照，排除encrypted_key及claim_token。正式部署持锁、停写备份后升级；回退旧软件须还原11备份，不能直接打开12。

## 真实固定8＋1组

| 组 | 操作/可复制消息 | 通过标准 |
| --- | --- | --- |
| R01 | 在当前50窗口、近十轮外准备标注的青禾书店人工档案；问“根据本会话人工档案，虚构青禾书店阅读角的预算和偏好颜色是什么？没有资料不要猜。” | 完整恢复，三百元/蓝色，一次主要调用 |
| R02 | 新session/natural_batch，约1秒间隔发“虚构清泉书店需要阅读角。”“预算四百元，偏好绿色。”“请合并前两条，说明书店名、预算和颜色。” | 三成员一批，完整理解，一次主要调用 |
| R03 | 新session：“你的血型是什么？如果资料未设定，请明确说未知或未设定，不要猜。” | 不编造未设置资料 |
| R04 | 第二测试人格询问青禾书店预算 | 不读取第一人格资料，不猜金额 |
| R05 | 明确引用50轮外远山书店回合第三成员，询问预算/颜色 | 恢复整轮，五百元/紫色，无额外理解调用 |
| R06 | 新session旧事实在近十轮外，关闭召回询问花溪书店预算 | legacy_recent，未知不猜，Scope/撤回/清单仍有效 |
| R07 | 持派生缓存锁，发“只回复基础聊天仍可用” | 单次生成，清单记录cache_busy及安全降级 |
| R08 | 本人QQ发“M72-QQ：请用一句纯文本确认收到，不使用Markdown格式。” | 真实入站、一次生成、纯文本实际发送及平台ID；禁止双星号等Markdown结构 |

R01–R07可由已授权工作台业务/API入口执行，不能记成实际QQ入站；R08必须有真实平台记录。人工准备的长历史不是实际历史聊天。每个关键错源、丢成员、身份串读、未知事实编造或重复调用单列缺陷，不用平均分抵消。修复用独立编号保留原失败，最多3次。记录受理、排队、模型、发送、tokens及金额。
