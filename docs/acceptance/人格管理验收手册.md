# 人格复制与回收站验收手册

2026-10-29，0.7.5.dev4/主库16/导出13。仅使用隔离运行目录和人工角色，不向正式私有人格写测试数据，不发真实QQ或付费请求。

## 人工界面检查步骤

1. 准备两个通用人工人格A、B，给A填写角色资料。选择A，点击“复制选中人格”，确认后列表出现带独立ID的副本；A仍是当前人格。
2. 查看副本设定，核心/表达/角色资料一致；副本没有旧聊天、记忆、Session或临时状态，入口仍是新建默认。
3. 点击复制后取消确认，核对没有新增身份。切换列表选中项后，迟到预检不能弹出旧对象的确认框。
4. 选中当前人格点击删除，应提示先切换。切至B，再选A点击“删除到回收站”，确认后A从正常列表和聊天下拉框消失。
5. 勾选“显示回收站中的人格”，选A切换聊天应被拒绝；点击恢复后原ID及历史保留，不自动切换当前人格或重放任务。
6. 制造人工排队请求/未决投递，删除相应人格应被拒绝；使用既有处置入口完成后再删，不能靠删除丢弃消息或费用记录。
7. 隐私及获批云端供应商边界只在人工私有夹具或可删除副本验证。正式私有原体删除按钮应明确拒绝；其主库副本继续被标记为私有，不作为直接验收目标。
8. 保留原配置、人格和日常账号。验证结束关闭隔离窗口、停止隔离服务并清理人工数据，原正式库不放入公开证据。
