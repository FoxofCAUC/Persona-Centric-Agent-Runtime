# M8.D 自动记忆验收手册

当前实施与证据解释见[实施记录](../M8.D-自动记忆实施记录.md)；本手册不是重新运行收费位置的指令。

## 正常操作

1. 在记忆整理页点击“开启／暂停自动记忆”完成角色的一次性开启。新建、原生导入和复制默认关闭；私人角色须另有该角色的整理供应商授权。
2. 正常聊天后保持工作台开启。当前Scope空闲120秒后，后台自动提取、独立复核并提交；有下一批会自行推进，不需批准或继续。
3. 在记忆整理页查看“有效来源已处理”和“摘要可用”。它们分别表示处理结论和有损摘要支持范围；不能相互替代。
4. 点“复核决策与隔离项”查看原因，点任务查看阶段、来源、实际调用次数和下次条件。额度耗尽会等待原窗口恢复。
5. 日常明确更正可自动形成事实新版本。同轮其他事实保留，旧原文不改写。真正撤回则整轮退出普通证据。
6. “人工处理隔离项”“记忆历史与有效期”“修复自动摘要（先预览）”是检查和纠错工具，不是正常自动流程必经步骤。

暂停停止新派发和重试，已发生调用照实记账；未知效果不可用重试按钮重放。关闭工作台后服务停止，期间不处理任务。

## 已执行工程检查

- 多批自动推进、多触发共享、手动/封存入口复用、双worker、队列满事务回滚。
- 提取与复核分离、原回执恢复、未知调用防重放、来源撤回和政策变更。
- 事实级更正保留独立信息、时间区间/到期/未来生效、重叠隔离、人工覆盖及显式修复。
- 相对日期与来源记录时间一并进入上下文和Manifest；3项最终离线补验通过，未额外收费复验。
- 小时额度等待及可控时钟恢复、旧客户端可选字段、Scope/角色隔离、旧来源屏蔽和导入授权不继承。
- 22→23人工及正式副本迁移、失败回滚、重复初始化、恢复、旧表内容和导出18/导入17兼容。

模拟时间窗口和结构断言不等于真实跨日运行或模型语义正确。模型事实答案另由真实位置及Manifest核验。
