## 2. ADR-PD-01：来源与编译

权威来源为明确授权的Core、Character、Expression及作者确认关系设定。作者编写的虚构背景属于创作者材料，不是私人共同经历。自动记忆、外部知识、模型自述、当轮观察及经历摘要均不能直接编译成稳定倾向。

编译流程为：读取指定权威版本 → 生成带source_refs及适用/不适用条件的草案 → 来源校验 → 作者确认/修改/拒绝 → 发布投影版本。来源不支持的新内容必须先在权威材料中修改，不能把确认动作当作新事实写入。

确认只在创建或修订发生，不能逐轮要求批准；未确认项不激活。来源版本、内容指纹与授权缺一不可。源资料更新后，对应投影待复核，不能自动延用到新版本。已经受理的合法旧快照保持冻结，但调用前仍检查来源资格/撤回；撤回不能被旧版本保留绕过。

复制只携带有资格的作者确认定义并重映射合法来源，不复制DecisionRecord、真实经历或经验候选；重映射失败标未配置，不沿用旧身份引用。回收站、恢复、私有原文及正式原体验收保护沿用既有规则。

## 3. ADR-PD-02：观察与动作

| 合同 | 最小职责与边界 |
| --- | --- |
| DispositionDefinition | 稳定ID、人格、来源版本/位置/指纹、适用范围、触发、偏好/避免、优先级、确认状态与修订；仅投影 |
| SituationFrame | 输入成员证据、交流行为、话题、明确请求、关系线索、不确定性；observation，不是心理诊断或长期事实 |
| DecisionRecord | 输入指纹、冻结版本、激活与排除ID、确定性贡献、动作排名/选择、缺口/回退、trace指纹 |
| DecisionCapsule | chosen_action、最多3项关键要求、必要来源版本；≤600字符，不暴露完整评分或私人正文 |

数据合同不是本轮表结构；后续开工才冻结存储/管理接口。审计中的原因是可复现的规则贡献，不要求保存模型内部思维过程。

动作白名单：respond、acknowledge、ask、clarify、support、explain、challenge、defer、set_boundary。defer仅说明暂不能处理；silence仅影子观测。动作不授予工具执行、主动发送或后台任务权限。

规则优先；无法判断就记录未知并respond或回退M7，不因不确定性普遍增加追问。先处理权限、硬边界和来源事实，再满足当前合法任务，再用作者设定及倾向影响交流，最后决定表达偏好。倾向不能让机器人编造未知事实、丢掉答案、为保持人设拒绝纠错或突破关系/隐私边界。

## 4. ADR-PD-03：受理、预算与提交

新请求在受理事务固定投影、编译器和决策政策；批次首成员固定，排队编辑不换版本。旧请求缺字段走M7，不补造旧DecisionRecord。显式重试保留输入和引用绑定，按既有重试合同使用当前设定/政策并追加记录。

准备在主库写事务外完成，正常路径本地有界，无新增云端理解/评分/修补。最终短事务复核Scope、来源、版本和预算，并保存有效DecisionRecord、Manifest、attempt后再调用主要模型。记录不含完整Prompt/输入/人设/向量，不突破既有Manifest大小上限。

胶囊占用角色3000字符总预算及总输入预算，先让出可选背景和样例；角色锚点/动态事实/样例的既有分区上限不因此扩大。核心边界、必要事实、明确引用和当前完整输入不得被挤掉。硬区装不下则明确失败，不截断成员或引用。

| 情况 | 处理 |
| --- | --- |
| 可选资源缺失、忙、超时 | 丢弃本次决策结果，记录原因，回到有效M7基线；迟到结果不改Prompt/追加调用 |
| 越权、快照损坏、明确引用失效 | 调用前失败，不以回退掩盖 |
| Live的DecisionRecord或Manifest无法保存 | 零主要调用，不静默退到无审计路径 |
| 来源在准备后撤回 | 最终复核不得注入；按来源与引用合同重新裁定，不能复活 |
| JSON格式合法但未兑现交流策略 | 作为动作实现缺陷记录；不靠自动评分/修补调用掩盖 |

## 5. ADR-PD-04：与后续自动化的边界

M8.A/D/E负责受管执行、记忆和运行，不获得改Disposition的授权；M9知识更新也不能改变作者正典。G-AUTO前禁止经验自演化、自动Affect调制和Director影子调用。门后Affect只做当轮有界权重调制，Reflection只产有证据/反证候选，Director只审提案，确定性门控才可提交。

Live关闭后回到M7，审计不删除；未知投递不变sent、确认片段不重发。当前控制台关闭停服规则不因本规划改变。新功能上线默认开启与逐步发布不矛盾：未验收Shadow不是产品上线，已验收Live才更新目标和初始化，显式关闭保持。
