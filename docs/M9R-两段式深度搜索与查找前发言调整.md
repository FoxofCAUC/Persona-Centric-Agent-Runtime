## 调整后的行为

```text
Jev判断
  ├─ none → 原人物回应，可使用已保存资料
  └─ web且公开任务可执行
       → 人物先自然接话，可带初步建议，并说明准备去查
       → DeepSeek深度思考＋联网搜索取得工作资料
       → 原v8人物层接着给出正式回答
```

查找前发言由原人物生成层决定，使用获准的性格、关系和当前语境，不从固定句库随机选择，不直接把内部工具状态念给用户。它是真实聊天事件，保存后立即可读；桌面在主回复仍排队、搜索尚未结束时也展示。正式回答知道本轮已经说过什么，可以综合资料接续、补充或修正。人物可以先讲当前看法，但不冒充已经搜索、找到网页或完成核对。

这是人物转译层增加的一次短发言生成，单独保留模型回执和用量。它增加一次实际调用及查找前的生成等待；两段式指资料任务与人物回答的职责分工，不代表每轮只有两次物理生成。过渡发言关闭深度思考、输出预算512tokens；后续资料任务固定开启thinking和high。用户可读取过渡发言不代表已阅读，也不代表联网任务成功。

新注册资料任务使用native-deep-thinking-search-v2：deepseek-flash、thinking.type=enabled、reasoning_effort=high，同时声明deepseek_web_search与deepseek_read_url；指定链接也保留搜索能力。输出按步至少8192tokens，不能当作整轮费用硬上限。公开检索界面不再让用户选择普通／深入；旧公开任务中的ordinary字段及旧回执按原意读取，新任务的实际请求固定为深度搜索。[官方联网工具说明](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)，[思考模式参数](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。

开启深度思考是作者选择的准确率方向，不保证每个事实都正确；本包不增加权威来源门、逐数字审核或独立事实裁决，也不改写此前错误攻略。

## 状态、恢复与输入边界

- Jev仍是唯一联网判断；none、总开关关闭或没有可执行公开任务时，不发查找预告、不新增搜索。Jev异常仍按原policy_fallback，在已有权限内处理。
- 过渡发言使用原组织任务及attempt／receipt账本，按root_turn_id去重；发布聊天事件和保存处理结果同事务提交，不建立第二套外发账本。
- 已收到过渡回执而本地发布失败时，先停止本轮，恢复只发布已有回执，再开始搜索；不重新生成。已知生成失败或结果未知时保留错误和费用，不放固定话术冒充成功；搜索仍可按原决定继续。
- 搜索过程中取消或退出，已说的话仍在历史；成功／未知调用不重放。重试复用已完成发言；本轮费用仍包括最初发言的已知或未知用量。
- 发言进入同轮档案与后续人物上下文，来源屏蔽规则保持。整库迁移保留发言；个人导出保留实际事件，不携带执行权限。普通审计只保留来源引用与哈希。
- 人物语境仅发给已授权的原人物生成连接。原生资料任务仍只接收绑定当前事件的公开任务，不接收人物原件、隐藏档案、整库记忆或查找前台词。
- 旧比较工具的新计划只建两段式位置；含单段式的历史计划只能只读report，run／resume在调用前拒绝。不删除旧原文和分析。
