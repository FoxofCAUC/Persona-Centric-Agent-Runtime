# M8.A：v8当前系统职责交接

这是阶段7的后续开工入口，不表示M8.A执行器或无人值守已完成。阶段7实际状态见[交付记录](阶段7-v8正式交付记录.md)。

| 职责 | 当前权威 | 后续边界 |
| --- | --- | --- |
| 输入、合批、冻结 | ingress、input_batches、turns及政策/人物/模型快照 | 不从新政策重装旧请求；滚动5秒由现有入口实现 |
| 主回复、取消、原生重试 | ChatEngine、attempts、generation_retry；物理调用审计 | 首次加最多3次原生重试；未知与已成功位置不得外层重放 |
| 整理执行 | organization_tasks、OrganizationEngine、organization_attempts/receipts | 失败格式也先保留收到的原生回执和用量；任务状态不等于有可发布记忆 |
| 每日/增量触发 | organization_schedule，经OrganizationEngine.worker调用daily_tick/incremental_tick；organization_progress游标及blocked_task | 继续复用现有排队/去重及额度；实际跨日触发本次未观察 |
| 封存触发 | sessions、session_triggers、session_organization typed sources及包标识 | 封存有待处理/阻塞状态，不能另起独立整理执行链；来源必须保持本人/角色/渠道范围 |
| 额度及费用 | quota_reservations、物理调用记录、原生usage、QuotaService | 未知用量保留未知，不填零；预留与任务恢复统一处理，逻辑位置不等于物理收费次数 |
| QQ领取/投递/确认 | QQBridge与reply_delivery_streams/parts/attempts/operations | completed生成不等于sent；平台回执、未知效果、确认必须分开；不可另建第二发送队列 |
| 启停、锁和恢复 | InstanceLock、ServiceController、受管host/Workbench | 只操作本实例归属；重启将未决显式化，不自动重放未知生成或投递 |
| 后台验收 | plugins/background_acceptance、plugins/release_acceptance | 只显式开发调用，非生产收费调度权威，不接系统定时、自启动或日常整理 |

首个M8.A施工包仅统一任务标识、授权、预算、领取与恢复合同，并适配现有organization_tasks。以原任务ID及已发生效果为迁移依据；派发前持久化授权/额度/领取，派发后持久化原生回执；崩溃恢复先核实效果。不得并行建立另一套能对同一整理任务重复收费的执行器。新合同必须支持已排队、waiting_quota、running、failed/interrupted、completed及blocked_task，不把中断推断为没调用。

M8.D接收自动覆盖闭环、摘要重建、候选审核和语义误报治理。阶段6修复后的百轮仍有18条早期有效轮覆盖缺口、一个相关问题误判冲突候选；第93轮事实曾在86轮复述，不能宣传成纯82轮无复述回忆。现有显式重建和批准替换已具备，不等于无人值守治理完成。

M8.E接收常驻宿主、无人值守恢复、登录/断线/运维。实际跨日、系统睡眠/唤醒、长时间无人值守不由本轮有限验收代替。知识及联网能力继续后续阶段；不新增外部发送权限。

M4、M5、M6.1旧限制、旧Disposition/Shadow/Live研究与冻结的人机味整改按原记录携带，不因v8发布补记通过。旧Frame/Spec和实验装配已退出正常源码交付清单；历史解码、动作核元数据和关闭恢复依赖保留。

参考结论索引：[大肥鱼参考线](AI伴侣产品方向与大肥鱼参考线.md)、[v8采用](AI伴侣重构-v8最终采用与人机味修复结项.md)。v8采用原生文本、即时通讯指导、一次主回复及本地选材；生成位置由既有ChatEngine冻结和审计。新角色关闭恢复到发布前兼容默认，已有角色恢复真实启用前政策；只追加新政策版本，不改写历史或账目。

私人授权继续由现有dispatch guard执行。阶段7新增本机按角色ID绑定的主聊天授权，记录在private/personas/model-grants.json，不随复制继承，也不改原稿注册授权；供应商变化、角色变化均不能复用。main授权不等于整理/选择授权。正式有限验收期间暂缓每日整理，结束后恢复原开关；原已过期的每日触发及其权限前置不能被称为本轮跨日验证。后续M8.A必须分别核对任务种类与授权，不因可聊天而推断可后台整理。
