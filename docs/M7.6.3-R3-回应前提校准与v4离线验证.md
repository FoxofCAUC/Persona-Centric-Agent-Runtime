# M7.6.3-R3 回应前提校准与v4离线验证

2026-11-01。**规则与工程准备完成、模拟通过、真实效果未验证。** 候选更新为`0.7.6.dev9`，工具标记`r3-prerequisite-v1`。正式Shadow、默认选择器v2保持；结构20、导出17、配置2、桥接0.7.2不变。本阶段零真实模型调用、零QQ、未启动正式服务、未提交推送部署。

## 改动与边界

新增可由版本化入口政策选择的`character-selector-v4`。v4只在v3的表达样例段落后插入回应前提规则：根据具体正文判断，保留不依赖成功的过程关注迁移；需要完成、取得结果或适合庆祝的核心回应须有当前输入或有效引用支持；局部完成不扩大成整体；当前意愿及最后更正优先；判断整条样例，不能借一句合适的话忽略其余冲突前提。允许空选，不设ID、关键词或完成状态黑名单。

v1—v3正文、事实与Lorebook必要性、样例不得成为事实、输出协议及处理行为完整保留。默认仍是v2。除版本号外，生产代码仅改选择器版本分派/新段落及装配诊断职责清单；主回复提示、召回、预算、采样、胶囊、观察器、角色结构、API及数据库均未改。职责清单登记v4不代表本次请求使用v4，实际版本仍取调用及最终入模证据，词法回退显示未应用云端结果。

R2.1的C21原标签、计分和全部输出保持。新规则不追改历史成绩，也不因历史回复较好就宣布原选择正确。C23复述式表达与原“情境缺口与动作兑现修复”仍未完成，本阶段未处理。

## 人工材料与标签

新建P01—P12共12场景、两个完全合成的角色。身份、事实、关系、基础提示及样例元数据相同，只有各6条样例正文不同。题材为无台阶路线、辨认星图、旧物展导览、家庭照片、餐车招牌和种子交换架，未抽取私人资料或冻结独立评测，也未以R1/R2原句作近义改写。

| 场景 | 验证内容 |
|---|---|
| P01/P02 | 同一主题的进行中与完成后 |
| P03/P04 | 跨话题的过程关注迁移 |
| P05/P06 | 已完成但庆祝意愿不同 |
| P07/P08 | 整体未完，局部已完或也未完 |
| P09/P10 | 连续消息最后更正状态或意愿 |
| P11/P12 | 合法旧引用与当前说明一致或被更新 |

144条标签均以场景、角色、材料ID、正文SHA256定位，保存逐条理由、正文所需前提、输入支持、可迁移关注、正文/当前消息/引用证据及不得带入的事实。144条具体判断理由各不相同，引用经过原文核对。正文改变使旧标签失效；仅改标题不会改变正文标签。

例如P07的`e2`在过程型角色中是“这一小节已经对上了”，允许认可一盒照片排好；在立场型角色中是“整套都收尾了”，必须排除。立场型`e3`的“做完归做完”没有整套断言，在P07/P09可仅指明确完成的局部，不一概排除所有带完成措辞的样例。

运行材料、评价标签、脚本响应分别位于独立模块。标签没有进入候选、请求、Manifest、角色结构或正式数据库。脚本响应不读允许集合，刻意包含空选、适用选择和合法但不适用的选择，不能代表v3/v4模型判断。

## 隔离工具与证据

`scripts/r3_selector_prerequisites.py`只提供`prepare / simulate / report / verify`，没有真实执行入口。四动作均阻断真实客户端、HTTP、外部连接、DNS和数据报；只允许异步运行所需的本机连接。隔离配置及受理模型快照的供应商密钥为空。

使用现有本地`BAAI/bge-small-zh-v1.5`权重，只读载入，索引及缓存写入本阶段目录，没有下载或更换模型。每个场景＋角色冻结一次候选池，两臂共享候选、排序、来源、历史、引用、种子、主回复参数与格式，仅选择器版本不同。通过新政策正常受理v3/v4；baseline决策、关闭胶囊与观察器、v2主回复表达。每对相邻，不同对交替先v3或v4。

48个正常请求产生96次**模拟**生成，均为一次选择加一次主回复，无重试或词法回退。48条最终消息指纹均与模拟客户端实际收到的消息一致。24组主请求中4组完全相同，20组只有表达样例不同；事实、主提示、历史、引用和供应商参数没有未解释变化。另从冻结候选复算48条脚本响应，与96条回执逐字一致，未重新调度成功请求。

**候选限制：P06-stance唯一适用的`e3`未进入前五候选。** 两臂均缺失，候选为`e5/e2/e1/e6/e4`，未补塞、换题或改召回。另P10-stance没有适用样例，允许空选。因此每臂24请求中有22条存在适用候选；无适用材料、召回缺失、空选、预算裁减和回退分别统计。脚本故意选错的结果也原样保留，不能依据这些计数认定v4收益。
