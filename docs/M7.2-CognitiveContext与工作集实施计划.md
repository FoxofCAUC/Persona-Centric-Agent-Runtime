## 3. 政策、快照及Manifest

- 扩展现有版本化入口政策：context_mode为working_set/legacy_recent，cross_session布尔；不另建政策权威。
- 新请求受理固定可空上下文政策快照；自然批次首条固定，排队中编辑不改变已受理输入。
- 新增追加式context_manifests，含任务类型、请求/整理任务、attempt关联、Builder版本、最终输入哈希、状态版本、来源、裁剪、缺口及降级原因。
- 每次聊天、整理和模型连通性调用前持久保存Manifest；保存失败不得调用。预检失败可记录无attempt诊断。现有context_uses保留兼容字段并关联context_id。
- Manifest不重复保存完整Prompt、正文、人设或凭据；CognitiveContext不是第二份长期记忆。
- 迁移为既有人格两个入口建立新政策版本，召回开启、跨会话关闭，保留缓冲/回复模式。旧政策、批次、请求快照不改写；旧请求缺新快照时兼容运行，显式重试才取当前政策。

## 4. 工作集与预算

最多50个已完成且来源有效的逻辑回合，排除当前及创建顺序晚于当前请求的回合。当前session优先；跨会话开启后用同Scope其他session近期回合补足50。Scope含人格、本机用户、渠道、Bot及联系人。

失败、取消、未完成、撤回或归属不明记录不进入候选；QQ只使用确认sent实际正文。当前全部成员按轮转提取最多32词项，防首成员占满；省略原因记录，但原输入不截断。

复用M7.1投影、分词、缓存；仅内部增加任一词项命中，不改变管理查询all_terms/phrase。按命中数、范围内稀有程度、创建顺序、稳定ID排序，不依赖跨Scope统计。默认最近2完整回合加最多3相关回合；无命中不以无关历史填满。明确引用沿M7.0绑定，可超出50轮。按turn/Event/part去重，非首命中仍恢复整轮。

硬区为身份、核心边界、当前完整输入、必要角色事实、明确引用和权限；创作者设定、真实经历、长期记忆、有损摘要分别标来源。软区优先级：近期回合、相关有效长期记忆、相关召回、有损摘要、可选角色背景/样例。预算不足从最低优先级整组移除。

max_input_chars仍是字符预算。新历史块≤6000字符、≤5组；明确引用≤12000并服从总预算。硬区仍无法容纳则主要调用前失败。

## 5. 调用执行与恢复

1. 事务外后台线程构建候选和检索，不持主库写事务等待FTS/维护。
2. 短写事务复核请求、明确引用、选中来源、记忆版本、临时状态到期及额度。
3. 自动检索故障/过期剔除召回，使用经过Scope/来源检查的基础上下文并记降级，不用旧缓存冒充证据。
4. attempt和Manifest同事务保存，提交后一次主要调用。
5. 显式重试保留输入和引用绑定，当前模型/设定重新构建，旧Manifest保留；不自动重试。

关闭召回只恢复近10轮选择，不关闭Scope、撤回、实际发送资格和Manifest检查。

## 6. 接口与工作台

管理员/v1/manage：interaction.current/update增加上下文模式/跨会话，沿用expected_version、operation_id和选择冲突，省略字段保持原值。context.preview按任务类型、Scope和请求/任务预览分区、来源、预算、缺口，零持久副作用；context.inspect读取历史Manifest，原文展开重新核验权限/撤回。桥接无政策修改及上下文枚举权限，旧聊天/引用兼容，健康增加能力标识。

工作台提供按人格/入口的两开关、本轮硬软区/版本/来源/裁剪/字符/降级/hash、五种Builder只读预览及未就绪原因。失败保草稿，切人格/入口/目标清失效选择，拒绝过期响应。政策切换遇收集中批次须选封存/取消，不拆成多个收费请求。
