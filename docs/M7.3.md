## 已实现行为

- 同人格、用户、渠道及QQ账号/联系人只有一个权威活动会话。旧channel_sessions保留为兼容投影；历史归属不清的会话未纳管，不用当前QQ设置补造归属。
- 运行期间30分钟无有效输入、生成终结或投递推进后自动封存。每5秒检查；重启重新观察，不把离线时间计入空闲。重复输入、读取、整理和主题操作不续期。
- 收集中/等待容量/未处置中断输入、排队生成及未终结投递阻止封存。封存界面显示阻塞，使用原输入或投递处置，不自动取消或追加模型调用。
- 封存和新输入使用修订号复核。封存后原会话不接受新事件、笔记和原地重试；重复受理仍返回旧回执。接续创建新Session，不搬迁历史，也不打开跨会话召回。
- SessionPackage是不可变ID/顺序/哈希/资格/版本清单，正文仍由权威档案读取。回放不调用模型、不发送消息；撤回后保留包的历史元数据，但失效正文不进入普通证据。
- QQ只使用sent片段作为发出文本；resolved不是sent。桌面生成内容标generated_only，用户已读无证据时未知。
- 封存只生成手动整理和M8延后触发。整理复用M4队列、额度与Reflection Manifest；一次最多10完整回合，后续批次须手动提交。候选只引用用户Event，保持人工审阅。
- 可复用的旧桌面M4覆盖先逐项复核原文，再复用并适配摘要来源。旧QQ语义摘要不能证明实际part覆盖，预览明确列出缺口；显式重建单独标记。
- TopicSegment选择封存会话中的连续完整有效回合；Thread只关联同Scope主题段。标题/说明属于人工标注，主题不参与自动召回。版本、操作号、操作者与撤回影响可查。
- OrganizationDecisionProvider禁用适配器返回DEFER/provider_not_enabled，不读取模型凭据、不调用模型。

## 工作台使用

1. 在“会话与主题”选择人格和入口。QQ核对Bot及联系人；点击“读取会话列表”“查看状态”。历史浏览不改变聊天目标。显示上海时间及估计空闲计时，最终封存资格以服务复核为准。
2. 点击“只读回放”检查完整输入及实际发送状态。“封存会话”前会提示原会话只读；有阻塞先进入“处理输入阻塞”或“处理投递阻塞”。旧整轮账本可审计放弃后续发送，不能伪造送达。
3. “新建接续会话”返回新ID，桌面聊天切到新会话，清除旧引用、保留草稿。QQ继续通过真实入口的新消息建立/使用活动会话。
4. “整理预览”核对来源、覆盖、排除和预计批数，再提交本批。封存、预览和M8禁用触发均不收费；手动提交整理可能收费。
5. 回放中选中连续完整回合，填写标题/说明创建主题段。创建Thread，分别查看两者当前版本后关联；同Scope跨会话允许，跨入口禁止。
6. 查看Thread后选择关联主题段，查看主题段以展开回合列表。“查看所选回合”跳到权威档案重新校验；桌面资料可在档案页选择明确引用，QQ资料不能跨入口注入桌面聊天。
7. 后台刷新和失败不清空编辑草稿。切换人格、入口或目标后旧响应失效，不能把旧引用自动发到新身份。
