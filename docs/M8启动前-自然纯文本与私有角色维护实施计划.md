# M8启动前：自然纯文本、M7归档与私有角色维护

2026-10-29，用户已批准执行。本文为脱敏公共合同，不包含个人角色姓名、正文、身份编号或源文件指纹。

运行时0.7.5.dev3；主库15、导出12、配置2、桥接0.7.0及原生角色格式不变。不启动M8、不迁移主库、不重跑M7质量集。

## 自然纯文本

系统级Dialogue合同覆盖四种回复模式、窗口与QQ，不要求用户在消息中提醒格式。正文不用Markdown标题、强调、围栏、表格、引用块、装饰性列表或链接包装；技术代码、运算符、缩进、URL、数字及版本号作为数据保护。内部回复与选择JSON协议不变，不作为聊天正文展示。

两个独立硬门：真实生成的语义正文自身须满足自然纯文本；故障输出经过共用展示转换后也不能泄漏格式或破坏正文。清理成功不等于原始生成质量通过。转换失败不发送半批，不追加模型修补或自动重试。

新增派生display_reply和presentation诊断，原生成事件/ReplyBatch保持。转换版本、原始及残留格式类别、显示哈希写入现有结果诊断JSON；已持久Manifest不改。QQ片段入账前转换，桥接发送前校验正文及哈希，不改写已领取片段。历史内容仅派生显示，已发送记录不重写、不重发。

## 验收与历史口径

新样例使用正常人会发送的内容，不追加格式/拟人提醒，工程标识放请求ID。此规则不禁止用户自行表达格式偏好。

旧含格式提示的真实样例只证明有提示条件下生成/投递，不能证明无提示的自然输出；其合批、引用、版本、调用次数及平台ID证据仍有效。原失败、输入和结论保持，不重跑旧72次、24次或M7.5独立集。

32个固定离线场景＋必要受影响检查；实际固定6次主要调用（通用窗口1、通用QQ1、私有副本窗口4），修复最多2次；选择最多4＋2次，总实际请求上限14。无候选不补足，不增加探针或评分模型。第五次连续失败或QQ中断停止，额度finally恢复。

## 私有接入与维护

私有产物一律留运行目录private/personas/下，原始MD/JSON按字节存档；源文件哈希、正式身份、版本、关系、技术适配和待接入能力仅本地保存。数据库仍是运行角色正典唯一权威，私有登记只管理隐私、测试保护和来源映射。

使用合法原生包原样创建全新身份，关系按作者指定原文设置；不继承工程人格历史，不预写记忆、开场故事、梦境或共同经历。创作者专用章节、未来剧情及未实现能力不进入聊天/Embedding/云端，不伪装为已实现状态。仅必要可见设定可交给已批准的现有主模型和选择模型；地址/模型身份变化须重新授权。

验收不得写入受保护正式人格。临时副本使用独立运行目录、新身份、可见角色资料和初始关系，不复制正式经历或隐藏原稿，默认不接QQ。关闭后删除数据库、索引、正文日志、截图和备份，只留无正文的最小审计。

后续技术维护先测副本，再对正式身份零调用检查；保留Persona ID、真实经历及文学文本。发现文学差异停止，不自动润色、压缩、补写或重新导入替代升级。

## 顺序、发布及退出

1. 冻结现有M7未提交成果、设置和服务初态，保全私有原件。
2. 完成共用纯文本、私有登记/保护、32场景及受影响检查。
3. 通用窗口和唯一真实QQ自然消息通过，恢复测试设置。
4. 先提交源码/测试/工具，再提交文档及十份施工计划；普通推送origin/main。扫描工作树、暂存区和待推送历史，本地pre-push检查不可用时拒绝推送；已有钩子串联保留。
5. 推送后仅在本机验证私有临时副本、清理副本、导入正式身份。正式设置natural_batch（5/15秒）、natural_structured、working_set、跨会话关闭、hybrid_llm/v2，索引就绪后选中。
6. 恢复原额度、每日设置和服务初态，保留批准的新正式身份及政策。本机详细结果不追加进Git。

副本失败不切正式身份；修复预算不足或涉及文学决定时停止。旧M4 O01–O03、M5 P09、M6.1付费续跑条件继续携带。没有自动记忆、无人值守或人格演化施工。
