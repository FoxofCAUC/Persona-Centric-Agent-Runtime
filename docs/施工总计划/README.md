## 新的产品定位

PCAR 要提供一位具有完整人设、稳定人格、独立对外形象、真实互动历史的 AI 朋友。角色身份和历史由运行时持有，模型提供可替换的计算能力。人设提供外貌、背景与社交形象；人格提供相对稳定的行为规律；真实经历提供时间连续性。

建设同时沿着两条主线展开：当前一轮交流自然、有语境、能接住连续短消息；几周或几个月后仍能定位原话、接续主题、解释变化。两条主线都必须保留数据完整性、失败恢复和用户控制，不能用自然度抵消虚假共同经历或重复投递。

“大肥鱼”在讨论中指一类社区角色及实现生态，不能当作单一架构。参考项目中已有丰富的社交表达与记忆实践；PCAR 不宣称全面领先，也不把“所有同类项目只有 Prompt”作为立项依据。具体借鉴见 [许可与参考清单](07-参考项目借鉴与许可.md)。

## 本套文件采用的状态标签

- **[事实]**：代码、已读取文件或实际工具结果支持；注明来源。
- **[需求]**：用户明确提出的目标，不自动等同于实现细节已确定。
- **[既有决定]**：当前仓库已经采用的策略。
- **[原讨论建议]**：历史助手提出，仍需工程化或评估。
- **[本计划决策]**：本次施工设计采用的建议基线；实现阶段按影响范围冻结。
- **[待定]**：需要样本、兼容性实验或产品选择；有保守默认值时先据此开发。
- **[未实现/待验]**：不得标记为已交付或通过。
