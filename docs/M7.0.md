## 实现与兼容

新`archive.list/get/resolve/preview`只在管理员管理面提供，桥接不获得档案枚举。范围固定为人格、用户、渠道及QQ账号/对端。平台键多候选ambiguous，未知/不可用不语义替代；审计与普通读取分离。旧载荷、历史快照、Event/Receipt和片段ID不补造。

`/v2/ingress`的reference随原文参与指纹和加密日志去重，受理事务固定解析结果及来源hash/成员ID。新引用载荷parser_version=2；无引用保持既有解析版本。执行前复核已绑定来源，不因新平台键碰撞换目标；失败保存检查记录并零主要调用。完整引用块最多12000字符，先裁可选历史背景，不拆成员；批内一项引用失败整批停止生成。

有效引用不递归展开旧引用：恢复所属回合的所有用户输入；QQ只注入确认sent的实际纯文本，未确认片段保留状态；桌面语义回复标generated_only。已读未知。历史和明确引用按turn ID去重，不新增理解、评分或修补调用。

本机SDK原转换会自动get_msg。本项目host在运行SDK前安装进程内guard，固定get_reply=False；签名不兼容拒绝启动，不改安装包文件或其他项目。普通无引用旧客户端兼容；引用新插件遇旧服务拒绝，不剥离引用降级提交。
