# 模型供应商支持总则

适用于后续开发、验收、部署和维护。

- **当前项目仅对DeepSeek官方API提供重点适配与验证支持，后续开发优先支持官方DeepSeek。** 默认接入基线为`https://api.deepseek.com`，模型ID以官方当前目录和本机已保存配置为准。
- 其他供应商、第三方中转站及代理服务不在本项目的服务质量保障范围内；标准协议兼容不代表其可用性、响应速度、输出质量或功能兼容已获保障。
- 新增模型能力、结构输出、超时、用量、错误诊断和真实验收先覆盖官方DeepSeek。不得把中转返回、品牌别名或其他供应商测试结果当成官方API证据。
- 支持声明不代替阶段质量门。当前官方API连通及R06生成已完成，人工盲审、任务缺陷复评和Live门仍按实际进度判断；模型正文仍须通过项目校验。
- 保留用户显式配置其他兼容连接的能力，不自动切换供应商，不绕过私人资料授权、额度、TLS、来源和调用前审计。
- 用户明确要求删除的数据须直接清除，同时处理相关原文、回合、派生物、缓存、备份和运行记录。不得另存副本、墓碑、删除清单、内容指纹或详细删除审计来变相保留。该明确删除授权优先于历史保留约定。
- 生产资料、密钥和运行数据不入Git；作者设定与当前官方DeepSeek材料按既有权限保存。
