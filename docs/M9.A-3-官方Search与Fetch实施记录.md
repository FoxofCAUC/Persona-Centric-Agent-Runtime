## 工具执行与资料使用

本包使用官方原始JSON接口：Search为POST /v1/tools/search，Fetch为POST /v1/tools/fetch，固定官方HTTPS主机。2026-11-11核对[官方指南](https://api-docs.deepseek.com/guides/search/)、[Search接口](https://api-docs.deepseek.com/api/search/)和[Fetch接口](https://api-docs.deepseek.com/api/fetch/)。参数、计费及适用限制见[冻结合同](../templates/knowledge-web-contract.json)。

1. 当前触发规则进入知识职责后，LLM从管理员已登记的公开主题中选择ID，PCAR复制对应查询词执行Search。每次最多3个主题，每个返回5项，need_content=false；不发送ori_question，不把用户原始问句、私人经历或作者材料拼成外发查询。登记主题应由管理员确认公开性，不是自动隐私分类器。
2. LLM只从实际获准搜索结果中选择最多3个页面ID。PCAR校验URL及精确域名白名单后调用Fetch；模型不能创建任意URL或额外查询字段。初始域名为中文Wikipedia及Wikidata，默认关闭且无登记主题。新增站点须显式登记。
3. 搜索摘要只参与选择。Fetch返回的完整Markdown正文保存为来源版本，再进入已有分段、知识翻译和独立复核流程，主模型接收自然语言知识和出处句柄。正文过大明确失败，不将部分正文伪装成完整证据。
4. 网页资料按source_claim保存，独立复核意见仅是处理记录；不能把“来源声称”直接升为已核对事实。版本身份包含所属角色、URL、正文SHA-256和来源日期；抓取时间与来源日期分开，未知来源日期及许可保持未知。
5. 词法／ANN未在本次联网代表验证中启动。现阶段由显式联网开关选择这条路径；语义判断仍未替换为Jev，因此自然问法漏触发问题不能宣称整体解决。

请求URL只允许HTTP／HTTPS、标准端口、已登记域名，拒绝凭据、片段、控制字符及IP字面量；Fetch派发前校验所有本机DNS结果均为公网地址。PCAR不直接抓取目标网站。供应商Fetch响应没有最终重定向地址，记录为provider_does_not_report_final_url；该检查不能证明供应商内部重定向链或其解析结果，未虚报已完成此项验证。

## 生命周期、费用与管理

复用ManagedOrganization的队列、单执行位置、租约、额度预留、回执和发布事务，自动调用仍60次／小时、240次／滚动24小时。Search／Fetch以原始响应单独留账，HTTP失败也保留响应。明确408／429及可重试5xx按1／2／4秒有限重试，最多4次；效果未知不重放。已保存回执恢复不产生第二次工具请求，成功结果可按来源政策及新鲜度桶复用。

网页正文和失效映射放在既有权威数据库。默认新鲜度24小时；更正产生新版本并退役旧版本，明确撤回持续生效。缓存、历史回答、出处、生成前及投递前沿统一证据校验。关闭处理职责时明确阻断联网知识回答，不回退原始正文或本地旧路径。

增加knowledge.web.policy.current／update和knowledge.web.withdraw，沿用版本检查与operation_id；knowledge.manage.show提供角色所属网页版本、当前失效版本和工具费用。工作台可登记公开主题、域名、启停及撤回已获取页面，无独立密钥输入。导出21携带网页来源与失效记录，导入重新绑定角色且默认关闭授权，不携带执行缓存和密钥；恢复合并不能清除当前撤回记录，也不能通过额外失效ID影响其他角色。

按官方文档，每次成功工具请求估算0.00075美元；错误和空结果按合同记录。管理页将工具请求费用与模型tokens分开，并标注“文档估算”，实际账单金额保持未知，不冒充账单结算。主回复费用沿已有主调用账目保存。
