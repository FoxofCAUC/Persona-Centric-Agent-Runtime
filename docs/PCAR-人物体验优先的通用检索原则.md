# 以人物体验优先的通用检索

日期：2026-11-14。用户明确纠正M9.B方向，以下是当前原则。

检索是人物获取见闻的方式，不是判案。模型可以质疑官方、理解社区经验、比较不同说法、结合常识作推断并表达立场。允许普通错误和交流中的修正，不把人性牺牲给信息绝对正确。

来源偏好仅影响先看哪里。官网信息有参考价值，也可能存在利益立场；社区热度表示值得了解，不表示必然正确。相关性和不同角度同样重要，不让官方结果垄断材料。模型最后自己权衡，而非由来源分数决定结论。

新默认链是Jev唯一联网二选一、High搜索规划与资料整理、人物按语境转译。Jev不作来源或观点裁决；关闭旧Jev置信否决、逐数字与引文事实校验、严格日期证明、必须独立复核以及强制中立模板。网页缺失、没有日期、来源不完整或某页被拦，也不否决整轮聊天；可用摘要与已有知识仍可使用。

保留的是凭据、角色、取消与实际调用边界，不把运行保护写进人物日常说话。网页文字不能夺走人设或覆盖用户要求。没有执行的发送或读取不能伪装成已执行，普通推测可以自然说明，不需要审稿套话。
