# 第一次使用 PCAR

本指南适用于 **v0.3 Windows 桌面包（程序 0.3.0，数据库结构 36）**。部署命令与旧数据升级步骤见[同版本部署手册](../../AGENT_INSTALL.md)。

从 v0.3 桌面包使用新版 Windows 工作台时，可以[从私聊记录创建角色](双人聊天生成角色卡.md)或[接续历史聊天](历史聊天接续.md)。

在左下角「应用菜单 → 外观」选择浅色模式、深色模式或跟随系统。首次打开默认跟随 Windows 的应用颜色，系统切换时工作台会同步换色。手动选择即时应用并保存在本机，重开后直接沿用。浅色使用柔和的暖灰绿底，深色使用低亮度的灰绿底，两套配色都保留聊天正文、输入提示和按钮的可读对比度。

在聊天输入框上方打开「输入缓冲」，可为当前角色选择逐条发送、定时缓冲或无限缓冲。定时缓冲可设为 1 至 3600 秒，每加入一条都重新计时。无限缓冲下，点击「加入本轮」暂存消息，关闭再打开同一会话仍可继续添加。点击「确认发送本轮」后，已加入的消息才会按顺序一次发送。每轮最多暂存 20 条、共 12,000 字符，达到容量时会保留草稿，由你确认发送或取消本轮。

新版工作台默认关闭本机模型调用限额。要控制调用次数，打开「应用菜单 → 高级设置 → 模型调用限额」。达到限额时可以等待，也可以临时放行本轮消息和当前受阻的后台任务，无需重发。[限额与弹窗操作](../acceptance/修补包4-前后台调度与模型调用限额.md#用户操作)

## 准备什么

| 需要准备 | 说明 |
| --- | --- |
| Windows 电脑 | 已验证 Windows 11 x64 |
| 部署 Agent | Codex、DSH，或其他能读写本机文件并执行命令的 Agent |
| 模型服务 | 基础聊天所需的接口地址、模型名和你自己的 API 密钥 |
| 网络与代理 | 有效的 Windows 手动 HTTP/HTTPS 系统代理；仅 PAC 的配置暂不支持 |
| 存储位置 | 分开的程序、数据、工具目录，均选当前用户可写的位置 |

Agent 会准备 Python 3.12 x64（含 Tkinter）、uv 和依赖。桌面包已包含公开的本地检索模型，仍需联网准备其他依赖。

模型服务可能收费。发送消息、显式测试、重试、记忆整理或联网任务都可能产生调用；打开窗口和保存配置本身不调用模型。密钥通过本机安全输入填写，不放进截图、仓库或公开反馈。

## 桌面包和环境准备

取得 `PCAR-v0.3-Windows-x64-desktop.zip` 和 `SHA256SUMS.txt` 后核对摘要，解压到新的程序目录。桌面 ZIP 内置固定版本的本地向量模型和公开人工演练包。[v0.3 发行页](https://github.com/FoxMoreland/Persona-Centric-Agent-Runtime/releases/tag/v0.3) · [桌面 ZIP](https://github.com/FoxMoreland/Persona-Centric-Agent-Runtime/releases/download/v0.3/PCAR-v0.3-Windows-x64-desktop.zip) · [SHA256SUMS.txt](https://github.com/FoxMoreland/Persona-Centric-Agent-Runtime/releases/download/v0.3/SHA256SUMS.txt) · [环境准备与升级命令](../../AGENT_INSTALL.md)

三种数据方式各有用途：

- **第一次使用：** 新建空数据目录，再创建角色。
- **换电脑或换位置：** 将自己的完整迁移包导入空目标，保留原实例备份。
- **已有可用实例：** 登记原数据位置，保留原数据和环境。

已有工作台先正常退出。迁移时先核对原资料，再启用目标；不要用新建流程覆盖旧数据，也不要向正式实例导入包内人工演练数据。详细步骤见 [本版部署手册](../../AGENT_INSTALL.md)。

已有 v0.2 数据时先正常退出旧工作台并备份，再登记原数据目录，结构 33 升至 36。旧版迁移包先用对应版本恢复到空目录，再升级。

## 发送第一条消息

环境准备完成后，双击程序目录的 **启动PCAR-新版.bat**。打开「人物」新建或导入角色，配置自己的模型连接，选中角色和会话即可聊天。使用已审私聊装配时，登记文件后在「会话授权」确认接收方。包内另提供原 Tk 入口。[私聊装配和模型分工](../../AGENT_INSTALL.md#登记已审私聊装配)

首次体验可以先保持联网和自动记忆关闭，只配置基础聊天。人物资料与会话保存在所选数据目录中，下次从同一入口打开即可接续。

## 再按需要开启其他能力

**自动记忆。** 新建、原生导入和复制的角色默认关闭自动记忆。配置整理模型、确认资料使用范围后，按角色开启；工作台运行期间会自动提取、复核和整理后续交流中的重要信息。操作参考 [自动记忆手册](../acceptance/M8.D-自动记忆验收手册.md)。

**联网查资料。** 在“联网与资料”页为当前角色开启按需检索。Jev 使用自己的凭据判断是否需要上网。人物先在对话中接话，发言显示后 DeepSeek Flash 开始原生深度检索。私有人物使用获准的公开问题。参见[本版部署手册](../../AGENT_INSTALL.md)。

**场景发言。** 为需要启用的角色准备获审场景材料，登记 v8 Pro 与 Jev 1.14 的用途授权。新安装默认关闭。[场景发言接入与回退](../expression/E.N6-场景发言接入与回退.md)

**数据与备份。** 人物、聊天和记忆保存在本机数据目录；调用云端模型时，相应材料会发送给配置的服务。备份与迁移按固定版本手册执行，新机重新输入密钥并确认角色资料授权。

## 正常退出与求助

新版工作台在本机聊天服务或存储需要维修时会显示「修复中」。完成后自动回到原会话，修复期间也可选择「安全退出工作台」。收起托盘后，后台继续接收已经受理的回复。使用应用菜单完全退出时，点一次即可，PCAR 会保存已有结果并自行复查暂时被占用的组件。

需要找回较早的人物或聊天时，在应用菜单打开「高级设置 → 本机备份与恢复」，查看备份时间，点「选择恢复位置」。工作台在所选位置新建核对目录，显示该副本和当前实例的记录数。换电脑或迁移整个实例使用完整迁移包。[备份内容与恢复操作](../acceptance/修补包6-巡检备份退出安装与本地修复.md#从备份恢复到独立目录)

工作台与托盘运行期间，已开启的后台任务会继续工作。正常退出时等待清理完成；如果退出失败，窗口会保留并显示原因。仅最小化到托盘不等于退出。当前日常入口为工作台，QQ 接入暂停。

| 遇到的情况 | 先检查 |
| --- | --- |
| 环境准备失败 | Windows 手动代理是否开启、目录是否可写、Python 是否为 3.12 x64 且含 Tkinter |
| 服务没有启动 | 首页显示的具体错误；不要占用或结束不属于本实例的端口与进程 |
| 发消息失败 | 是否已选择角色，模型地址、模型名和密钥是否正确 |
| 记忆或联网没有运行 | 对应配置、当前角色的开关与资料授权是否齐全 |
| 换机后不能调用 | 迁移目标是否重新配置凭据并完成启用 |

仍有问题时，在 [Issues](https://github.com/FoxMoreland/Persona-Centric-Agent-Runtime/issues)注明实际使用的版本、出错步骤和可公开的错误信息。附图前移除密钥、私人内容与本机身份信息。
