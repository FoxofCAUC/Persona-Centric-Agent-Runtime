# 新版工作台 Windows 试用与回退

新版是 PCAR v0.2 的工作台候选。使用 Windows 11 x64、Python 3.12 x64（含 Tkinter）、uv 和 Microsoft Edge WebView2 Runtime。两个启动入口可依次使用同一份结构 33 数据。

## 第一次打开

1. 按随包的 SHA-256 校验值核对 ZIP，解压到独立程序目录。保留原有 PCAR 程序目录。
2. 双击 `启动PCAR-新版.bat`，为新实例选择一个专用空目录。程序可以使用包内的公开检索模型。环境准备和依赖下载使用当前 Windows 用户的手动 HTTP/HTTPS 系统代理。
3. 从「开始第一次聊天」任选配置 DeepSeek 连接或创建角色。两项就绪后点击「开始聊天」，发送仍由你决定。已有的角色 JSON 可通过「新建角色」预览、修改并确认创建。

## 接续已有 v0.2 实例

先从旧工作台正常退出。按原部署手册备份资料，再从新版程序目录双击并选择原数据目录。已有结构 33 实例继续使用原来的角色、会话、记忆和配置。若实例缺少新版窗口组件，启动入口会补齐锁定依赖。准备期间保持这个实例退出。

需要重新选择数据目录时，可在启动脚本中显式提供 `-RuntimeHome`，或按部署手册更新本机的程序定位。准备或启动失败时先看窗口提示。准备日志位于所选数据目录的 `logs/environment-prepare.log`。[v0.2 部署手册](../../AGENT_INSTALL.md)

## 临时回到旧工作台

1. 在新版应用菜单选择「退出工作台」，等待该实例的组件退出。收起到托盘会继续运行。
2. 双击候选目录的 `启动PCAR.bat`，或从保留的 v0.2 程序目录启动旧工作台。两种方式都选择同一个结构 33 数据目录。
3. 旧工作台可读取新版已保存的人物资料、版本和记忆。再次打开新版前先正常退出旧版。新版未发送草稿会在新版窗口中按原会话恢复。

使用结构 27 等历史版本时，按对应版本的迁移与备份流程操作。结构 33 和更早结构的回退分别使用适配的数据副本。[升级与回退约定](../../AGENT_INSTALL.md#验收关闭与回退)
