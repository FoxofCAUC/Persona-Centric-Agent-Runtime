# 从双人聊天记录生成角色卡

打开当前仓库或双人成卡候选包中的 `启动PCAR-新版.bat`，在「人物 → 新建角色」使用「从聊天记录生成」。新实例自带经审定的提示词。需要从文件导入时，点「导入提示词文件」，在候选包根目录选择 **双人角色卡提示词.json**。使用源码工作区时，直接使用相同的内置版本即可。窗口会显示当前使用的版本。提示词文件可以重复使用。

从旧工作台升级时，先退出原窗口，启动新版并选择原来的数据目录。首次使用新版会补齐界面依赖。

1. **选择聊天记录。** 支持 Moect v1.3.0 的微信私聊 Markdown，也支持用二级标题逐条标明说话人的通用 Markdown。预览双方、日期和消息数，有重名或引文归属问题时可逐条修正。
2. **确认并分析。** 核对本次会发给官方 DeepSeek 的脱敏片段和调用范围，按窗口提示配置你自己的模型连接。确认后，PCAR 分别提炼两人的观察，按需归并，再用一次额外请求同时生成两张卡。步骤和用量在本次导入中记录，云端生成可能产生费用。
3. **核对已填字段。** 切换 A、B 查看人设、语言风格、本人原话、日常等四个场景、兜底和 Jev 判别说明。已核观察可回到原文。模型生成的表达文案可直接编辑，缺少本人依据的基础事实留给你填写。遇到严重冲突时，弹窗列出涉及的人物和字段。按提示定位，修改或明确留空后继续。
4. **保存并开始聊天。** 选择当前人物或同时创建两人并保存。只有所选角色的冲突需要先处理，普通建议可直接使用。现有必填项会在表单中定位，年龄、身高等可选资料可以留空。默认从空白会话开始，也可确认本人身份，把这段历史接到对侧角色。Jev 和场景资料齐备后可以启用场景发言。[历史聊天接续](历史聊天接续.md)

提示词包版本为 `pcar-import-prompts-v1`。它包含三段通用模板，发布清单记录了 SHA-256。模板的加载与导入均在本机完成，模型请求在用户确认本次资料范围后发出。 [详细验收记录](../acceptance/LT-13-双人成卡与场景启用.md)
