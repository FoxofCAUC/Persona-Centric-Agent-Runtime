## 实施前必须冻结的问题

| 决策 | 需要输入/证据 |
| --- | --- |
| Session开始、空闲、手动结束与异常中断 | 明确用户操作、时间语义和重启边界，不能用窗口关闭等同事实结束 |
| Thread/TopicSegment与现有session关系 | 给出最小DTO和来源成员归属；避免为话题变化复制权威原文 |
| 封存结果及后处理授权 | 区分有损摘要、证据、候选和正式提交；NO_CHANGE有效，不自动扩大M4授权 |

| 任务幂等、租约、重启与预算 | 明确哪些可自动恢复、哪些须显式继续；主要模型不自动重放 |
| Scope、撤回、版本与检查清单 | 非首成员撤回须使所有派生结果退出使用，旧Manifest不授予原文永久访问权 |
| 迁移、导出及回退 | 先按实际改动选择最小结构，不提前占用编号或预建表 |
| 验收与真实调用限额 | 先人工固定集与故障模拟，再批准有界真实样例；不重做M6旧72次 |
