## 1. 目标和边界

实现CharacterCandidateRetriever内部接口，协调精确事实、词法和真实本地语义候选，具备拒识、歧义处理、依赖整组和预算选择。版本继续0.7.5.dev1，主库14/导出11/桥接0.7.0，模型和依赖沿用M7.5.1冻结制品。

不迁移主库、不扩展CharacterSpec、不新增公共API/工作台政策、不改变正式聊天调用链。原select_context保留生产和对照路径；本包新增可选members参数，仅内部新调用使用，默认行为保持。新增逻辑不等于hybrid已开启；.3接上下文/Manifest，.4唯一正式联合验收。

## 2. 输入与检索合同

内部retrieve显式接收persona_id、不可变version_id、有序members、lexical/hybrid、可选scenario和example_limit=2/4。正文成员数量1–20，每成员保留现有24000字符上限；无效输入拒绝。指定版本从现有CharacterService读取，不偷读最新head。

只使用现有Lorebook标题/关键词、表达样例及dependencies。人工关键词可作为别称，不从正文提取新实体、不创建关系边、不新增正典字段。结构化事实继续read_fact/现有别名合同；未知值不可由近似背景填补。表达样例标记creator_setting，不成为真实经历证据。

处理顺序：范围/版本/可见性 → 精确事实 → 分类型词法/语义候选 → 拒识/歧义 → RRF稳定融合 → 依赖/预算 → 权威复核。

- 词法逐成员大小写归一化字面匹配，不执行正则/脚本，不跨成员拼成关键词。hybrid的ASCII词项采用ASCII字母数字/下划线边界，中文保持字面匹配。
- 一次编码全部成员；底座新增可选per_kind_limit，原默认query输出不变。Lorebook和样例分别最多10个语义候选，避免互相挤占；不隐式下载/重建。
- 精确事实不参加RRF。其他合格候选两路等权RRF，k=60，两类独立排名；同融合分按词法强度、人工priority、稳定ID排序。标题命中权重2，关键词/场景权重1；优先级不绕权限或拒识。
- 语义独有候选必须达到该类型阈值。共享标题/别称若没有同成员内的唯一词法区分线索，则拒识，不能以最高cosine猜一个。多个成员各自明确不同实体时，保留各自已区分候选。
- cosine不是置信度；允许无结果，不能强行填满背景。

## 3. 参数、依赖和输出

先冻结32例开发集（16正/16负）与哈希，再计算本地分数。两类阈值各从0.40至0.90、步长0.025选择：首先负例零错误激活，再最大化正例目标条目覆盖，并列取高阈值。拒绝全部语义候选不能称为交付。版本化内部配置绑定模型/语料哈希，不增加入口政策字段。

保留身份800、动态事实/设定1600、样例600、总3000字符（计序列化和头部）；Lorebook至多4项含依赖，深度至多2，样例2或4。循环/缺失/禁用/私有依赖整组拒绝。共享依赖按并集仅计一次；总预算裁剪先移除末位样例，再移除末位可选根组，最后移除非必需锚点，每步重新生成依赖并集。必需事实放不下时明确失败。

结果包含人格/版本、算法配置指纹、模型/索引指纹、fact_paths、candidate排名、selected/rejected/removed/degrade_reason、命中成员和词项、依赖组、分区预算以及内部parts/text。diagnostics排除parts/text；不复制完整输入/正典/向量。结果明确activation_authorized=false，.3仍须在真实调用前复核。

软故障（缺模型/依赖、校验失败、缓存缺失/损坏/忙、推理或资源故障）只降级一次到同指定版本的原词法算法，不重试/下载/构建。越权、版本不存在、来源复核失败、危险路径不能降级掩盖。CPU推理不持主库写事务。
