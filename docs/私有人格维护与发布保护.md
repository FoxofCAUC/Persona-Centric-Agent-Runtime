# 私有人格维护与发布保护

本文件只记录通用机制。个人原创角色及其台词、隐藏正典、姓名/身份、原件哈希、截图和测试正文不得写入公共材料。

## 本机登记及使用

使用D盘虚拟环境，运行python -B -m persona_runtime.private_personas。register接受原生包、文学原稿及作者指定关系文件；原件按字节存档，文学段落不自动提取补写。status只显示数量；import以稳定操作号创建独立身份和初始关系；check是零模型调用的原文/运行资料一致性检查。详细路径与记录编号只在本机传递。

工作台人格列表显示“个人私有／禁止原体验收”，“私有兼容检查”读取本地登记及权威版本，不上传或调用模型。没有隐式公开分享功能。已批准云端模型只接收当前必要的可见设定，隐藏文学原稿始终留本地；模型地址或名称变化时阻止未批准的传输。

原生包不含共同经历，文学开场不等于已发生聊天。正式初始化不创建Event、Session、长期记忆、摘要或主题，不导入工程人格历史。

## 测试隔离

任何验收脚本先检查受保护状态，再开始不限额、选择人格或写测试数据。正式私有人格不能作为验收目标；不限额启用时也不能切到它，显式指向它的入站、资料编辑、笔记、记忆或整理写入被拒绝。普通日常聊天不因私有标记而禁用。

clone只在运行目录tmp/private-acceptance/创建带归属标记的临时副本；只复制可见JSON、初始关系及获批模型指纹。不得复制隐藏MD、正式聊天、记忆或状态。private_copy_workbench工具有4次主要/4次选择上限，只接窗口，不接真实QQ，不发探针或评分调用。

测试关闭后，先清理API/工作线程及模型准备，确认实例锁可释放，再删除限定目录。cleanup拒绝正式根、无归属标记、重解析点、归属不符或仍在运行的目录。正文、缓存、截图和备份不保留；无正文的结果/调用次数/哈希审计仅本地存放。不得声称本地删除会撤销供应商已经收到的请求。

## 后续版本维护

开始后续阶段先读本机私有登记。先在可删除副本中检查新格式、字段、年龄、索引、上下文及导出，再对正式人格零调用核对；不能把真实验收消息写进正式历史。

技术改动必须保持文学字段原样及正式Persona ID。发现字段丢失、正文不同或原件哈希变化时停下报告；不自动补设定、改台词、改历史日期或用重新导入替代升级。未来情绪、反思、Director、演化等仅以待接入清单记录，相关阶段另行授权。

## 提交与推送

代码、通用工具、人工假资料及脱敏结论可提交。private/、运行库、缓存、截图、备份、原始角色文件及任何改名/嵌入的正文均不可提交。

private_publication_guard工具从本机登记读取私有指纹与正文特征，检查工作树、暂存区、待推送提交及二进制产物；报告只列位置和状态，不复制匹配内容。本地pre-push必须启用并保留已有前置钩子，登记损坏或检查失败时拒绝推送。只在本机注册来源，不将私有检测特征写进Git。

这是一道误发布防护，不是对抗拥有本机权限者的数字版权或任意转码识别系统。维护者仍不得绕过检查或把私有资料拷入源码目录。
