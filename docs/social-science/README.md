# PCAR 社会科学开发指导

版本：1.0；形成日期：2026-11-12。

本套文档将社会学、社会心理学与关系科学研究转化为PCAR的设计和验收建议。核心区分是：用户认知更新、双方关系适应、角色稳定倾向演化。研究结论、工程建议与待验证假设分别标明；不把人类研究直接当作已经验证的LLM算法。

## 开发时怎样使用

1. 先核对[当前状态](../STATUS.md)与[交接](../HANDOFF.md)，确认当前范围、授权及阶段依赖。
2. 先读第一册的原则与第二册的模型边界，为一个具体交流失败选择最小假设；明确哪些行为应改变、哪些反例应保持。
3. 依据第三册选择对应开发包和验收场景，映射到已有持久化、受管任务、复核、版本与撤回机制。
4. 用第四册模板记录理论支持、工程假设、证据、反证、行为指标和停止条件，再决定是否扩大实现。

召回优先级、证据可靠性与发展意义分别处理；摘要和反思不得反复充当新的独立经历。只有成长叙事而没有可复现的行为变化，不算完成稳定倾向演化。明确边界、更正和撤回应落实到实际行为与有效性过滤。
