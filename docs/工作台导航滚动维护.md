# 工作台左侧导航滚动

2026-10-29，0.7.5.dev3局部界面维护。

左侧按钮列改为独立的竖直滚动视口。小窗下可拖动滚动条，或将鼠标停在导航按钮区域使用滚轮，访问底部“故障排查”。在右侧内容区域滚动时，仍使用原页面的滚动逻辑。支持小幅滚轮输入、缩放和未来新增入口，不需要全屏。

后续导航入口继续添加到ScrollNavigation.body，不恢复为无滚动的固定Frame。当前页面切换不会重置导航位置。
