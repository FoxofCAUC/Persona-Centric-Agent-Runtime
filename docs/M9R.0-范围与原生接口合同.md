## 范围与基线

输入为[M9R开发手册](M9R-DeepSeek原生能力接入与后续研发规划.md)、当前官方合同及预先登记的人工公开问题；输出为可执行请求合同、作用域及补缺规则、五位置首次回执和工程结果。没有使用人物原件、隐藏资料、正式对话或记忆，不生成人物体验评分。

行为基线：总开关关闭时不调用Jev；Jev none时使用已有资料或直接回应；web或原异常降级才新增联网。生产链仍为Jev→High计划→独立Search／Fetch→High整理→原v8回应；正式配置、Jev连接、权限和数据库结构保持。

`persona_runtime/deepseek_native_contract.py`定义纯合同；`provider_compat.py`接入显式标记及数值工具用量白名单；`chat.py`对原生标记在外发前拒绝旧传输，避免静默丢字段。`experiments/m9r_native_probe.py`仅承担隔离探针，复用现有audited_complete的attempt身份及保存钩子，不另建生产重试账本。探针的整包接收／离线检查器不是M9R.1生产传输。

## 请求配置与输入

新请求必须显式提供`_native_web_profile`，仅支持HTTPS精确域名api.deepseek.com及deepseek-flash。允许根地址、/v1及完整Chat Completions地址；拒绝网关、其他端口、URL凭据、查询参数和其他协议路径。不凭相似型号名称推断工具能力。存量配置继续可读、可导出和当前运行，正式配置迁移另包实施。

| 配置 | 思考 | 声明工具 | 本次每步输出预算 |
| --- | --- | --- | --- |
| 普通检索 | disabled | web_search＋read_url | 2048 tokens |
| 深入检索 | enabled／high | web_search＋read_url | 8192 tokens |
| 指定链接 | disabled | 仅read_url | 2048 tokens |
| 已有资料追问 | disabled | 无 | 2048 tokens |

工具完整名称为deepseek_web_search、deepseek_read_url。不发送JSON模式、强制tool_choice或文风采样参数；与旧结构化用途冲突时调用前失败。流式要求include_usage。预算属于探针独立快照，没有修改正式参数；max_tokens限制各步输出，不是整轮费用上限。[官方工具指南](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)、[应用参数说明](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)

只接收已经形成的公开任务投影：人工公开问题，或后续经明确范围批准的问题、必要公开条件和指定URL。builder接收文本system/user与协议assistant，拒绝附带任意人物／记忆／配置对象。文字本身是否含私人信息仍由调用方根据来源和授权保证，字段白名单不能自动证明脱敏。M9R.2须落实投影来源，不把主回复完整上下文交给原生搜索，也不新增分类LLM。

## Jev与有限补缺

| 状态 | Jev | 新原生／独立工具 |
| --- | --- | --- |
| 总开关关闭 | 不调用 | 禁止 |
| Jev none | 调用 | 禁止，已有本地资料仍可用 |
| Jev web | 调用 | 原权限内允许，另记实际取得情况 |
| Jev不可用 | 保留失败／未发出事实 | 原policy_fallback，原权限内优先联网 |

原生请求完成却无工具调用，记录“完成／未取得新资料”，不视为第二个模型否决Jev；回答自述“搜索过”不是执行证据。

补缺仅限许可仍有效、Jev web或原降级、原生任务**明确完成且工具调用为0**、当前请求尚未补缺。明确搜索任务对已批准公开查询做一次Search，明确读链接任务对指定公开URL做一次Fetch；均为独立计账的新动作，最多一次。无可靠公开查询不加规划模型；普通闲聊、未知、失败、断流、已有工具或已补缺不进入此路。精确引用／长期原文保存的按需Fetch另在M9R.2定义，不普遍再抓所有结果。

## 三类数据与回传

| 数据 | 权威与用途 | 生命周期 |
| --- | --- | --- |
| 人格、经历、关系、有效记忆 | PCAR本地权威 | 按原版本、更正、撤回和迁移规则保留 |
| 可读资料 | URL、标题、取得时间、片段／正文／模型归纳，供v8消费 | 本地保留，区分原文与归纳，不能冒充用户经历 |
| 原生协议包 | 原始assistant、server_tool_calls、annotations、签名、版本 | 人物／入口／会话／账号／型号／协议隔离，可失效 |

回传深复制原始opaque字段，保留未来扩展；作用域、账号、型号或版本不符则拒绝，不能跨人物／会话借用。思考只留在本机隔离原始协议中，不展示、不写普通审计正文、不抽取为记忆。网页与归纳不能改变人物核心或权限。

搜索素材不会仅靠协议回传进入后续上下文；read_link网页可由有效signature恢复。包失效时请求仍可能成功，HTTP成功不证明记住网页。长期连续性依靠PCAR资料与记忆；重启、裁剪、新会话及迁移在M9R.3实现，本包不宣称完成。[官方多轮说明](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)

## 响应、结束与账目

非流式保留完整assistant和用量；流式进度在choice.server_tool_event，完整工具字段及引用在最终delta。进度、工具完成及正文片段不能代替整轮终态。引用偏移按Unicode码点解释，不按UTF-8字节定位。[Chat Completions参考](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)

| 证据 | 结算 |
| --- | --- |
| stop、有效正文、完整终态 | 完成，有无新资料另记 |
| length | 已知截断，保留用量 |
| content_filter | 上游拒答，保留工具及用量 |
| HTTP200内error，含无DONE的流式错误终块 | 已知失败，先读取同块用量 |
| 断流、缺终态或无法解释协议 | 未知；最后观察用量与终态用量分开，不填0 |

成功或未知物理调用不重放。探针保留首次结果，任一协议失败／未知停止余下位置，不自动转旧链或改参数重生。旧生产客户端不能保全扩展字段及HTTP200错误用量，故新标记在其外发前报provider_native_transport_required；M9R.1再实现生产传输与受管恢复。

工具结果块数、实际动作数及计费次数分别记录；计费以usage.server_tool_use中的tool_search／tool_fetch／tool_image_search为准，一次动作可含多个查询词条。有效终态用量省略该对象时，按已核对官方合同解释为三个计费数均0，标记“合同省略”，不伪称显式返回0；无终态、空用量、null或不完整计数继续未知。

价格快照deepseek-cny-2026-11-15：搜索／抓取估算CNY0.005／次。token、缓存和思考按原数值保留，reasoning不重复加到total；工具估算不冒充整轮总价或实付。历史USD账目不回写，正式独立工具计价在M9R.2更新。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

## 冻结探针与实际结果

先固定5个物理位置、0次自动重试。人工公开问题围绕DeepSeek应用API，指定链接为公开工具指南；普通／深入同题，链接首轮仅概述搜索区别，再追问未概述的回传规则。两追问均不声明工具。全程Windows手动系统代理，无网关、人物材料或真实Jev调用；Jev行为使用本地夹具验证。

调用后观察累计达到100,000 tokens、60次计费工具或工具用量未知即不启动后续位置。普通／深入探针等待180／360秒，仅限制本次诊断，断开不证明服务端停止计费。这是位置上限和请求间停止条件，**没有整轮费用硬上限**。
