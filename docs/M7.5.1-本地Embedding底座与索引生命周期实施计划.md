# M7.5.1 本地 Embedding 底座与索引生命周期实施计划

日期：2026-10-29。用户已授权实施；基线 main@624e6f0，开工工作区干净。本包仅开发及定向自检，不单独举行正式阶段验收，不自动提交推送。

## 1. 目标和不变边界

交付真正可离线运行的中文 Embedding、角色源片段转换及可重建向量缓存，供 M7.5.2 混合候选使用。开发版本0.7.5.dev1；主库14、导出11、桥接0.7.0和角色格式保持。

本包不接入正式聊天、不启用hybrid、不改变角色编辑事务、不新增HTTP管理接口或工作台设置。M7.5.2做融合与拒识，.3接入受理快照/上下文/Manifest和降级，.4唯一正式联合验收。既有精确事实、未知值、creator_only、原文/来源权限、3000字符角色预算及可靠投递合同保持。

## 2. 模型、来源与缓存合同

- 采用FastEmbed + ONNX CPU + BAAI/bge-small-zh-v1.5（512维）；具体依赖、ONNX来源、修订和文件哈希在本机探针后冻结，见[开发记录](M7.5.1-开发记录与本地模型探针.md)。不能用假向量/云Embedding替代真实本地探针。
- 依赖独立放在character-semantic可选组。未安装时旧词法及运行时可导入；未准备模型时返回明确诊断。
- 只有显式prepare脚本联网下载；装载、构建、查询、失效恢复均不下载。进程内单模型复用、并发1、ONNX CPU线程2，不建常驻宿主。
- 运行数据根使用PERSONA_RUNTIME_HOME。模型在models/character-embedding/指纹目录，索引在cache/character-semantic/v1，证据在exports/acceptance/M7.5.1-日期；下载、临时及依赖缓存都在D盘。拒绝路径逃逸、重解析点和权威数据库硬链接。
- 本包仅编码启用的conversation Lorebook标题/类别/关键词/正文，以及启用表达样例场景/关键词/正文。私有和停用项编码前排除；结构化精确事实不转为语义事实来源。
- 模板character-source-v1完整拼装字段，使用固定tokenizer按384 tokens、重叠32 tokens分块，保留字符及token覆盖位置，重新编码确认不超过512 tokens。模板文本也参与完整覆盖；不重复添加长标题/关键词造成超长，不静默截尾。查询逐成员同样分块。
- 输出float32、512维、有限数、L2归一化向量。零向量、错误维度、NaN/Inf拒绝。
- 内部CharacterEmbeddingProvider负责身份/诊断/分块/编码；CharacterSemanticIndex负责明确版本的build/query/invalidate和显式rebuild。原select_context不变。
- 缓存键绑定本地用户、人格、角色版本、源内容、模型、模板/分块/归一化和格式。独立SQLite保存元数据与向量，不保存完整设定正文，不成为第二权威。
- 按版本惰性显式准备：编辑/导入/恢复的新版本只能建立新空间；本包不挂编辑事务回调。合法旧版本保留，无自动GC。新模型/模板不能复用旧空间。
- 推理在主库事务外；独立缓存锁、临时SQLite、完成校验后原子替换。失败保留旧完整缓存。查询前后复核指定权威快照，拒绝串版本及来源失配。
- 原始候选按最高分块分数聚合，分数相同按kind/ID稳定排序；返回ID、分块、成员映射和指纹，不返回授权。依赖展开、融合阈值与最终注入不属于本包。
