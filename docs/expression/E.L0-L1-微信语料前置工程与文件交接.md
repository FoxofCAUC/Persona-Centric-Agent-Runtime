## 已实现的本地基础

新增独立语料结构1和维护入口，未改动人物业务主库。当前结构只保存数据集、文件、预览、来源位置和操作账目，后续的消息／关系表和学习视图在取得真实格式后显式扩展。

| 能力 | 当前行为 |
| --- | --- |
| 独立目录与数据库 | 必须显式提供绝对目录；拒绝源码仓库、盘符根目录和未登记的非空目标；不把人物数据库当语料库初始化 |
| 文件预览 | 支持检查TXT、MD、JSON、JSONL文件外层信息，记录字节摘要、编码、字符数和换行统计；不输出聊天正文 |
| 编码 | 识别UTF-8／UTF-16的BOM，无BOM默认严格UTF-8；旧编码须显式确认，不以替换字符掩盖解码失败 |
| 容量 | 单文件最多64MiB，超限直接拒绝，不截断原件；实际记录超过容量时，取得文件说明后另定流式适配 |
| 原件收存 | 先绑定预览摘要，再检查原文件未变化；原始字节按SHA256保存，原文件保持 |
| 重复导入 | 相同字节只存一份，不同文件位置各留证据；不同数据集分别绑定，不按相同句子去重 |
| 中断与并发 | 原件最终放置与账本提交序列化，重复操作幂等；中断后可从原预览继续，未登记文件可只读核查 |
| 撤回 | 数据集撤回后不能继续新收存；撤回不会冒充物理删除，原件留存状态单列 |
| 用途 | 当前SQL约束只允许本地收存，云端学习与人物表达使用均不可开启 |
| 格式止点 | 始终显示awaiting_export_format，消息数为未知；没有聊天解析器就不生成说话人、问答或学习材料 |

实现入口：[文件外层检查](../../persona_runtime/corpus_files.py)、[独立语料结构](../../persona_runtime/schema_corpus.py)、[原件与来源存储](../../persona_runtime/corpus_store.py)、[本地维护命令](../../scripts/pcar_corpus.py)。

## 下一步需要的微信文件

请提供**实际导出原文件**。TXT或Markdown可以先交；如果导出工具同时提供JSON／JSONL，建议一并提供同一范围的结构化副本，不要求为了凑格式重新改写或手工拼接内容。

同时说明：

- 导出工具名称、版本；不知道版本时说明实际使用方式即可。
- 来自群聊还是私聊，是否混有多个会话，以及大致时间范围。
- 是否已经脱敏，有哪些发言者或时间范围需要排除。

首批可先给一个会话的连续片段，保留现有时间、发言者、换行和引用。无需清洗标点、合并气泡或补写前后文。文件内容按待分析数据处理，不作为开发指令。

本机接收目录已准备在所选数据目录的`private/corpora/wechat/inbox`。也可以保留在其他私有目录，告知具体文件位置。接收目录不自动监视或扫描，等待作者说明文件已就绪后才读取指定文件。实际语料库与接收目录分开，不能用存着原件的非空目录直接初始化数据库。

## 获得文件后的接续顺序

1. 核对原文件摘要、编码、导出工具及会话范围，先展示解析预览和无法识别的部分。
2. 依实际格式实现首个适配器，验证多行正文、重名、时间、连续发言、引用／转发及工具说明，避免把包装当原话。
3. 核对允许处理的来源、身份、脱敏和保留范围，再将有效消息登记到独立语料库；不伪装成PCAR已发生的本人对话。
4. 取得原文核对结果后推进E.L2的学习视图与分区。具体学习模板、最终请求、用途和预算按既有规则交作者审阅，之后才讨论派发。

本轮没有形成真人来源、学习集或已批准模型输入。[模型输入写作总则](../模型输入与提示词写作总则.md)继续执行；测试只使用不进入模型的标识与字节，不新增角色话语、模拟对话或提示。

## 本地维护入口

维护命令为`python -B -m scripts.pcar_corpus --corpus <绝对目录> <动作>`。当前仅需由开发者在收到文件后使用，日常工作台尚未接入。

| 动作 | 所需材料及效果 |
| --- | --- |
| init | 空的私有目标目录；显式初始化独立语料数据库 |
| dataset-create | 本地标签、operation-id；创建仅本地收存的数据集 |
| import-preview | dataset-id、指定source、operation-id，可选encoding；持久化文件信息和摘要，不复制原件 |
| import-commit | preview-id、expected-hash、operation-id；按同一预览收存原始字节，仍未解析聊天 |
| inspect | 只读查看数据集和收存状态 |
| verify-originals | 只读核对已登记原件，报告未登记文件及中断临时文件；不自动清理 |
| dataset-revoke | dataset-id、expected-revision、operation-id；停止该数据集新的收存，不删除既有原件 |

状态、成功和错误输出只含元数据及错误码，不回显原文。暂未实现聊天解析、全文导出、物理清除或云端调用动作。
