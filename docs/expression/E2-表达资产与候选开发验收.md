# E2表达资产与候选开发验收

2026-11-16，按作者要求完成E2。候选程序0.2.0rc5、主库结构30，表达资产、授权来源、版本／回退、候选快照和受限学习队列已实现。正式实例保持结构27，本轮没有启用正式人物、接入聊天表达派发或启动新守护。下一阶段为E3独立表达运行阶段。

E1审阅确定的默认协议`expression-json-scoped-v3`保持。主稿、Jev判断、原生深度搜索及原v8编排未改；新增模块通过预留表达接点供E3消费。

## 1. 来源与资产

数据与既有业务同在主库，角色ID、用户、会话及通道范围沿PCAR权威记录，新增14张表达数据表。表达库保存“情境—说法—来源版本—角色范围”，不会写入人物设定、关系或事实记忆。

- 支持登记作者样例、获准公开人类材料，以及PCAR已完成会话中的顶层用户原话；来源必须明确授予`use`和／或`learn`。用户事件按原角色和范围重新读取，撤回、引用及非用户产物不能作为学习原话。
- 主稿、再制稿、自己的历史回复、维护摘要和测试答案没有自动来源入口；会话增量收集只登记用户事件。合成测试素材单独标注，仅在隔离实例验证，不加入正式人物。
- 来源版本和资产版本追加保存，维护操作按operation_id幂等并校验预期版本。撤回来源或更改授权使旧引用不可用，相关词条／向量失效；回退资产内容也必须重新验证当前来源，不能恢复已撤回权限。
- 同一情境和说法可合并有效来源。独立学习批次按`(asset_id, job_id)`记录一次采纳观察，含义是已发布的学习批次，不是实际发送次数或记忆强化。
- 禁用资产后，普通编辑不能静默重新启用，须显式恢复。第7组代码偏好仍作为后续表达协议选型材料，没有新增内容分类路由。

主要模块为`expression_assets.py`和`schema_expression_assets.py`，角色与来源验证在候选使用及学习发布边界执行。

## 2. 小库候选及E1合同接线

`ExpressionCandidates`在已发布且来源有效的资产中检索，最多5条，受上下文字符预算约束。无匹配或预算不足返回空选择，不截断表达内容凑数。

首版以情境、风格及显式关键词形成候选，过滤“对方／现在／时候”等通用检索词，支持人工标注的单字关键词。现有本地Embedding仅对已有候选排序，并结合相似度做多样化选择；未用未经校准的向量阈值直接激活资产。分数和检索词不进入人物提示，也不作为自然度或事实裁决门。

候选快照保存角色／范围、政策和人格版本、资产版本及来源证明。`validate`在使用前从主库重读，`scoped_texts`映射到E0的`ScopedText`；索引、向量和快照正文都不拥有来源权威。权限、来源、角色或资产版本改变会使旧快照失效。

已验证候选接入E1默认上下文装配，未新增回复生成调用。实际调用时使用的候选模块源码已按摘要归档；之后仅修正本地通用词误匹配，学习请求和首次响应保持，未补跑模型。本地真实`BAAI/bge-small-zh-v1.5`、512维排序与缓存验证通过，无下载或联网。

## 3. 学习范围、预算与后台边界

每个角色默认`enabled=false`、`learning_enabled=false`、授权会话列表为空。可一次授权至多16个本人桌面会话，按事件游标增量登记顶层用户原话，批次准备和游标重入均幂等；不要求每轮聊天审批。QQ学习输入未开放，不接转发、图片描述或隐藏档案。

`ExpressionLearning`准备冻结任务、在派发前复核来源／角色／政策与现有云端用途权限，再保存完整首次HTTP回执后派生提案。成功、未知、结果无效的旧位置均不自动重放；本地结果处理失败可以从完整回执恢复。请求或回执不可改写，退出取消保留未知并传播关闭信号。来源在请求期间撤回时，费用与回执保留，提案不发布。

默认单批最多10个来源、输入12,000字符、输出容量1024tokens；按该角色近3600秒／86400秒的派发预留限制为1／4次。未发送失败保留用量null并记不适用，真正未知用量保持未知。学习调用独立记账，本地检索不收费。新任务的表达学习用途不自动继承私人角色的主回复许可，继续经过PCAR现有用途／提供商检查。

学习结果先为待发布提案；发布是资产维护动作，可以批量安排，聊天运行不等待人工逐轮审核。已授权范围的收集和单批执行由`collect_authorized`／`step`提供，单次有界，不创建线程、服务、自启或新守护；正式组织宿主接线和统一运行状态在E3继续。E2未开启自动后台学习。
