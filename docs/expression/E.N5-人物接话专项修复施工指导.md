# E.N5 专项修复施工指导 · 让角色以自己的身份接话

当前返工进入[接话决策与人物发言分工](E.N5-接话决策与人物发言分工.md)。D0 已交付固定版本的 MaiBot 原文和首批16位判断表。原有因素试验、删指导结果及作者意见继续作为对照依据。

2026-11-18，作者批准此路线。目标是让角色在分享、吐槽、较真、求助和收尾之间自然取舍。原 v8 Pro（B）保留作对照。先风格后联网，使用作者审过的真人原话进行回放；工程因素收益不足时转作者共创。[30轮根因复核](E.N5-连续发言客服感根因复核.md)

## 冻结与接入

在本机私有目录冻结人物及字段版本、原模型与请求参数、两段各15轮原话、每轮实际呈现过的前文、首份原生正文指纹、回执和逐轮评语。原始依据须能够逐轮重建。实验条件和来源摘要随研究配置及受理快照保存，沿用现有消息、呈现和回执接口。未经选择的实例继续使用自己的冻结配置。研究元数据只用于后台。

| 方案 | 唯一变动 |
| --- | --- |
| B 原 v8 Pro | 直接取已经保存的原生正文和受理时的输入 |
| P 只改人物材料 | 在角色资料消费端按作者审过的原文字符区间，统一省略社交习惯中的任务步骤分句。其余文字逐字保留，原件继续留存 |
| H 只改额外历史 | 保留原有顺序、最近两轮及显式引用。对原排序选出的至多三对较早历史，全部匹配来自人物自己、总共只命中一个一至二字汉字词、该词在最近两轮双方文字中也没有支持时，省略该对。用户命中、多词命中、型号等按既有规则；省略处不补位 |
| PH 两项合用 | 同时应用完全相同的 P 和 H 版本 |

重点检查材料和消息的所有者、角色与版本、模型、最终请求指纹、撤回、重开、多气泡、引用及既有位置的回滚。旧位置使用冻结版本，已呈现正文从保存的回执恢复。来源失效后停止后续使用。人物主回复仍由同一 Pro 单次生成。

## 固定前文的16个诊断位置

第一段选第03、04、06、07、11、12、13、15轮，覆盖午餐分享、对象不明的求助、猜单位、揽写作、版本比较、收束、自然反问和道别。第二段选第03、05、09、10、12、13、14、15轮，覆盖人物立场、设定猜测、接错排障阶段、明确求助、已有线索、必要帮助、过早下结论与退出问诊。

先复核全部30轮 B 的消息指纹与原生正文。再核对 P 仅少指定字段的指定区间、H 仅少符合资格的额外历史、PH 严格等于两项差异的组合。五处弱词可在这批数据中验证，另一处同样是人物侧单词匹配，但获得最近两轮支持。结果文档应给出每轮完整用户输入、当时实际历史、基线与候选完整可发送消息、差异来源及等价复用索引。

通过具体输入审阅后，B 的16份旧正文直接复用。预计 P 新增16个 Pro 请求，H 新增5个，PH 另增5个，共26个。完全等价位置只展示一次并可查索引。保留首次失败、截断、未知及其回执，未派发位置才可续跑。本研究的预计数量用于核对具体实验范围。

## 盲审与分流

先分别判“可接受”“出现明显服务化”“求助没有接住”或“无法判断”，支持整轮全部不可接受以及备注，再匿名排序。相同正文折叠，完整前文始终可查。保护自然社交反问和必要技术澄清，检查第一段第7轮、第二段第3、10、15轮等关键失败或保护样本。问号数量、改字率、模型自评和相对排名都不能代填作者的绝对判断。

有单项收益且关键场景达到底线，优先选取该单项；组合候选须有额外收益。首批仍明显服务化时，交付“真人原话、失败发言、值得保留的人物反应、对应入模材料”。由作者提供或指定原文和适用范围，最小共创候选逐字审阅后先回同16位验证，不凭旧预算自动换稿或扩测。

## 连续终验与上线边界

风格通过小批审阅后，使用两个独立隔离范围，以相同人物和获审真人脚本，让 B 与入围候选各自跑两段各15轮，共60份新正文。检索关闭，各链只接续自己的已呈现发言。选材优先保持同一发言者、连续真实片段、合理时间边界，包含分享、拒绝或更正、自然转题、明确求助和收尾。标出原时刻、删节及原对方发言间隔。长时间跳跃另起会话，材料缺口交作者指定；用过的开发位置单列。提供同排版正文、完整气泡、整组固定匿名映射、失败、等待及用量，可否决整组并指出变味位置。

作者明确通过连续风格体验后，胜出版本另建 E.N5 桌面批次，两段各15轮。每段预选确实要求查公开资料的真人原话与同段后续追问，再审其原文及公开范围。按真实 Jev 决策、查前可见回执、Flash 深度检索、Pro 回复与资料复用逐项结算。预计30次主回复、30次 Jev；若两轮均触发，另计两次查前发言与两次原生检索，工具用量另记。进入 E.N6 须有30份真实正文及桌面可见回执、至少两次先呈现预告的真实联网、至少一次同段直接复用，并获作者对自然度、等待、费用与整段体验的明确认可。实际未触发时留存缺口，另提新材料定向补验。

## 首批交付与当前验收点

两项候选已接入 v8 的版本化本地消费路径。受理时冻结研究版本、人物、范围和字符区间；普通实例沿已有配置。固化的30份 B 请求分别与原消息及物理请求指纹吻合。P 保留原有工作态度与回到日常的描述，只删经此次审阅的任务步骤分句。H 实际改变第一段第6、11轮及第二段第10、12、13轮；第二段第14轮原样保留。

作者审过完整差异页并批准本批26个差异请求。全部获得官方 DeepSeek Pro 的首次完整 HTTP 200 回执。16份基线正文直接复用，16个位置的64个方案位置对应42份不同请求。新增用量29,398 tokens，计费金额以实际账单为准。每份已取得的原始响应均重新解析，并与盲审页对应正文核对；本批没有失败、未知或未派发位置。

私有状态 `en5_style_factor_result_review_page` 指向结果页。每轮匿名，以相同前文为对照，支持先逐份判断、整轮否决、可选排序和整批意见。技术页单独提供身份、原始回执指纹和耗时。首批样本仅用于定位和筛选；进入独立多轮终验或作者共创依作者对这批正文的决定。[工程清单](E.N5-接话修复候选清单.json)

## 首批作者意见与共创接续

作者认为首批整体有改善，个别回复仍过度服务化。42份不同正文获30项可接受、11项服务化，1项未评。仅改人物材料改善了三个基线服务化位置，也在四个基线已接受的位置出现服务化。两个因素合用时，一处明确求助比单项表现更差；版本比较位置的三种改法均被标为服务化。原始票与逐项解盲按导出指纹存档，整批反馈沿本次会话记录。

本轮进入已选定的作者共创分支。私有状态 `en5_style_co_creation_page` 指向失败原话、已认可对照和完整入模证据。共同取用的原话或人物资料须待作者指定并审阅，随后用同一16位复核。连续风格终验等待这一轮的认可。作者随后指定删去人物资料前的通用发言指导，10轮对照已留存。[通用指导删除对照](E.N5-通用发言指导删除对照.md)
