# PCAR 本地知识优先检索与短答包 2 实施记录

2026-11-20。工程验证使用结构 35 的隔离副本。包 2 提供本地存储、证据登记、检索及回复交接。作者已批准 J4 的检索意图预设，已按原指纹登记到隔离实例并完成两次真实判断。

当前新回合采用本地模型向量召回。[现行检索方向](检索交接根因与换题验收.md#作者纠正后的开发方向)

## 包 2 历史版本怎样读取知识

1. J1 确定接话目标。装配显式选择 `local-first-v1` 时，J4 使用 `retrieve / none` 判断是否需要资料。只有选择检索的轮次才查库。
2. 根据当前角色的桌面知识读取权限，使用 SQLite FTS5 查询。检索词按中文单字、双字及字母数字词建立索引，随后核对完整实体、属性、别名、适用条件和有效期。实体或属性相似但关键条件未匹配时，结果记为资料不充分。指代词可以承接同会话上一轮或明确引用的、目前仍可读取的本地事实的主体。
3. 按会话、角色、实例顺序选取有权使用的证据。单条清楚且无限定的事实直接登记选材结果。有多项一致资料或适用限定时，J5 选材并单独留存本地选材回执。同一条件下有不同值时记为冲突。命中轮直接生成回复，工作台可以打开该轮采用的来源和引文。
4. 未命中、过期、证据不充分或用户要求重新联网核实时，程序核对联网开关、查询范围和会话授权后接续已有查前提示与搜索流程。联网关闭时仍可读取获准的本地事实。用户要求只用本地资料时，未命中也可沿会话继续回应。
5. 生成前、发布前和打开详情时重查选中修订及其有效范围。来源被撤回或原授权失效会停止使用旧证据。存储等待走现有工作台唤醒机制，J4 已有回执可以复用。

## 数据和操作入口

- `local_knowledge_documents` 保存来源修订、作用域、公开 URL、原文哈希、抓取时间、发布时间和原回执。会话私有资料还绑定授权修订及对应授权记录。
- `local_knowledge_facts` 保存事实修订、实体与属性别名、值与单位、限定、引文位置、生效区间和核验有效期。可绑定前一修订和原业务来源。历史资料须能以保存的原文与偏移核对。撤回后相同修订的重复登记仍保持失效。
- `local_knowledge_reads` 在同一事务内绑定回合、查询指纹、命中结果、选中的事实修订和可选 J5 回执。FTS5 索引可从事实记录重建，完整业务库可随迁移包导出和导入。

资料登记是给明确导入和后续后台整理使用的入口。使用 `python -m scripts.pcar_local_knowledge --home "<隔离实例>" --help` 查看命令。公开资料用 `admit-public`，由操作者指定角色或实例范围。材料 JSON 含 `document` 和 `fact` 两个对象。文档需提供 `url/title/body/receipt/acquired_at/source_kind`，事实需提供 `subject/predicate/value/quote/start/end`。偏移按原文字符计数，起点含、终点不含。

`admit-legacy` 核对旧公共来源的页面当前修订、事实状态、所有者、原文哈希和引证。`admit-turn` 从已授权的会话检索回执登记事实，保留原会话范围。`query` 按当前真实权限试读，`withdraw` 撤回指定修订，`rebuild-index` 重建并核对索引。各写操作使用 SQLite 事务。[本地操作入口](../../scripts/pcar_local_knowledge.py)

两组离线回归共 160 项通过，涵盖增量库、私聊各阶段、桌面恢复、旧版迁移和原生搜索兼容。

| --- | --- |

| 包 1 结构 34 副本升级 | 原有 171 张表、371 行比对一致，包括 4 个回合和 3 笔检索记录。两种副本均通过完整性与外键检查，升级前备份可读。 |

## 原题在新隔离窗口的整轮复验

最终整轮使用原获批的 J4、整理和资料审核文案，沿工作台正常入口从第一题跑到最后一题。九条不同原话加一次 Python 重问，共十条，故障为零。三次冷查均完成真实联网及整理。重复查询、跨题取用和已引用的精确时刻未再联网，换算按常规回答，道别按接话决定静默。最后一次运行的程序指纹与启动记录一致。

此前独立窗口暴露了标题简称、计划时刻混入实际结果、地名层级、指代主体丢失、提前预告与已上线资料混选以及把推测说明当成适用限定等问题。修复后用原回执逐项核对。结构 33 和 34 副本逐行对账，旧来源准入、迁移导入、索引重建、幂等登记和撤回另有验收记录。末版证据及路由回归和兼容回归共 220 项通过。私有目录「包2全题复验」保留所有原题、故障记录及最终对账。
