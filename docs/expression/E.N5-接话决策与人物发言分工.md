## 模型材料与固定前文

Flash 的人物投影只取本轮冻结的 `core.data.core_traits` 与 `expression.data.style`。最近两轮通过原 v8 已用前文与实际显示回执核对，再按事件顺序放回对应用户和人物消息角色。当前合批中的每个成员可独立定位。显式引用使用当初受理和已校验的来源。当轮编号只在该轮有效。接口以技术字段公开可用编号和取值，Flash 候选首版采用官方非思考 JSON 输出，最大输出 128 token。

主要动作使用“参与交流”“回应求助”“承接转题或收尾”。任务状态使用“无待办”“进行中”“已收束”。未定由空目标及两项“未定”表示。有效判断的目标在 Pro 侧映射回原请求的消息位置、说话人及必要的合批成员或引用标识。受审说明和三个字段追加到原系统消息末尾，原始真人发言与角色已说的前文逐字保留。作者判断和模型判断复用这套装配。

首批沿用第一段第03、04、06、07、11、12、13、15轮和第二段第03、05、09、10、12、13、14、15轮。准备时重建全部30份原请求，分别核对输入、物理请求、首次原生正文及桌面可见回执。16个位置的决策输入均有最近两轮和本轮发言，实际显式引用计数为0。混合气泡、显式引用及跨范围拒绝另用本地替身检查。

## D2 实测结果

16份官方 Flash 首次回执均完整。14份返回 `id/source/text`，典型内容是下一条聊天发言，另2份的正文无法解析为单个 JSON 对象。2-14 的返回文本在一个对象后又续写了一条用户消息。系统依照既定合同要求 `target/action/task_state`，有效判断0份，16轮均取回已保存的原 v8 正文。用量8,325 tokens，新增 Pro 请求0次。最短1.50秒、中位数1.74秒、最长2.73秒，3秒回退线没有触发。

上述结果定位到判断输出的结构。Flash 输入中的历史和当轮消息也使用 `id/source/text`。模型沿这一格式续写是观察到的现象，具体哪项提示或装配导致它仍需另作受控验证。私有状态 `en5_decision_d2_receipt_review` 保存16份未经修补的决策原文和对应作者判断。已发生调用和判断失败均按原回执保存。

## D3 隔离桌面施工
