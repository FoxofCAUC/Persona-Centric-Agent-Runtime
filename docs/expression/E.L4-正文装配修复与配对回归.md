# E.L4 正文装配修复与配对回归

2026-11-18。上轮新链对原v8 Pro的正文偏好为6比10。作者要求定位问题、修复后做真实模拟，并解除测试阶段真实计费请求的数量上限。作者随后审阅了这一版完整输入并同意实测。

## 失票位置的证据

- 在第3、4位，人物从表达素材搬入了同一句经历。第3位还引入了双方的入学关系。对照原话、首次理解及当时实际采用的条目，相关句子能追溯到条目里的引语，聊天中没有对应经历。
- 在第9位，原稿把建议扩成了已经执行的下单和取消操作。其表达条目提供了可以补入个人计划的开放句式。这个句式可能诱导扩写，单条回执无法确定唯一成因。
- 在第11位，理解回执已经标出缺少具体版本对比资料，旧正文仍断言旧版更稳定。这一位的旧语义选材为空，问题也涉及正文如何使用资料状态。
- 原v8装配把当前用户原话作为独立消息，并保有人物关于如实报告、尊重更正的边界。修复前的新链精简了上述人物资料，同一条原话又同时作为历史和回复目标出现。
- 作者在第10位接受了括号内的补充说明，在第13和16位指出两条不同链路中的动作旁白会出戏。上游的整段括号删除会同时损伤第10位的说明。

## 本轮修复

正文直接复用同一位置已冻结的原v8系统消息，将原样保存的Flash理解和适用表达放在单独的参考消息中，最后保留当轮完整用户原话。理解与用户原话完全相同时省去重复理解块。装配使用已审的字段和包装，所有实际请求在实测之前交作者核对。

表达先经已获认可的语义终选，再检查能否从原说话人迁移到当前人物。实验投影整体跳过以下三类条目，即引语与真人来源有至少4个连续规范化文字或数字重合、要求填写开放引语槽位、明确提示模仿来源空括号。第三类同时要求源句确有空括号。规范化仅用于检查，采用的表达仍按原文及原顺序传入。短接话词和纯说法描述均可保留。这是保守的研究筛选条件，也可能略去可用的长表达。

原来选中的18个条目位置中，本轮传入5个，分布于第2、4、7位。13个跳过项中，6个触发来源长引语检查，5个触发空括号模仿检查，2个含开放槽位。资产库及原选择回执均保留。

呈现端单独处理明确且独立的非言语动作括注，保留原始回执、删除跨度与显示正文的各自摘要。普通括号说明、未确定的用法、引用及代码等保留原文。用此前3条作者备注回放，位置10的说明完整保留，位置13和16的动作括注可单独定位。

## 真实模拟与观察

回归沿用同一人物的16个固定位置，覆盖上轮胜负两侧及空选材位置。每位使用原受理状态和同一份Flash理解，对照为同一位置的原v8 Pro及修复前语义选材稿。三路材料均按各自的首次回执取正文。试验集合在调用前冻结，账本按位置登记一次，测试阶段没有固定计费请求总数上限。

| 项目 | 结果 |
| --- | --- |
| 新Pro请求 | 16次，全部HTTP 200并正常结束，均取得首次正文 |
| 对照 | 对原v8 Pro、对修复前新稿各16组正文有差异 |
| 呈现改动 | 新生成的16份中0份触发动作投影，作者看到全部原始正文 |
| 用量 | 输入17,662、输出329，合计17,991 tokens |
| 成本与等待 | 按既有高峰单价估算人民币0.0431178元，实际扣费待核对。新增Pro网络请求中位数约1.83秒 |

第3、4位的新回执均未复现原先重复搬入的经历句。第9位没有再报告已下单或退订，却仍补入未经给出的家庭关系和生活细节。该位保存的理解已将长辈归入人物家庭，而具体生活细节还超出了理解材料。第11位明确了尚缺具体对比资料，同时提出了未经核实的版本差异猜测。这些例子已保存在首次结果中。

本轮使用已用于诊断的16个开发位置验证组合修复。上述观察记录具体错误在首次回执中的表现。
