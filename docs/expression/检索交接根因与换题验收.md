# 检索交接根因与换题验收

包 2 的九轮验收暴露了一个设计缺口。系统能证明某句话来自一篇资料，却没有一路保存“用户问的哪件事、要哪些事实、这段原文支持其中哪项”。下游只能根据实体名称、关键词、候选顺序和一组用途混杂的限定语重新猜测。结果既有错放，也有漏放。第九轮同一题单十条全部通过，记录成立。换题泛化需另行验收。

## 现场证据与诱发条件

| 首次暴露或复发 | 现场对账 | 原因与影响 |
| --- | --- | --- |
| 第一轮 | 来源有新人物线索，候选因作品全名和简称差异被拒。发射时刻的不同写法互相冲突。首版题序在发射问题和代词之间插入了另一个主题。 | 入库核验用标签连续出现代替事实对应关系，值比较丢失了精度。题序另行影响了“它”的实际指向。 |
| 第二轮 | 来源同时陈述本期人物与下期预告。J5 选入本期人物，J7 放行。发射追问的公开检索只收到代词。 | 有来源的旧事件通过了事实审核。指代信息在本地问句变成公开查询时丢失。需要核对导出的获准查询原文。 |
| 第三、四、八轮 | 已入库的推测因用户没有说出“可能”或“玩家猜测”而未被召回。另有作品名、版本、节目和出处分散在标题与相邻句，整理产生的合成标签无法回指。 | 旧 conditions 同时表达适用范围、把握程度和消息出处。匹配器一律要求提问包含限定。同义词例外只能覆盖已见写法。 |
| 第五轮 | 名字见于正文，提交的引文却指向列表标题。另一个候选中的整理标签与原文之间多了一个助词。核对器还把从 J3 取用已交付答案判成缺少资料。 | 可靠的单位是来源字段、位置和所指事件。找得到这个词也可能指错位置。验收还需区分新查入库与对话中复用。 |
| 第六轮 | 可见日期和时刻正确，却引用了计划发射的文字。同批资料中有实际点火原文。“预定轨道”又让整句被当成发射计划。 | 时间值相同不能证明事件已经发生。计划词作用于哪一个动作需按原句判断。同期日期补充还暴露了缓存键被覆盖、写入改变自身检索结果的独立状态问题。 |
| 第七轮 | 用户问人物及其来历，选择集合只含一项。J7 连退两稿。发射地点的中心和下属场地被判冲突。主题题的一次评分要求精确标语，排除了有据的实质回答。 | 同一组缺项证据重复写作不会补出第二项。上下级地点可兼容，同一层级的不同地点可能实质矛盾。评分应跟随用户所问的内容和粒度。 |
| 第九轮 | 同版完成冷查、原题重问、换题后回问、日常换算和结束对话，共十条。自动评分还曾漏识别紧邻中文的人名。 | 交付、证据和评分是三个可独立出错的环节。最终真实通过数保留。反复用于选方案和改程序的题单只作为回归对照。 |

九轮初始评分器登记的失败条数依次为 3、2、2、1、2、0、4、1、0。第六轮的计划引文以及第五、七、九轮的评分争议说明，直接汇总这串数字无法得到产品的真实故障率。私有验收目录“包2全题复验”保存了逐轮窗口、决策、工具和落库回执。

## 各层责任

1. **J4 和授权投影**决定是否检索、可以用什么措辞向外查询。现场多个失败回合已经正确启动检索。代词问题要比对本地指代、已交付的上一轮证据、授权记录和最终发出的查询，保留原有公开范围确认。
2. **采集与整理**决定下游能看到什么。相关结论写在检索综述里，但原句没有进入候选，J5 就无法使用它。相反，把标题里的主体和另一件事的正文拼在一起，也会给下游制造表面上完整的候选。
3. **本地库与召回**决定哪些原文还可用。资格检查、时效、撤回和版本控制继续有效。可能性和出处随事实保留。地区、平台和版本用于比较适用范围。检索别名负责发现候选，同一属性词可以用于多件不同的事。
4. **J5**核对本次问题所需的事实。选材必须同时检查事件和覆盖范围。J7 在取得错误事件的真引文时可能放行，在取得半套资料时可能连续退稿。两种表现都追溯到 J7 之前。
5. **主回复和 J7**分别负责角色表达和资料事实审核。修复位置在材料交接。J7 的退稿有诊断价值，个人经历、角色性格和日常发言仍按既有规则处理。
6. **状态与验收**也各有独立故障。资料补写必须与后续读取对账，回执绑定到实际所选的事实与版本。验收要看来源说了什么、选择交付了什么、窗口真正显示什么，并单列题序和评分器错误。

## 新版候选的工程行为

| 环节 | 可核对的行为 |
| --- | --- |
| 采集 | 对只有摘要的非指定链接查询，可在已有公开来源中补取一页。同一 URL 的不同正文或摘要按来源内容分别留存。给整理模型的有限空间优先分配给已引用来源和不同页面。搜索综述用于导航，回答材料来自可定位的摘录。 |
| 冷查整理 | DeepSeek Flash 使用主模型 Key。输出用户原问里各项要求、事实对应的序号、原文值和位置。主体可在同页标题或引文中，相邻句可一并引用。重复句用出现次序定位。值、来源、位置和引用边界可逐项检查。 |
| 限定与精度 | 区分适用范围、把握程度、出处和明确的上级地点。计划、公告、实测和传闻随事实状态保存。认定地点上下级关系要有同段原文。名字相似或两个地点同属一馆都不足以合并。 |
| 入库重查 | 事实、各项要求、支持关系和拒收原因随同一次事务提交。不同事实可共享检索别名。事实重查先定位该条所属的主体、属性与限定，再在同组内检查矛盾、修订和时效。已有资料不足以覆盖整题时，保留已核验部分用于后续，登记本轮资料不足。 |
| J5 选材 | 同时看到当前问题、可用拆项、事实和原句。可接受整个集合、去除一项后复核，或判定资料不足。冷查缺少列出的任何一项时，程序不给完整交付选项。实际是否答对事件由 J5 独立判断。每次选择均留存绑定回执。 |
| 温读与恢复 | 原问可复用已有拆项。改写后的问题重新交给 J5 对照。已选资料在发出前重新检查授权、有效期、撤回和版本。回执或入库事务已经完成时，重启从对应断点接续。结构化选材资料仅在新装配启用。 |

整理拆项与事实提取在同一次模型调用中完成，可能同时漏掉同一项。J5 仍须核对用户原问。只检查编号齐全无法发现这样的遗漏。新路径在候选很干净时只需一次 J5，有多余证据时每去除一项会增加一次判断。真实延迟需按冷查、温读分别记录。

候选沿用单轮最多八条整理事实。改写追问在当前会话已有结构化记录中先检索三十二个候选编号，再核对资格，最多交八条给 J5。所问资料完全缺席、网页摘录不含原句、或相关内容排在候选之外时，系统仍可能补查。离线验收测的是信息已进入候选时的交接行为。实调须额外核对上游有没有取得原文、拆项有没有遗漏、回复有没有把限定说准确。

## 换题试验与后续验收

先封存展览、演出、档案、交通、服务范围、缺项资料六组独立输入与期望。首测演出和交通各漏选一次。原因是旧、新事件共用了一个搜索属性。按事实编号重查时，别名召回了另一事实，两个不同属性被提前判成冲突，J5 只看得到错误候选。修复按事实所属组检查修订和矛盾，保留同组内的冲突拦截。这一变更不含场次、到站、温度等题面词。

同一批三条旧题的原文回放也出现三个夹具问题。一条需要沿原会话的公开范围确认，另两条的模拟回复直接复述长引文，触发夹具内的 75 字断言。复核恢复公开范围确认，并由模拟回复端回显选中的原文值。原六组和三条旧题来源回放均通过。修复后另取工艺试验、出版修订、场馆预约三组，在新主题首轮通过。上述试验使用模拟整理和决策结果，验证候选是否可见、能否入库、选择是否交付、缺项是否仍被误判为完整。语义识别能力留给真实上游验收。

冻结代码的定向工程回归共 170 项通过，其中结构、存储与修订 47 项，检索、私聊、恢复与输出 123 项。首测曾将两处字符偏移各多算一位，改为按起止位置切回原文。早期兼容回归遗漏独立数据目录，补上隔离目录后重跑上述完整范围。私有专项目录保留首测与最终结果，模板真实上游调用为零。

审阅具体装配后，使用独立工作台和空会话。新增题目以当次公开原文核对，包含当前与前次事件、复合提问、真实资料缺项、地点层级和同层矛盾，以及跨主题后改写追问。逐项记录原问题与授权查询、来源原句、整理原始返回、入库及拒收、J5 候选与选择、J7 意见、窗口正文、各段耗时和物理调用。日常问候与个人经历分别作为无需检索和资料外自由表达的对照。

所有资料结论均能对上所问对象与事件、每项有据要求在窗口得到回答、无资料时不冒充已查证、同义追问可复用有效记录，方可记录本批通过。保留首测失败。修复后重验原例，再用没有参与修补的新资料验收。待审候选尚未取得真实模型泛化结果，正式 G-Auto 保持原断点。

## 首次真实换题暴露的三处故障

首版整理和 J5 文案经作者审阅后，在没有历史事件和知识条目的独立实例接入真实模型，用国内赛事与全球赛事容易混淆的复合问题首测。原问、独立核分资料、模型回执与可见气泡分别保存。

| 环节 | 实调证据 | 工程处理 |
| --- | --- | --- |
| 专职整理输出 | 已收到服务端响应。终止原因是 length，用尽了从聊天模型继承的 1,024 个输出 tokens。数据库把这次已知截断登记为未知结果。 | 结构化整理单独预留 8,192 tokens。对明确收到响应且因长度终止的调用，最多增加一次整理，扩大到 32,768 tokens。两次各自记账。重试绑定首次冻结的同一摘录，不重发用户消息、预告或搜索请求。 |
| 原文位置交接 | 赛事首个完整整理返回有七条事实。模型直接给出逐字主体和引文，程序要求位置对象，七条全部拒收。地理控制题也出现同类错误。 | 唯一的引文可以反查全文位置。主体必须能在所选引文或同页标题中定位。必要时保留完整句子和上下文。日期只写月日时保留原文，沿用普通时效。冻结的赛事返回复核有五条通过，两条因主体歧义或限定超出引文保留拒收。 |
| 复合提问的前提 | 修订后 J5 已收到国内冠军、比分和另一赛事的逆转经过，仍按整题缺资料退回。本轮工作台告诉用户没有确切消息。 | 经作者再次审阅，整理额外标记后问依赖哪个前问。J5 独立核对来源，可用明确反证更正前提，也可在两场事件都可区分时接受完整对照。其他独立要求仍要有证据。选择和对应的事实集合均保存到回执。 |

真实外发使用原有角色材料和主模型 Key。判断文案的新增内容按候选摘要绑定隔离用途。正式 G-Auto 保留原断点。

### 前提由谁判定

真实整理在有来源和只看原问两种输入下都省略了可选的 dependencies。程序将省略解释成没有依赖，事实 J5 因此无法选择更正。作者随后批准独立 Jev 单选。对于缺少关系记录的复合问题，Jev 只看原问和逐项原文，在“独立”和“依赖第几项”之间作出选择。该判断不读取网页、人物或赛果。事实 J5 再用原文判断前提是否成立。两种判断分别持久化，中断后沿原回执接续。

独立判定版的赛事首问取得两张真实回执。关系节点选中 premise/0，事实节点选中 correct/0。窗口答出了国内冠军、比分以及另一场赛事的名称。所选来源还写明了另一场决赛先失一局后连赢三局，首问气泡省略了这一经过。按可见答案单独登记内容遗漏。

从地理话题回到同一赛事，窗口补全了另一场决赛的经过。该轮外部搜索和专职整理各为零。首问与重问选中了完全相同的五条资料，但首问沿用整理顺序，重问使用查询相关性排序。终验候选统一按同一查询排序，并为每条选材路径保存实际顺序，重启后核对原记录。顺序差异已查实，模型采样和会话历史也会影响措辞。

独立多项提问还暴露了两种故障。日期及地点三条有据候选各多带一个重复的原文位置字段，旧检查按额外键直接退稿。新检查允许与已验证引文、主体或原文值完全相符的位置重复出现，冲突位置仍拒收。另有转载原句只写“今天”和时刻，同一实体、属性和状态的另一原句明确写出年月日和相同时刻。该相对时间不提供一个与绝对日期冲突的新日期，程序优先采用具备完整日历依据的记录。冻结的真实整理结果在隔离数据库复核时准入三条，再读取得完整日期时刻和地点。补取网页返回明确 HTTP 错误时，按已知失败记录，保留已取得的其他来源。

统一排序版的赛事首问和跨题重问都只给出了国内冠军与比分。两次选择相同，原文中单独支持后问的事实被“只更正前提”排除。用同一组真实来源和同一份已审选材文案，先单独询问能否形成完整对照，J5 选择了 complete。终版据此调整决策顺序。有可定位的补充材料时，先判断整套资料能否直接回答。完整对照不足时，另行判断是否有证据足以只更正前提。两个选择均使用已审判据，保留各自回执。缺乏证据的独立问题继续登记不足。

另一个新实例中，全量候选同时包含冠军、整届赛事晋级路径、决赛比分和单局操作。J5 对整组选了不足，再选择只更正前提。为区分文案与候选集合的影响，取两轮分别获得的真实原文，每个所问事项按同一相关性顺序先选一条代表材料。两次隔离 Jev 核对均选择完整回答。当时的实现先让事实 J5 审阅逐项选出的原文。只有 J5 接受，才将这组材料交给回复模型；不接受时按原流程审阅更大的候选集合，最后才判断能否只更正前提。这一规则适用于有多个所问事项的资料问题，不依赖赛事名称。

### 旧版验收结论

真实换题的整体验收未通过。前提判定、正确更正和本地复用均有实际成功回执，另一轮隔题重问完整答出了两场赛事的区别及逆转方式。最后一批空会话中的赛事首问仍答成没有资料。隔题重问重新联网后，逐项候选通过 J5，国内冠军和比分答对，气泡仍省略了已选来源中的具体逆转经过。航天问题在先前实例答出月日和发射中心，时刻追问本地命中；最后一批首问因拆项无法连续匹配原问而未入库，后续公开查询也失去了明确指代。

最后一批结束后，对原回执补做了两项本地修补。共享主体的复合问题可以从唯一、保持先后次序的逐字匹配中找到各自有区别的原问片段。整理值省略同一句中的文字时，只在唯一可定位、未跨句、未省略限制语的条件下恢复连续原文。新增文字、改序、跨句归纳和歧义位置继续拒收。用同一份真实整理返回在隔离数据库回放，航天拆项恢复并读到了月日，地点候选仍因主体位置有歧义被拒。赛事回放额外恢复了一段真实晋级经过，两个国内冠军候选仍触发旧的标量冲突。本次屏幕结果按实际运行版本记账。

### 作者纠正后的开发方向

上文记录的是旧版的失败现场。原先提出的赛事冲突特判与逐项审核施工方案已经撤销。

本地库承担语义召回。用本机 BGE 模型为用户自然提问和有权读取的来源片段编码，从同一向量空间选取相关材料。来源带着日期、适用范围和出处进入回复链。名称写法不同不能作为拒绝召回的理由，相似度只表示相关程度。会话授权、资料撤回及有效版本在资料对模型可见前生效。

联网得到的来源先写入本地库，随后沿同一向量路径回忆。新回合退出逐字选事实、按问题拆项选材以及逐项对照气泡的旧流程。保留旧回执供查阅，不能把没有执行的事实审核记为已通过。

检索系统的价值以真实使用衡量。用户可以换一种说法、跳到别的话题、再接着追问。观察回复能否自然承接原意、利用本来就有的资料、在确有需要时补查，以及出错后能否纠正。离线回放用来定位故障；工程计数和固定原题通过情况不构成真实体验的结论。
