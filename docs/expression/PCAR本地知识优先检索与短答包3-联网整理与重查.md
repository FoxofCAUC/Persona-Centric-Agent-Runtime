# PCAR 本地知识优先检索与短答包 3 实施记录

2026-11-20。包 2 的 J4 已获作者批准，原版装配已登记到对应隔离实例。两次独立的真实 J4 调用分别对公开资料查询返回 `retrieve`，对日常换算返回 `none`。作者已审阅通过包 3 的知识整理预设。隔离工作台已按审阅版本完成真实冷查询及同题复用。

## 冷查询怎样得到回复

1. J4 选择检索后，工作台先查本地。命中轮按包 2 的权限、时效和来源规则生成回复。本地缺资料且本轮具备联网许可时，沿原回合先显示查前提示。完整显示回执到达后才派发联网工具。
2. 搜索回执先保存在业务库。整理模型只收到已授权的查询、查询日期、来源编号和相关原始摘录。单次最多八条，按模型输入空间裁定，每条最多 1,200 字符。标题和综合底稿可以留在本地详情；整理事实需要有可核对的原文摘录。
3. 整理使用独立的调用用途、预算记录和物理回执。接收方绑定已有官方 DeepSeek Flash，标准私有人格核对整理用途授权，会话全流程模式核对当前接收方及授权修订。返回的原始 JSON 先留存。程序逐项核对来源编号、引文实际位置、值、单位、主体、限定及时间字段，合格条目进入同一次写事务。资料自动沿原会话范围登记。
4. 写事务同时保存事实修订、全文索引和提交回执。重复处理同一工具结果沿已保存回执恢复。同一作用域、同一网址及同一内容版本的文档可复用，独立取得的事实保留各自的验证时间和来源关系。
5. 提交后开启新的读事务，再用原来的本地问题检索。单条明确事实可直接取用；复合问题需要独立选材时交 J5 核对。复合问句的选择结果与原查询指纹绑定，再次使用时逐条复核索引、来源、作用域和有效期。J6、Replyer、J7 收到选定的事实，窗口可展开原始引文和出处。
6. 重问先查已提交的本地知识。即使先前正文退稿，仍可使用有效的已入库事实。过期、撤回、存在冲突或证据不充分时按实际状态处理。明确要求重新联网的查询使用本轮取得的证据。

## 中断与核对

| 断点 | 恢复行为 |
| --- | --- |
| 已查回，尚未整理 | 从原回合保存的工具记录生成整理输入，再核对授权和来源。 |
| 有明确的发送前断网证据 | 沿原回合等待恢复并重新申请派发；已经收到的搜索结果继续使用。 |
| 整理请求结果未知 | 保留原尝试身份，停在回执核对处。工作台可按授权查看已查回资料。 |
| 已收到整理结果，尚未提交 | 复用原始整理回执，重新核验所用来源。 |
| 已提交，尚未作答 | 重新读库并登记所用修订。已完成的搜索和整理各用原回执。 |
| 整理期间撤权，或显示前撤回资料 | 停止相应提交或展示。控制不同用途的授权、来源状态以及事实修订均在各自使用点复核。 |

## 作者批准后的真实验收

隔离 WebView2 工作台按审阅时的完整装配运行。四个会话提交 26 个不同回合。按原施工表，包 3 的冷问题入库后作答、重问本地命中、回复引用已选事实、整理回执后可恢复四项均有对应证据。前三项有真实窗口回执，恢复项通过故障注入回归。

| 现场问题 | 已核对的结果 |
| --- | --- |
| 日期被错误拒收 | 整理模型引出了发布日期，程序却要求中文属性标签也出现在来源原文。现在将属性标签用于索引，事实值与引文仍须回指原文。Python 冷查、原题重问与跨题回问均答出完整日期。 |
| 同一实体与同一日期有多种写法 | 实体按原问题和来源共同支持的名字建索引。同一主体、属性和条件下，等价日期写法可以共同支持同一回答。不同年份或不同日仍保留冲突。神舟两次冷查均答出月日及发射场，其中一次给出完整年份。 |
| 无关的旧剧情被选作前瞻主题 | 按原文引证位置、问题相关性和可用日期挑选整理摘录。跨题召回旧材料时，问题明确点名的属性需要对应证据。最后一场缺少主题资料时，工作台在标准授权下请求查找范围。确认原问题后，原回合补查并答出蘑菇主题；再问直接命中同一条已提交事实。 |
| 更新程序后要恢复已发出的整理请求 | 派发时保存所选片段的编号、位置、长度及请求指纹。恢复时用原片段和当前授权校验同一回执，避免重新排序改变已经发出的请求。 |

## 资料审核范围和日期完整性修正

作者批准的 `private-reply-output-v4` 在查后或本地命中的正文上运行 J7。它读取目标问题、资料状态、所选事实、正文和长文详情。核对范围为所问资料的正确性、依据和关键限定。角色自己的经历、性格、感受和其他与所问资料无关的话属于自由表达。日常聊天与查前预告直接进入原有发布流程，留存本地放行回执。J7 的选项为 `accept` 与 `fact`。资料不足时，角色可以按已知范围自然作答。

神舟原回合有 24 条来源。整理模型引用新华社的「4月24日」，同一搜索回执中的央视原文给出了完整日期。修复后的提交与旧知识首次复用都会核对同一主体、同一事件和月日，以原文中可定位的完整日期另存一条事实。若找不到明确引文，或匹配来源给出不同年份，保留原记录的精度。每次引用重新核对作用域、来源和有效性。日期与地点同时被问到时，选材需要覆盖两项。

- 原失败回执的本地回放覆盖冷提交、旧月日记录在重启后的首次复用、再次重问。三条路径都把完整日期和发射场交给了回复入口。原会话已经封存，原正文保留原样。
- 可写隔离窗口的三轮真实提问依次为神舟、日常换算、神舟。两次神舟正文均在桌面显示「2025年4月24日从酒泉卫星发射中心起飞的」。首轮联网和整理各一次，重问两项均为零。日常换算与查前预告的 J7 调用均为零。
- 使用已审预设单独核对三份实际材料，带个人经历的正确日期原稿获得 `accept`，错误前瞻主题获得 `fact`，撤去资料后仍断言具体主题的原稿获得 `fact`。私有目录「资料审核与日期完整性」保存批准指纹、逐轮窗口回执、旧数据回放和三次 J7 回执。

### 跨主题复验

隔离工作台完成五轮公开测试。黄河入海口首问和跨话题重问均答「渤海」，后者重新使用同一事实，联网与整理为零。日常聊天跳过 J7，另两条资料错误和缺证据对照均被资料终审拦截。45 项回归及 7 项日期检查通过。

自动控制课程提纲漏答根轨迹与频域分析。原始回执确认相应章节已入库，但本地检索把同一「章节目录」下的不同章当成冲突值，J5 最终选中一条概要，最终答复不完整。传递函数与方框图的追问由常规聊天作答。私有目录「资料审核与日期完整性／跨主题实测」保存逐轮回执、来源核对和故障数据。

### 目录条目修正与现场复验

有明确编号的目录按主体、属性、限定和编号核对。不同章节可共同进入结果，同一编号对应不同标题时记录冲突。核对覆盖当前可用的全部证据，再按原有读取条数上限取材。对提纲问题，J5 可以选择按编号排序的同一文档条目及其概述。索引在读取时识别已有记录，无需重新整理旧资料。

同题复验中，第一次 J5 取回了第 3 至第 6 章，J3 同时选中此前的残缺回复，J7 拦下两稿。修正后，若本轮的目录证据完整包含并扩充了同题旧答所用的事实，旧答退出本轮自动选材。显式引用继续沿原引用范围处理。隔离桌面首稿答出了建模、时域、根轨迹、频域和离散系统，J7 放行。五条来源逐条复核，联网及整理均为零。对同一章注入不同标题会触发冲突，撤回后恢复。

目录修复后用《档案法》与 OpenStax 微积分教材完成四轮隔离桌面回放。章节名与点分小节可混排，汉字间的排版空格不影响同章比较。两种资料切换后，重问均复用五条旧事实，保存了同一小节不同标题触发冲突的对照。四轮使用本地传输替身。私有验收目录「目录冲突修正-e58cb6ff／换题回归」保存输入、回执和最终对账。

再换建筑防火规范和 MIT 美国城市史课表做四轮隔离桌面回放。规范的章节与小节共存。课表首测曾把同一周的不同课次判为冲突，修复后按周次与课次识别。两种样本重问均复用原事实。同一周同一课次给出不同标题仍触发冲突，发布前复核拦住旧选材。完整记录在私有目录「规范与课表复验」。

### 连续三轮无误报验收

同版代码依次回放《民法典》和《物种起源》、CSS 语法规范和比较政治课程、环境应急预案和 HTTP 语义规范。首测发生的三种编号误判已修复。三轮均完成两个首问和两个跨题重问，所有重问复用原事实编号且没有再次触发联网或整理。六组同位置不同标题对照均报告冲突，撤回后恢复。工作台显示和发布前证据重核均已对账。验收使用本地模型替身，逐轮材料和源码指纹位于私有目录「连续三轮换题验收」。
