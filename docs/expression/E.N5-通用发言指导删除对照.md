# E.N5 通用发言指导删除对照

2026-11-18，作者根据截图及开发者反馈指定删除人物资料前的通用发言指导，并小批验证。按截图正文的边界去掉原 v8 系统消息开头180字，保留“人物资料”标题、后面的人物材料、每轮用户原话、历史、消息角色和模型参数。每个位置复用原 B 首次回复，对删减版取得一份真实 Pro 回复。既有装配继续用于原研究回放；本次改动限定为可复验的试验版。[原 v8 指导](../../persona_runtime/companion_im.py) · [接话专项施工指导](E.N5-人物接话专项修复施工指导.md)

## 为什么这一段值得独立检查

指导在每轮系统消息开头同时要求人物化表达、处理正事、衡量建议与解释的时机，以及控制短句和标点。它允许意思到了就收住，却也反复把任务完成和是否提供建议递给模型。模型面对带技术词的闲聊时，可能把“衡量对方意愿”落实成再次问用途、接下一项活，附在已经成立的自然反应之后。短句、省略之类的形式指导也无法替模型决定这一轮该以自己的立场回应，还是应对方请求提供帮助。以上为可检验的解释，整段删除的对照无法单独归因到其中一个词句。

## 实际对照

冻结位置为第一段第03、06、07、11、12、13、15轮及第二段第03、10、15轮。10个新增请求全部取得 HTTP 200 及完整首份正文，复用10份原版。接收的原始字节、实际模型、正文与匿名页均已核对。新增10,195 tokens，实际扣费待账单核对。

| 位置 | 删减后看到的变化 |
| --- | --- |
| 1-06 | 减少自我推介，改用预算玩笑；原话没有交代单位，仍有过度猜测 |
| 1-07、1-12 | 分别减轻当场揽写稿和未来代测邀约，人物仍可用自己的好恶继续说话 |
| 2-03 | 对游戏内容给出自己的判断，减少让用户替她决定如何回应的问句 |
| 1-13、2-10 | 保留正常的社交反问和明确求助时的必要澄清 |
| 1-11 | 给出更直接的建议，也新增没有资料支持的版本差异判断 |
| 2-15 | 对方回到吐槽后仍继续排障，具体动作还更多 |

初读结论为局部改善。去掉通用指导后，主动揽活和把人物态度交给用户的现象在几个原失败位置减轻；任务意图和收尾仍有残留。每位置只有一份新采样，使用与原版相同的冻结前文，结论限于此批。后续由作者逐对判断自然性、必要帮助及事实边界。私有状态 `en5_guidance_removal_review` 指向匿名页，`en5_guidance_removal_reading` 指向解盲初读，`en5_guidance_removal_input` 可逐字核对删减范围。
