## 产品行为与权限

角色联网政策新增discover_public_pages，默认关闭，旧缺字段策略保持关闭。工作台可勾选「自动定位未登记公共话题」，需要已授权的中文Wikipedia、正文保存及原站API能力；角色读取、联网和Jev仍需原有授权。启用后即使登记主题表为空，也可以查询公共百科问题。

1. Jev选择是否需要公共知识，既有目标理解消解问题和指代。
2. 已登记主题优先沿原流程；没有对应候选时，主模型提出最少必要百科标题，通常1个、最多3个。不会为了开启此功能预先给验收题填主题表。
3. 另一逻辑位置独立复核公开性、相关性和私人信息风险。普通私人关系中的姓名、住址、账号、联系方式、内部资料等不能作为公开标题。结构检查拒绝非文章命名空间、URL／控制符、联系方式及长数字等明显不合规标题。
4. 程序仅将通过复核的标题转换为固定中文Wikipedia页面URL，并通过原站API读取。原问题、近期对话、号码及私人限定语不作为来源请求参数。提出和复核仍使用已授权主模型及其配置，不新增模型密钥。
5. 实际读取前及发布前，核对提出／复核任务完成状态、角色／渠道／会话范围、政策、来源签名、结果指纹和准确URL。不得篡改复核结果、换目标或跨角色复用审批。
6. 取得正文后继续走现有章节／窗口选材、翻译、独立证据复核、Manifest和投递前校验。不存在的页面作为已知无匹配，不造文档或事实。

来源请求使用页面或修订标识，正文与revid沿既有一致性校验。[MediaWiki页面解析接口](https://www.mediawiki.org/wiki/API:Parsing_wikitext)列出了page、oldid及missingtitle语义；HTTP200仍可能包含API错误，故同时核对JSON内容。[错误格式说明](https://www.mediawiki.org/wiki/API:Errors_and_warnings)

公开性仍有模型判断参与，本轮验证不能被表述为穷尽的隐私安全证明。首版自动定位范围是中文Wikipedia主命名空间；它不是任意站点、任意私人信息或全网自由查询。其他来源仍按既有登记政策执行，不依赖任何本地百科包或标题字典。
