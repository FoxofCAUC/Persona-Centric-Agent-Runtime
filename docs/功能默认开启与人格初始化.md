- 每项新功能必须同时交付默认策略、已有目标的启用步骤、新建／导入／复制初始化、界面状态和必要局部验证。代码存在但入口未启用，不能宣称功能已实装。
- 后续已上线功能默认开启；未实现或未通过阶段门的能力不能伪装启用。显式关闭仍是有效用户设置，普通重启和重复初始化不能将其覆盖。
- 默认开启不授予新供应商权限、不提高额度、不扩展跨人格／跨入口读取，也不绕过隐私、测试隔离、来源撤回或不确定投递保护。新外部凭据仍需配置，未就绪必须显示原因，按既有合同安全降级。
- 验收只做新增和受影响检查；不为修改默认值重跑全量、历史付费组或真实QQ。默认行为本身必须有测试，历史兼容场景显式选择旧模式。
