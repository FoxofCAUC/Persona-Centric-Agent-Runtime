# 本人人格私聊桥接

## 0.5.0协议说明

新插件先验证服务durable_ingress_v2能力，通过/v2/ingress受理获准本人QQ纯文本、保留平台来源ID并等待批次关联turn。不兼容明确提示，不自动降级重交；新插件发现 `reply_delivery_parts_v1` 后，通过 v2 逐片领取、发送并记录平台消息 ID；旧插件不会领取带有新账本的回复，历史 turn 仍可使用 /v1 路径。默认逐条，用户在工作台按人格/入口显式开启缓冲。

仅供当前项目独立部署的 AstrBot 4.29.1 使用。`prepare` 将本目录复制到独立 Bot 数据目录，并通过宿主的 PYTHONPATH 导入当前仓库中的 `persona_runtime`。

插件不自行调用 LLM，不包含密钥或旧 TRPG 配置。只允许指定 OneBot 平台、已核对 Bot QQ、本人好友私聊及有平台消息 ID 的纯文本。
消息进入异步 HTTP 请求之前即停止 AstrBot 默认传播。HTTP/模型失败不会回退普通聊天。

平台消息去重与发送权由人格服务持久化管理；后台投递支持用户显式重试后生成的新回复，发送不确定状态不自动重发。后台发送前再次核对当前 Bot 身份。
每个待投递请求绑定原本人账号与 Bot 账号；配置切换不会把旧回复发给其他人。

测试使用 `scripts/test.ps1`，实际 SDK 探针见 `scripts/check_sdk.py`。真实 QQ 扫码与消息收发需用户自行验收。
